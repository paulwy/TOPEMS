# _archive/ 归档目录

本目录存放**已废弃、不再维护、但保留作历史参考**的零散文件。
与 `svc/_archive/`（整服务归档）、`docs/archive/`（文档归档）不同，这里是**根级散落归档**，
收纳那些不属于某个服务目录、也不属于文档体系，但删除前有参考价值的代码/脚本残留。

## 归档语义

- **历史快照**：文件对应功能已在代码库他处落地或彻底移除，此处仅留作考古；
- **不再维护**：不随主代码编译、不参与构建、不接受 PR 修改；
- **保留原因**：记录旧接口形态 / 旧表结构，便于回溯"当初为什么这么设计"。

## 注意

- 本目录**已被 git 跟踪**（未加入 .gitignore），属有意入库的历史快照；
- 不要在此目录新增业务代码；新废弃文件优先归入 `svc/_archive/<服务>/` 或 `docs/archive/`；
- 若未来确认某文件彻底无参考价值，可由集成阶段统一 `git rm` 移除。
