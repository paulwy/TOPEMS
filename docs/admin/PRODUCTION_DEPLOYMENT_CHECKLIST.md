# TOPEMS 生产环境部署验证清单

## 概述

本文档是 TOPEMS 系统生产环境部署的完整验证清单，用于确保部署过程的每个环节都经过验证，系统可以安全、稳定地运行在生产环境中。

## 部署前检查清单

### 1. 硬件资源检查

- [ ] **CPU**：≥ 8 核（推荐 16 核）
- [ ] **内存**：≥ 16 GB（推荐 32 GB）
- [ ] **磁盘**：≥ 100 GB SSD（推荐 200 GB）
- [ ] **网络**：≥ 100 Mbps（推荐 1 Gbps）
- [ ] **操作系统**：Linux（Ubuntu 20.04+ / CentOS 8+ / Debian 11+）

### 2. 软件依赖检查

- [ ] **Docker** ≥ 20.10（如使用容器部署）
- [ ] **Docker Compose** ≥ 2.0（如使用容器部署）
- [ ] **PostgreSQL** ≥ 13（推荐 15）
- [ ] **Redis** ≥ 6.0（推荐 7.0）
- [ ] **Nginx** ≥ 1.18（反向代理）
- [ ] **Node.js** ≥ 18（前端构建，如源码部署）
- [ ] **Rust** ≥ 1.70（后端编译，如源码部署）

### 3. 网络与安全检查

- [ ] **防火墙配置**：仅开放必要端口（80/443/22）
- [ ] **SSL 证书**：已配置有效的 HTTPS 证书
- [ ] **域名解析**：域名已正确解析到服务器 IP
- [ ] **API 网关**：已配置请求限流和熔断
- [ ] **VPN/堡垒机**：管理端口通过 VPN 或堡垒机访问

### 4. 数据库准备

- [ ] **PostgreSQL 已安装并启动**
- [ ] **数据库已创建**：`CREATE DATABASE topems;`
- [ ] **数据库用户已创建**：`CREATE USER topems WITH PASSWORD 'strong_password';`
- [ ] **权限已授权**：`GRANT ALL PRIVILEGES ON DATABASE topems TO topems;`
- [ ] **pgvector 扩展已安装**：`CREATE EXTENSION IF NOT EXISTS vector;`
- [ ] **数据库备份策略已配置**：每日全量备份 + 实时 WAL 归档

### 5. Redis 准备

- [ ] **Redis 已安装并启动**
- [ ] **Redis 密码已设置**：`requirepass strong_password`
- [ ] **Redis 持久化已配置**：RDB + AOF
- [ ] **Redis 内存限制已设置**：`maxmemory 4gb`
- [ ] **Redis 淘汰策略已配置**：`maxmemory-policy allkeys-lru`

### 6. 环境变量配置

- [ ] **JWT_SECRET**：已生成强随机密钥（≥32 字符）
  - 生成命令：`openssl rand -hex 32`
- [ ] **JWT_REFRESH_SECRET**：已生成强随机密钥（与 JWT_SECRET 不同）
- [ ] **DATABASE_URL**：已配置正确的数据库连接字符串
- [ ] **REDIS_URL**：已配置正确的 Redis 连接字符串
- [ ] **AI_API_KEY**：已配置 AI 服务 API 密钥（如使用外部 AI 服务）
- [ ] **AI_PROVIDER**：已配置 AI 服务提供商（openai/azure/anthropic/mock）
- [ ] **SERVER_PORT**：已配置服务端口（默认 8080）
- [ ] **LOG_LEVEL**：已配置日志级别（生产环境建议 info 或 warn）
- [ ] **CORS_ORIGINS**：已配置允许的跨域来源

## 部署过程检查清单

### 1. 代码获取与编译

- [ ] **代码已拉取**：`git clone <repository-url>`
- [ ] **代码版本已确认**：`git checkout <release-tag>`
- [ ] **依赖已安装**：`pnpm install`（前端）/ `cargo build --release`（后端）
- [ ] **前端已构建**：`pnpm build`
- [ ] **后端已编译**：`cargo build --release -p topems-unified-core`
- [ ] **编译产物已验证**：二进制文件存在且可执行

### 2. 数据库迁移

- [ ] **数据库迁移已执行**：`cargo sqlx migrate run`
- [ ] **迁移结果已验证**：所有表已创建
- [ ] **初始数据已导入**：管理员账户、默认配置等
- [ ] **数据库备份已创建**：部署前的完整备份

### 3. 服务启动

- [ ] **后端服务已启动**：`./target/release/topems-unified-core`
- [ ] **后端服务状态已验证**：`curl http://localhost:8080/health` 返回 200
- [ ] **前端服务已启动**：`pnpm start` 或通过 Nginx 托管静态文件
- [ ] **前端服务状态已验证**：`curl http://localhost:3000/` 返回 200
- [ ] **Nginx 已配置并重启**：反向代理配置正确
- [ ] **HTTPS 已配置**：SSL 证书有效

### 4. 进程管理

- [ ] **Systemd 服务已配置**：后端和前端服务作为 systemd 服务运行
- [ ] **服务自动重启已配置**：`Restart=always`
- [ ] **服务开机自启已启用**：`systemctl enable topems-backend`
- [ ] **进程监控已配置**：Prometheus + Grafana 或其他监控工具

## 部署后验证清单

### 1. 基础功能验证

- [ ] **健康检查端点**：`GET /health` 返回 200
- [ ] **API 根路径**：`GET /api` 返回 200
- [ ] **登录功能**：使用管理员账户登录成功
- [ ] **登出功能**：登出后跳转到登录页
- [ ] **Token 刷新**：Token 过期后自动刷新
- [ ] **权限控制**：不同角色访问权限正确

### 2. AI 业务智能模块验证

- [ ] **业务 Copilot - 创建会话**：`POST /api/ai/dsh/copilot/sessions` 返回 200
- [ ] **业务 Copilot - 发送消息**：`POST /api/ai/dsh/copilot/sessions/{id}/messages` 返回 200
- [ ] **业务 Copilot - 意图识别**：`POST /api/ai/dsh/copilot/intent/recognize` 返回 200
- [ ] **智能表单 - 获取定义**：`GET /api/ai/dsh/forms/definitions/{type}` 返回 200
- [ ] **智能表单 - 验证表单**：`POST /api/ai/dsh/forms/validate` 返回 200
- [ ] **文档智能 - 文档列表**：`GET /api/ai/dsh/documents/documents` 返回 200
- [ ] **文档智能 - 文档搜索**：`GET /api/ai/dsh/documents/search` 返回 200
- [ ] **治理仪表盘 - 仪表盘数据**：`GET /api/ai/governance/dashboard` 返回 200
- [ ] **治理仪表盘 - 治理评分**：`GET /api/ai/governance/score` 返回 200
- [ ] **治理仪表盘 - 风险评估**：`GET /api/ai/governance/risk` 返回 200

### 3. 前端页面验证

- [ ] **登录页**：页面正常显示，登录功能正常
- [ ] **仪表盘页**：数据正常加载，图表正常显示
- [ ] **业务 Copilot 页**：模块选择、对话、表单、文档功能正常
- [ ] **治理仪表盘页**：评分、风险、合规、成本、性能数据正常显示
- [ ] **响应式布局**：桌面、平板、移动设备布局正常
- [ ] **页面加载性能**：首屏加载时间 < 3 秒

### 4. 性能验证

- [ ] **API 响应时间**：P95 < 2 秒，P99 < 5 秒
- [ ] **并发用户**：支持 ≥ 100 并发用户
- [ ] **吞吐量**：≥ 100 请求/秒
- [ ] **错误率**：< 1%
- [ ] **CPU 使用率**：< 80%（正常负载下）
- [ ] **内存使用率**：< 80%（正常负载下）
- [ ] **数据库连接数**：< 80% 最大连接数
- [ ] **缓存命中率**：> 80%（如启用缓存）

### 5. 安全验证

- [ ] **HTTPS 强制**：HTTP 请求自动重定向到 HTTPS
- [ ] **SQL 注入防护**：恶意 SQL 输入被正确过滤
- [ ] **XSS 防护**：恶意脚本输入被正确转义
- [ ] **CSRF 防护**：跨站请求伪造被正确拦截
- [ ] **API 限流**：超过限流阈值的请求被拒绝
- [ ] **敏感数据加密**：密码、Token 等敏感数据加密存储
- [ ] **日志脱敏**：日志中不包含敏感信息
- [ ] **安全头**：HSTS、CSP、X-Frame-Options 等安全头已配置

### 6. 监控与日志验证

- [ ] **应用日志**：日志正常输出，级别正确
- [ ] **访问日志**：Nginx 访问日志正常记录
- [ ] **错误日志**：错误日志正常记录，包含堆栈信息
- [ ] **性能指标**：Prometheus 指标正常采集
- [ ] **监控告警**：Grafana 仪表盘正常显示，告警规则已配置
- [ ] **日志轮转**：日志文件按大小或时间轮转
- [ ] **日志保留**：日志保留策略已配置（建议 ≥ 30 天）

### 7. 备份与恢复验证

- [ ] **数据库备份**：每日自动备份正常执行
- [ ] **文件备份**：上传文件定期备份
- [ ] **配置备份**：配置文件版本控制
- [ ] **恢复测试**：定期进行恢复测试（建议每月一次）
- [ ] **备份验证**：备份文件完整性已验证
- [ ] **异地备份**：重要数据异地备份

## 运维检查清单

### 日常检查（每日）

- [ ] **服务状态**：所有服务正常运行
- [ ] **系统资源**：CPU、内存、磁盘使用率正常
- [ ] **错误日志**：无新增严重错误
- [ ] **备份状态**：昨夜备份成功完成
- [ ] **安全告警**：无新增安全告警

### 每周检查

- [ ] **性能趋势**：性能指标无明显下降
- [ ] **错误趋势**：错误率无明显上升
- [ ] **用户反馈**：收集并处理用户反馈
- [ ] **安全更新**：检查并应用安全补丁
- [ ] **日志审查**：审查异常日志

### 每月检查

- [ ] **恢复测试**：执行一次完整的恢复测试
- [ ] **容量规划**：评估资源使用趋势，规划扩容
- [ ] **安全审计**：执行一次完整的安全审计
- [ ] **性能优化**：识别并优化性能瓶颈
- [ ] **文档更新**：更新运维文档和 runbook

## 紧急回滚清单

### 回滚触发条件

- [ ] **严重故障**：系统无法正常提供服务
- [ ] **数据损坏**：数据库数据出现损坏
- [ ] **安全漏洞**：发现严重安全漏洞
- [ ] **性能严重下降**：性能下降超过 50%

### 回滚步骤

- [ ] **通知相关人员**：通知运维、开发、业务人员
- [ ] **停止服务**：优雅停止当前服务
- [ ] **恢复数据库**：从最近的备份恢复数据库
- [ ] **回滚代码**：切换到上一个稳定版本
- [ ] **重启服务**：启动回滚后的服务
- [ ] **验证功能**：验证核心功能正常
- [ ] **通知用户**：通知用户服务已恢复
