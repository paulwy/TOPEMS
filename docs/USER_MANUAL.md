## 1. 系统简介

### 1.1 什么是 TOPEMS

TOPEMS（化工新材料企业数字化平台）是一款面向高科技添加剂、精细化工、新材料研发生产型企业的全业务数字化管理平台。

### 1.2 系统功能模块

TOPEMS 包含以下核心功能模块：

| 模块 | 说明 |
|------|------|
| 研发管理（RS） | 科研项目管理、试验记录管理 |
| 实验室管理（LIMS） | 样品管理、检验流程管理 |
| 质量管理（QMS） | 质量标准、质量检查、问题跟踪 |
| 环境健康安全（EHS） | 安全隐患、安全检查、应急预案 |
| 供应商管理（SRM） | 供应商信息、评估、采购订单 |
| 生产管理（PDM） | 生产工艺、配方、批次管理 |
| 工作流（FLOW） | 审批流程管理 |
| 报表（Report） | 数据报表和导出 |
| 通知（Notification） | 消息通知系统 |

### 1.3 技术架构

- **前端**: React 18 + TypeScript + Vite + Tailwind CSS
- **后端**: Rust + Axum + SQLx
- **数据库**: PostgreSQL 16 + Redis 7
- **AI**: Ollama + qwen2.5:7b-instruct

## 3. 登录和账户管理

### 3.1 用户登录

1. 访问登录页面
2. 输入用户名和密码
3. 点击"登录"按钮
4. 首次登录后建议修改密码

### 3.2 账户设置

1. 点击右上角用户名
2. 选择"账户设置"
3. 可修改以下信息：
   - 个人信息（姓名、邮箱）
   - 修改密码
   - 通知偏好设置

### 3.3 权限说明

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| 管理员 | 系统管理员 | 全部功能 |
| 部门经理 | 部门管理者 | 本部门数据 |
| 工程师 | 普通用户 | 基本功能 |
| 访客 | 访客用户 | 只读功能 |

## 4. 仪表盘使用

### 4.1 统计卡片

仪表盘顶部显示关键统计数据：

- **项目总数**: 当前系统中所有项目的数量
- **进行中**: 当前正在进行中的项目/任务数量
- **待审批**: 当前用户需要审批的任务数量
- **告警数**: 系统当前的告警数量

### 4.2 快捷操作

提供常用功能的快捷入口：

- 新建项目
- 创建样品
- 发起审批
- 查看报表

### 4.3 最近动态

显示系统最近的业务动态，包括：
- 项目更新
- 审批通知
- 告警信息

### 4.4 服务状态

显示各个微服务的运行状态：
- 绿色：正常运行
- 黄色：部分异常
- 红色：服务不可用

## 5. 模块导航

### 5.1 研发管理系统（RS）

**功能入口**: 点击顶部菜单"RS"或"研发管理"

**主要功能**:
- 项目管理：创建、编辑、删除研发项目
- 试验记录：记录和管理各类试验数据
- 项目进度：跟踪项目执行情况

**适用角色**: 研发人员、项目经理

### 5.2 实验室管理系统（LIMS）

**功能入口**: 点击顶部菜单"LIMS"或"实验室"

**主要功能**:
- 样品管理：样品接收、登记、跟踪
- 检验流程：定义和管理检验流程
- 检验任务：创建和执行检验任务
- 检验记录：记录检验结果

**适用角色**: 实验室技术人员、质量人员

### 5.3 质量管理系统（QMS）

**功能入口**: 点击顶部菜单"QMS"或"质量"

**主要功能**:
- 质量标准：维护质量标准文件
- 质量检查：执行各类质量检查
- 质量问题：跟踪和解决质量问题
- 质量改进：管理质量改进建议

**适用角色**: 质量管理人员、质检员

### 5.4 环境健康安全系统（EHS）

**功能入口**: 点击顶部菜单"EHS"或"安全"

**主要功能**:
- 安全隐患：记录和管理安全隐患
- 安全检查：执行安全检查
- 应急预案：管理和维护应急预案
- 演练记录：记录应急演练情况

**适用角色**: 安全管理员、安全员

### 5.5 供应商管理系统（SRM）

**功能入口**: 点击顶部菜单"SRM"或"供应商"

**主要功能**:
- 供应商管理：维护供应商信息
- 供应商评估：对供应商进行评估
- 采购订单：管理采购订单

**适用角色**: 采购人员、采购经理

### 5.6 生产管理系统（PDM）

**功能入口**: 点击顶部菜单"PDM"或"生产"

**主要功能**:
- 生产工艺：定义生产工艺流程
- 生产配方：管理生产配方
- 生产批次：跟踪生产批次
- 生产统计：查看生产统计数据

**适用角色**: 生产管理人员、操作员

### 5.7 工作流审批

**功能入口**: 点击顶部菜单"审批"或"流程"

**主要功能**:
- 待我审批：查看待审批任务
- 我已审批：查看已审批任务
- 发起审批：发起新的审批流程

**适用角色**: 所有需要审批的用户

### 5.8 报表中心

**功能入口**: 点击顶部菜单"报表"

**主要功能**:
- 报表生成：创建各类业务报表
- 报表导出：导出为 Excel、PDF、CSV 格式
- 模板管理：管理报表模板

**适用角色**: 管理人员、数据分析师

### 5.9 通知中心

**功能入口**: 点击右上角铃铛图标

**通知类型**:
- 系统通知：系统维护、更新等
- 工作流通知：审批任务、审批结果
- 告警通知：设备告警、质量告警
- 提醒通知：待办提醒、截止日期

## 6. 常见操作指南

### 6.1 如何创建项目

1. 进入研发管理模块
2. 点击"新建项目"按钮
3. 填写项目信息：
   - 项目名称
   - 项目描述
   - 项目状态
4. 点击"保存"

### 6.2 如何发起审批

1. 进入工作流模块
2. 选择需要使用的审批模板
3. 填写审批信息：
   - 审批标题
   - 审批内容
   - 相关附件
4. 选择审批人
5. 提交审批

### 6.3 如何生成报表

1. 进入报表中心
2. 选择报表类型
3. 设置筛选条件：
   - 日期范围
   - 项目/类别
4. 点击"生成报表"
5. 查看报表数据
6. 可选择导出格式（Excel/PDF/CSV）

### 6.4 如何处理告警

1. 收到告警通知
2. 点击通知查看详情
3. 根据告警类型采取相应措施
4. 在系统中记录处理结果

## 8. 常见问题

### 8.1 登录问题

**Q: 忘记密码怎么办？**
A: 联系系统管理员重置密码。

**Q: 登录后提示无权限？**
A: 联系管理员分配相应权限。

### 8.2 数据问题

**Q: 数据保存失败？**
A: 检查网络连接，或联系技术支持。

**Q: 如何导出数据？**
A: 使用报表中心或列表页的导出功能。

### 8.3 审批问题

**Q: 审批被拒绝后可以重新提交吗？**
A: 可以，根据审批意见修改后重新发起。

**Q: 可以委托他人代为审批吗？**
A: 可以，使用审批转交功能。
