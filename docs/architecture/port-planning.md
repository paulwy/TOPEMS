## 1. 规划背景

### 1.1 现状分析

当前 TOPEMS 平台服务端口配置存在以下问题：

| 问题类型 | 具体表现 | 影响 |
|---------|---------|------|
| 端口分配无序 | 服务端口分散在 8000-8056 之间，缺乏逻辑分组 | 难以记忆和管理 |
| 配置分散 | 端口配置分散在多个脚本和代码文件中 | 维护困难，易出错 |
| 扩展空间不足 | 未预留未来服务扩展端口 | 限制平台发展 |
| 缺乏文档 | 端口分配规则未正式文档化 | 新成员上手困难 |

### 1.2 规划目标

1. **标准化**: 建立统一的端口分配规则和命名规范
2. **模块化**: 按业务领域分组，便于管理和定位
3. **可扩展**: 为未来新增服务预留充足空间
4. **可维护**: 集中配置管理，降低维护成本
5. **可追溯**: 完整文档记录，便于迭代和审计

## 3. 配置管理

### 3.1 配置文件结构

```
config/
├── ports.env          # 端口配置文件（主文件）
└── ports.example.env  # 端口配置示例文件
```

### 3.2 配置文件格式

所有端口通过环境变量管理，格式如下：

```bash
# 核心服务
IAM_PORT=8000
NOTIFICATION_PORT=8004
PORTAL_PORT=8005
FLOW_PORT=8006
INTEGRATION_PORT=8007

# ERP服务
ERP_PORT=8010
HRM_PORT=8012
CRM_PORT=8013

# PLM服务
RS_PORT=8020
DOC_PORT=8028
LIMS_PORT=8022
PDM_PORT=8023

# MES服务
MES_PORT=8030
QMS_PORT=8031
EHS_PORT=8032

# SCM服务
SCM_PORT=8040
SRM_PORT=8041
WMS_PORT=8042

# 基础设施服务
FILE_PORT=8050
MAIL_PORT=8051
IM_PORT=8052
GIS_PORT=8053

# 数据分析服务
BI_PORT=8060
REPORT_PORT=8061
AI_PORT=8062

# 预留扩展服务
MOBILE_PORT=8070
```

### 3.3 配置加载优先级

1. 环境变量（运行时传入）
2. `config/ports.env` 文件
3. 脚本内置默认值

## 6. 回滚方案

### 6.1 回滚步骤

1. **停止所有服务**
   ```bash
   bash scripts/topems.sh stop
   ```

2. **恢复旧配置**
   ```bash
   cp config/ports.env.backup config/ports.env
   ```

3. **恢复服务代码中的旧端口默认值**

4. **重启服务**
   ```bash
   bash scripts/topems.sh start-all
   ```

### 6.2 回滚条件

当出现以下情况时执行回滚：

| 条件 | 说明 |
|------|------|
| 服务启动失败 | 超过 3 个服务无法启动 |
| 服务间通信失败 | 核心业务流程中断 |
| 测试不通过 | 集成测试失败率超过 10% |
| 性能问题 | 响应时间超过 SLA 标准 |
