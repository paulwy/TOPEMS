## 1. 系统概述

TOPEMS 是面向化工新材料企业的全业务数字化平台，采用微服务架构，提供研发管理、实验室信息管理、质量管理、安全环保等核心业务能力。

### 1.1 核心价值

- **研发数字化**: 从配方研发到产品上市的全流程管理
- **质量合规**: 符合行业法规要求的质量管控体系
- **数据驱动**: 基于AI的智能分析与决策支持
- **敏捷协作**: 跨部门协同与移动办公能力

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 单一职责 | 每个服务只负责一个业务领域 |
| 松耦合 | 服务间通过API通信，避免强依赖 |
| 高可用 | 支持故障转移和弹性伸缩 |
| 可观测 | 完善的日志、监控和追踪体系 |
| 安全优先 | 认证授权贯穿所有服务 |

## 3. 服务架构设计

### 3.1 平台服务

#### 3.1.1 IAM 服务 (topems-iam)

**职责**: 统一身份认证、权限管理、单点登录

**核心功能**:
- 用户管理（创建、查询、更新、删除）
- 角色管理（角色定义、权限分配）
- 权限管理（菜单权限、数据权限）
- 认证服务（登录、登出、Token刷新）
- 审计日志

**数据库 Schema**: `iam`

**关键表**:
| 表名 | 说明 |
|------|------|
| iam.users | 用户信息 |
| iam.roles | 角色定义 |
| iam.permissions | 权限定义 |
| iam.role_permissions | 角色权限映射 |
| iam.user_roles | 用户角色映射 |
| iam.audit_logs | 审计日志 |

#### 3.1.2 工作流服务 (topems-flow)

## 5. API 架构设计

### 5.1 API 设计原则

| 原则 | 说明 |
|------|------|
| RESTful | 遵循REST规范 |
| 版本化 | API版本管理 |
| 统一响应 | 统一的响应格式 |
| 错误处理 | 统一的错误码 |
| 认证授权 | JWT Token |

### 5.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1717056000
}
```

### 5.3 错误码规范

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

### 5.4 API 网关配置

```yaml
routes:
  - path: /api/iam/*
    service: topems-iam:8002
  - path: /api/flow/*
    service: topems-flow:8004
  - path: /api/doc/*
    service: topems-doc:8001
  - path: /api/ai/*
    service: topems-ai:8003
  - path: /api/rs/*
    service: topems-rs:8005
  - path: /api/lims/*
    service: topems-lims:8006
```

## 6. 安全架构设计

### 6.1 认证授权

```text
┌─────────────────────────────────────────────────────┐
│                    OAuth 2.0 / JWT                 │
├─────────────────────────────────────────────────────┤
│  登录 → 获取Token → 请求API → 验证Token → 授权检查  │
└─────────────────────────────────────────────────────┘
```

### 6.2 权限模型

**RBAC + 数据权限**:
- **角色权限**: 基于角色的菜单/功能权限
- **数据权限**: 基于部门/项目的数据访问范围

### 6.3 安全措施

| 措施 | 说明 |
|------|------|
| API网关 | 统一入口，安全防护 |
| mTLS | 服务间加密通信 |
| 审计日志 | 完整操作记录 |
| 输入校验 | 参数验证和过滤 |
| 速率限制 | 防止API滥用 |

## 7. 部署架构设计

### 7.1 开发环境

```yaml
version: '3.8'
services:
  postgres:
    image: postgres:16
    ports:
      - "5433:5432"
    environment:
      POSTGRES_PASSWORD: topems_secret
  
  redis:
    image: redis:7
    ports:
      - "6379:6379"
  
  # 平台服务
  iam:
    build: ./platform/topems-iam/backend
    ports:
      - "8002:8002"
    depends_on:
      - postgres
      - redis
  
  # 业务服务
  rs:
    build: ./services/topems-rs/backend
    ports:
      - "8005:8005"
    depends_on:
      - postgres
      - iam
```
