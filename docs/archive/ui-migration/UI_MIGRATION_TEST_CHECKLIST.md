# TOPEMS UI 重设计迁移 - 测试验证清单

> 用于系统地验证 Industrial OS 新布局的各个页面和功能。
> 使用方法：启用新布局后，按清单逐项验证，标记通过/失败。

## 前置条件

- [ ] 已启用新布局：`VITE_UI_V3_ENABLED=true`
- [ ] 开发服务器已启动：`cd apps/web && pnpm dev`
- [ ] 已登录系统，拥有管理员权限
- [ ] 测试数据库已准备，有测试数据
