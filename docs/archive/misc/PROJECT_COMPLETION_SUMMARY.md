## 一、项目概述

TOPEMS（Total Operations & Production Enterprise Management System）是一个面向制造业的全栈企业管理系统，集成了 ERP、MES、CRM、WMS、HRM、QMS、SCM 等业务模块，并通过 AI 智能中枢提供智能化的业务辅助能力。

### 1.1 核心特性

- **微服务架构**：基于 Rust + Axum 构建的高性能后端服务
- **AI 智能中枢**：集成大语言模型、Agent 编排、知识图谱、RAG 检索增强
- **业务 Copilot**：为 ERP、Finance、CRM、WMS、MES、HRM 等模块提供智能助手
- **AI 治理**：完整的 AI 治理仪表盘，包括合规监控、风险评估、成本分析
- **前端微应用**：基于 React + TypeScript 的模块化前端架构
- **MCP 适配层**：Model Context Protocol 标准适配，支持多模型接入

## 二、架构设计

### 2.1 四层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Layer 3: 业务赋能层                        │
│  ERP │ Finance │ CRM │ WMS │ MES │ HRM │ QMS │ SCM │ APS  │

├─────────────────────────────────────────────────────────────┤
│                    Layer 0: MCP 适配层                        │
│  模型适配 │ 工具注册 │ 上下文管理 │ 协议转换 │ 多模型支持      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 AI 治理架构

- **治理仪表盘**：实时监控 AI 使用情况、合规状态、风险预警
- **合规检查**：内容安全过滤、PII 脱敏、请求频率限制、数据保留策略
- **风险评估**：高/中/低风险分类，风险项追踪和处理
- **成本分析**：按模型、按时间、按业务模块的成本统计
- **性能监控**：响应时间、成功率、Token 消耗量

### 2.3 业务 Copilot 架构

- **会话管理**：多轮对话、会话历史、上下文维护
- **意图识别**：自然语言理解，实体提取，业务意图分类
- **模块路由**：根据意图自动路由到对应业务模块
- **动作执行**：创建订单、查询数据、生成报表等业务动作
- **FAQ 检索**：基于知识库的常见问题解答
