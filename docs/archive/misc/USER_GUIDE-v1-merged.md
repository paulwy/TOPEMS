## 1. 系统简介

TOPEMS（Total Operations & Production Enterprise Management System）是一个面向制造业的全栈企业管理系统，集成了 ERP、MES、CRM、WMS、HRM、QMS、SCM 等业务模块，并通过 AI 智能中枢提供智能化的业务辅助能力。

### 1.1 核心功能

- **业务管理**：ERP、MES、CRM、WMS、HRM、QMS、SCM、APS、EHS、OA、BI 等 12 个业务模块
- **AI 智能助手**：业务 Copilot，支持自然语言交互，自动识别业务意图
- **AI 治理**：实时监控 AI 使用情况、合规状态、风险预警
- **智能表单**：AI 辅助表单生成和填写
- **文档智能**：AI 文档解析、摘要、问答

### 1.2 系统要求

- **浏览器**：Chrome 90+、Firefox 88+、Safari 14+、Edge 90+
- **屏幕分辨率**：最低 1280x720，推荐 1920x1080
- **网络**：稳定的互联网连接

## 2. 快速开始

### 2.1 登录系统

1. 打开浏览器，访问系统地址（例如：`https://topems.yourcompany.com`）
2. 在登录页面输入用户名和密码
3. 点击「登录」按钮
4. 首次登录建议修改密码

### 2.2 系统首页

登录成功后，您将看到系统首页，包含以下区域：

- **顶部导航栏**：系统 Logo、模块菜单、用户信息、通知
- **左侧菜单栏**：各业务模块的快捷入口
- **主内容区**：当前模块的操作界面
- **底部状态栏**：系统状态、版本信息

### 2.3 切换业务模块

1. 点击顶部导航栏或左侧菜单栏的模块名称
2. 系统将切换到对应业务模块的操作界面
3. 常用模块可以添加到收藏，方便快速访问

### 2.4 修改个人信息

1. 点击右上角用户头像
2. 选择「个人设置」
3. 修改个人信息（姓名、邮箱、手机号等）
4. 点击「保存」按钮

## 3. AI 智能助手使用

### 3.1 打开 AI 助手

1. 在系统任意页面，点击右下角的 AI 助手图标
2. 或使用快捷键 `Ctrl+Shift+A`（Mac：`Cmd+Shift+A`）
3. AI 助手面板将从右侧滑出

### 3.2 与 AI 助手对话

1. 在输入框中输入您的问题或需求
2. 按 `Enter` 键发送消息
3. AI 助手将分析您的意图，并给出相应的回答或操作建议
4. 您可以继续追问，AI 助手会保持上下文记忆

### 3.3 业务意图识别

AI 助手可以自动识别以下业务意图：

| 业务模块 | 支持的意图 |
|---------|-----------|
| ERP | 创建采购订单、查询库存、生成财务报表 |
| CRM | 创建客户、查询商机、管理合同 |
| WMS | 入库操作、出库操作、库存盘点 |
| MES | 创建生产订单、工序管理、质量检验 |
| HRM | 员工管理、考勤查询、薪资计算 |
| QMS | 质量检验、不合格品处理、质量分析 |
| SCM | 供应商管理、采购协同、物流跟踪 |
| APS | 生产计划、工序排程、资源优化 |
| EHS | 安全检查、事故管理、环保合规 |
| OA | 流程审批、文档管理、会议管理 |
| BI | 报表生成、仪表盘创建、数据分析 |

### 3.4 使用建议

- **描述清晰**：尽量用自然语言描述您的需求，包含关键信息
- **提供上下文**：如果涉及特定数据，请提供相关的编号或名称
- **逐步细化**：如果 AI 助手的回答不够精确，可以继续追问细化
- **确认操作**：AI 助手建议的操作，请确认后再执行

## 4. 业务模块操作

### 4.1 ERP 企业资源计划

#### 4.1.1 创建采购订单

1. 进入「ERP」模块，选择「采购管理」
2. 点击「创建采购订单」按钮
3. 填写采购订单信息：
   - 供应商名称
   - 采购物品列表（物品名称、数量、单价）
   - 交货日期
   - 付款方式
4. 点击「提交」按钮
5. 系统将自动提交审批流程

#### 4.1.2 查询库存

1. 进入「ERP」模块，选择「库存管理」
2. 在搜索框中输入物品名称或编号
3. 点击「查询」按钮
4. 系统将显示匹配的库存信息

### 4.2 CRM 客户关系管理

#### 4.2.1 创建客户

1. 进入「CRM」模块，选择「客户管理」
2. 点击「创建客户」按钮
3. 填写客户信息：
   - 客户名称
   - 联系人
   - 联系电话
   - 邮箱
   - 客户等级
4. 点击「保存」按钮

#### 4.2.2 管理商机

1. 进入「CRM」模块，选择「商机管理」
2. 查看商机列表，点击商机名称查看详情
3. 可以更新商机阶段、添加跟进记录
4. 商机成交后，可以转换为销售订单

### 4.3 WMS 仓储管理

#### 4.3.1 入库操作

1. 进入「WMS」模块，选择「入库管理」
2. 点击「创建入库单」按钮
3. 填写入库信息：
   - 入库类型（采购入库、退货入库等）
   - 物品列表（物品名称、数量、库位）
   - 关联单据号
4. 点击「提交」按钮
5. 仓库管理员确认后，入库完成

#### 4.3.2 出库操作

1. 进入「WMS」模块，选择「出库管理」
2. 点击「创建出库单」按钮
3. 填写出库信息：
   - 出库类型（销售出库、领料出库等）
   - 物品列表（物品名称、数量、库位）
   - 收货方信息
4. 点击「提交」按钮
5. 仓库管理员确认后，出库完成

### 4.4 MES 制造执行

#### 4.4.1 创建生产订单

1. 进入「MES」模块，选择「生产管理」
2. 点击「创建生产订单」按钮
3. 填写生产订单信息：
   - 产品名称
   - 生产数量
   - 计划开始时间
   - 计划完成时间
   - 生产车间
4. 点击「提交」按钮
5. 系统将自动进行产能校验和排程

#### 4.4.2 工序管理

1. 进入「MES」模块，选择「工序管理」
2. 查看工序列表，点击工序名称查看详情
3. 可以更新工序状态（待开始、进行中、已完成）
4. 记录工序实际开始时间、完成时间、产量

### 4.5 HRM 人力资源

#### 4.5.1 员工管理

1. 进入「HRM」模块，选择「员工管理」
2. 点击「添加员工」按钮
3. 填写员工信息：
   - 姓名、工号、部门、职位
   - 入职日期、联系方式
   - 薪资信息
4. 点击「保存」按钮

#### 4.5.2 考勤查询

1. 进入「HRM」模块，选择「考勤管理」
2. 选择查询时间段
3. 点击「查询」按钮
4. 系统将显示考勤记录（出勤、迟到、早退、请假等）

## 5. AI 治理仪表盘

### 5.1 查看治理仪表盘

1. 进入「AI 治理」模块
2. 系统将显示治理仪表盘，包含以下信息：
   - **治理评分**：综合评分（0-100分）
   - **治理等级**：较差、一般、良好、优秀
   - **总请求数**：AI 服务总调用次数
   - **总 Token 数**：AI 服务消耗的 Token 总数
   - **总成本**：AI 服务消耗的总费用
   - **平均响应时间**：AI 服务平均响应时间
   - **合规率**：AI 请求合规比例
   - **风险数**：当前存在的风险项数量
   - **活跃模型数**：当前使用的 AI 模型数量

### 5.2 查看风险评估

1. 在治理仪表盘中，点击「风险评估」标签
2. 查看风险项列表，包含：
   - 风险类型（内容安全、数据隐私、模型滥用等）
   - 风险严重程度（低、中、高、严重）
   - 风险描述
   - 发生次数
   - 处理状态（待处理、监控中、已解决、已关闭）
3. 点击风险项可以查看详情和处理建议

### 5.3 查看合规状态

1. 在治理仪表盘中，点击「合规状态」标签
2. 查看合规检查项列表，包含：
   - 检查项名称（内容安全过滤、PII 脱敏、请求频率限制、数据保留策略等）
   - 通过次数
   - 失败次数
   - 合规率
3. 点击检查项可以查看详细的合规报告

### 5.4 查看成本分析

1. 在治理仪表盘中，点击「成本分析」标签
2. 查看成本统计信息，包含：
   - 总成本
   - 按模型统计的成本
   - 按时间统计的成本趋势
   - 按业务模块统计的成本分布
3. 可以选择时间范围查看不同时期的成本

## 6. 常见问题

### 6.1 登录相关

**Q: 忘记密码怎么办？**
A: 点击登录页面的「忘记密码」链接，输入注册邮箱，系统将发送密码重置链接到您的邮箱。

**Q: 账号被锁定怎么办？**
A: 连续多次输入错误密码会导致账号锁定，请等待 30 分钟后重试，或联系系统管理员解锁。

### 6.2 AI 助手相关

**Q: AI 助手没有响应怎么办？**
A: 请检查网络连接，刷新页面后重试。如果问题持续，请联系系统管理员。

**Q: AI 助手的回答不准确怎么办？**
A: 您可以尝试更详细地描述您的需求，提供更多上下文信息。如果问题持续，可以反馈给系统管理员。

**Q: AI 助手会保存我的对话记录吗？**
A: 是的，AI 助手会保存对话记录用于上下文记忆和质量改进。您可以在「个人设置」中清除对话历史。

### 6.3 业务操作相关

**Q: 提交的单据如何撤回？**
A: 在单据详情页面，如果单据状态为「待审批」，可以点击「撤回」按钮撤回。如果已经审批通过，需要联系审批人驳回。

**Q: 如何导出数据？**
A: 在列表页面，点击「导出」按钮，可以选择导出格式（Excel、CSV）和导出范围。

**Q: 如何设置数据权限？**
A: 数据权限由系统管理员统一设置，普通用户无法自行修改。如有需要，请联系系统管理员。

### 6.4 系统性能相关

**Q: 系统响应慢怎么办？**
A: 请检查网络连接，清除浏览器缓存后重试。如果问题持续，请联系系统管理员。

**Q: 页面加载不完整怎么办？**
A: 请刷新页面，或尝试使用其他浏览器。如果问题持续，请联系系统管理员。
