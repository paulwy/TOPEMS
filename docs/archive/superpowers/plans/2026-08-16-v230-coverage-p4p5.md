### 2.2 优先测试函数类型（纯函数优先，最多 coverage 增长 / test）

| 类型 | 典型来源 | 建议模式 |
|:-----|:---------|:---------|
| **SerDe roundtrip** | `models/*.rs` 下 `Customer / CustomerContact / Opportunity / Contract / Quote / Invoice / Lead / Campaign / Case / Note / Activity` + `CreateXxxRequest / UpdateXxxRequest / XxxQueryParams / XxxExport / BatchXxxRequest` | `#[test] fn test_xxx_serde_roundtrip_full()` + `_minimal()`：struct 初始化 → `serde_json::to_string(&s).unwrap()` → `from_str` → `to_value` 比较 |
| **Params 反序列化** | `modules/*.rs` 下 `CustomerPaginationParams / OpportunityQueryParams` 等 `#[derive(Deserialize)]` 结构体 | `{} → all None` · `{all fields filled} → all Some` · `{partial} → 混合` · `invalid-UUID → Err` |
| **Route 工厂** | `pub fn create_routes() -> Router<AppState>` 或 `pub fn create_routes(state: AppState)` 等 | `#[test] fn test_create_routes_runs()` → 调用并断言 Router 类型可构造（类型级，不需要 DB） |
| **领域纯函数** | `modules/opportunity.rs` / `modules/contract.rs` 下 score / calculate / validate / format 类函数 | 构造输入 → 断言相等 |
