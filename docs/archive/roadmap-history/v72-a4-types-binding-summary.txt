[2/7] A4-1 统一类型绑定工具（api-binding-tools.ts）
----------------------------------------------------------------
位置: packages/shared-types/src/api-binding-tools.ts
- Type Extract Helpers:
  · OpenApiQueryParams<OpId>     - 提取 operations[OpId].parameters.query
  · OpenApiRequestBody<OpId>     - 提取 operations[OpId].requestBody.content
  · OpenApiResponseSchema<OpId>  - 提取 operations[OpId].responses.200
- Adaptation Wrappers:
  · AdaptedQuery<OpId>           - OpenApiQueryParams → Adapt<T>（编译期蛇→驼）
  · AdaptedRequestBody<OpId>     - OpenApiRequestBody → Adapt<T>
  · TypedApiResponse<T, OpId>    - SharedApiResponse<T>（强制 success/code/message 为 required）
  · TypedPaginatedResponse<T>    - SharedApiResponse<PaginatedResponse<T>>
- Runtime Helpers:
  · toOpenApiParams(camelObj)    - camelCase → snake_case（查询参数）
  · toOpenApiRequestBody(camelObj) - camelCase → snake_case（请求体）
依赖: openapi-adapter.ts (FIELD_MAPPING 130+ 条 + SEMANTIC_MAPPING)
