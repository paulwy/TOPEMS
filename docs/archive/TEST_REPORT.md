## 改进建议

### 1. 启动所有微服务
```bash
bash scripts/topems.sh start
```

### 2. 环境变量配置
确保设置以下环境变量:
```bash
export DATABASE_URL="postgres://topems:topems_secret@localhost:5432/topems"
export JWT_SECRET="topems_super_secret_jwt_key_for_development_only_change_in_production"
```

### 3. 修复测试配置
- 为集成测试添加 mock 服务
- 使用测试数据库而非生产数据库
- 添加服务依赖的健康检查
