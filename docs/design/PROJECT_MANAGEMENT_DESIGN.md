## 1. 概述

### 1.1 设计目标

本模块旨在将TOPEMS系统中分散的项目管理相关功能整合为一个**统一、高效、以项目为中心**的管理平台。

**核心目标**:
1. **突出项目管理** - 所有业务活动围绕项目展开，项目作为核心数据实体
2. **减少重复输入** - 数据自动从各服务聚合，避免重复录入
3. **动态展示进度** - 实时甘特图和仪表盘，直观展示项目状态
4. **效益分析** - 挣值分析、ROI等绩效指标
5. **工作流驱动** - 自动化审批流程，提升协作效率

## 2. 系统架构

### 2.1 整体架构

| 层级 | 服务 | 说明 |
|------|------|------|
| **核心层** | topems-pm | 项目管理核心服务 |

│   └── templates         # 合同模板

│   ├── budgets           # 预算主表
│   ├── budget_items      # 预算项
│   └── budget_versions   # 预算版本
├── 风险管理 (Risk)
│   ├── project_risks     # 风险登记
│   └── risk_events       # 风险事件
├── 质量管理 (Quality)
│   ├── quality_checks    # 质量检查
│   └── defects           # 缺陷管理

│   ├── acceptance_plans  # 验收计划
│   ├── acceptance_items  # 验收项
│   └── acceptance_records# 验收记录

│   ├── settlements       # 决算主表
│   ├── settlement_items  # 决算项

│   ├── project_documents # 项目文档

## 4. 项目作为核心模块的设计

### 4.1 核心设计原则

1. **项目作为根实体**: 所有业务数据都与项目关联
2. **数据聚合**: 从各模块自动聚合数据到项目视图
3. **统一入口**: 项目作为所有操作的起点
4. **生命周期管理**: 完整的项目生命周期跟踪

### 4.2 项目生命周期

```
立项申请 → 项目审批 → 项目启动 → 执行阶段 → 验收交付 → 决算归档
   ↓           ↓          ↓          ↓          ↓          ↓
 合同创建    预算编制   资源分配   进度跟踪   质量检查   效益分析
```

### 4.3 核心模块关联关系

```
项目(Project)
    │
    ├── 1:N ──► 阶段(Phase) ──► N:1 ──► 验收计划(AcceptancePlan)
    │
    ├── 1:N ──► 里程碑(Milestone) ──► N:1 ──► 合同里程碑(ContractMilestone)
    │
    ├── 1:N ──► 合同(Contract) ──► N:1 ──► 付款计划(PaymentSchedule)
    │
    ├── 1:N ──► 预算(Budget) ──► N:1 ──► 预算项(BudgetItem)
    │
    ├── 1:N ──► 风险(ProjectRisk) ──► N:1 ──► 风险事件(RiskEvent)
    │
    ├── 1:N ──► 质量检查(QualityCheck) ──► N:1 ──► 缺陷(Defect)
    │
    ├── 1:N ──► 验收记录(AcceptanceRecord)
    │
    ├── 1:N ──► 决算(Settlement)
    │
    ├── 1:N ──► 文档(ProjectDocument)
    │
    └── 1:N ──► 报告(ProjectReport)
```

## 5. 模块关联设计

### 5.1 模块关联矩阵

| 模块 | 与项目的关系 | 数据流向 | 说明 |
|------|-------------|----------|------|
| 合同管理 | 1:N | 项目→合同 | 一个项目可关联多个合同 |
| 预算管理 | 1:N | 项目→预算 | 项目预算编制与控制 |
| 风险管理 | 1:N | 项目→风险 | 项目风险识别与预警 |
| 质量管理 | 1:N | 项目→质检 | 质量检查与缺陷跟踪 |
| 验收管理 | 1:N | 项目→验收 | 阶段验收与最终交付 |
| 决算管理 | 1:N | 项目→决算 | 决算编制与差异分析 |
| 文档管理 | 1:N | 项目→文档 | 项目文档版本控制 |
| 报告管理 | 1:N | 项目→报告 | 自动生成项目报告 |
| 通知管理 | 1:N | 项目→通知 | 项目相关提醒通知 |

### 5.2 数据聚合流程

```
项目详情页数据聚合
├── 基本信息 ──────► 项目主表
├── 进度概览 ──────► 阶段+里程碑
├── 合同信息 ──────► 合同模块
├── 预算执行 ──────► 预算模块
├── 风险状态 ──────► 风险模块
├── 质量情况 ──────► 质量模块
├── 验收进展 ──────► 验收模块
├── 决算情况 ──────► 决算模块
└── 相关文档 ──────► 文档模块
```
