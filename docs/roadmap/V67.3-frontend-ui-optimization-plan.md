## 5. 经验教训

1. **草稿方案过期快**：Trae 内部 `.trae/documents/` 的方案仅代表撰写时点的判断，V67.x 架构迭代频繁，落地前必须 **重新审计+按真实状态调整**，否则会按不存在的 `mui/` 目录白忙。
2. **uniq -d 不能直接判定重复**：12 个同名冲突中 **5 个是合理分层**（templates/list/ 子目录、gis/modules/ 架构过渡态），真正死文件是 **stub 占位符** 和 **grep 零引用的 re-export 壳**。
3. **删除后跑 TSC 是最好的断链验证**：零引用是删除的必要非充分条件（`pages/gis/components/DataTable.tsx` 引用了 re-export 壳的间接链，TSC 是唯一可靠发现方式）。
4. **Tailwind 残留 grep 可以进 CI**：本次验证 0 残留，说明 V67.x sx 化彻底，可加入 pre-push hook 防止倒退。
