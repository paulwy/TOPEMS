## 一、背景与问题分析

### 1.1 问题概述

基于全面架构分析，TOPEMS 系统存在以下五大类问题：

| 类别 | 问题描述 | 严重程度 |
|------|---------|---------|
| **类型系统** | `ApiResponse` 存在 9 处定义，`PaginatedResponse` 存在 14 处定义，结构不一致 | 🔴 严重 |
| **数据获取** | 三种范式共存（useState/useEffect、React Query、shared-hooks） | 🟡 中等 |
| **状态管理** | `useAppStore` 每次渲染创建新对象，导致过度重渲染 | 🟡 中等 |
| **路由性能** | `DynamicRoutes` 每次路径变更重新加载配置 | 🟡 中等 |
| **后端服务** | Analytics 服务为空壳，SRM 后端不完整 | 🟡 中等 |
| **UI 优化** | 组件分散、主题不统一、响应式不足 | 🟢 低 |

### 2.4 Phase 3：useAppStore 性能优化（P0）

#### 目标
修复 `useAppStore` 每次渲染创建新对象的问题，减少过度重渲染。

#### 实施步骤

**Step 1：分析当前实现**

查看 [store/index.ts](../../apps/web/src/store/index.ts#L209) 中的 `useAppStore` 实现：

```typescript
const useAppStore = () => {
  const appState: AppState = { ... }; // 问题：每次渲染创建新对象
  return appState;
};
```

**Step 2：实现 memoized 版本**

使用 `useMemo` 缓存状态对象，仅在依赖变化时重新计算：

```typescript
const useAppStore = () => {
  const auth = useAuthStore();
  const theme = useThemeStore();
  const notifications = useNotificationStore();
  const ui = useUiStore();
  const shortcuts = useShortcutsStore();
  const workflow = useWorkflowStore();

  const appState = useMemo(() => ({
    auth,
    theme,
    notifications,
    ui,
    shortcuts,
    workflow,
  }), [auth, theme, notifications, ui, shortcuts, workflow]);

  return appState;
};
```

**Step 3：验证性能提升**

使用 React DevTools Profiler 验证：
- 状态对象引用稳定性
- 渲染次数减少

### 2.5 Phase 4：DynamicRoutes 缓存优化（P1）

#### 目标
添加路由配置缓存机制，避免每次路径变更重新加载配置。

#### 实施步骤

**Step 1：分析当前实现**

查看 [App.tsx](../../apps/web/src/App.tsx#L116) 中的 `DynamicRoutes`：

```typescript
useEffect(() => {
  const loadRoutes = async () => {
    const moduleConfig = await loadModuleConfig(moduleCode);
    // 每次路径变化都重新加载
  };
  loadRoutes();
}, [location.pathname]);
```

**Step 2：添加缓存机制**

```typescript
const routeConfigCache = new Map<string, ModuleConfig>();

const DynamicRoutes = () => {
  const { pathname } = useLocation();
  const moduleCode = extractModuleCode(pathname);

  const [routes, setRoutes] = useState<RouteConfig[]>([]);

  useEffect(() => {
    const loadRoutes = async () => {
      if (routeConfigCache.has(moduleCode)) {
        setRoutes(routeConfigCache.get(moduleCode)!.routes);
        return;
      }

      const moduleConfig = await loadModuleConfig(moduleCode);
      routeConfigCache.set(moduleCode, moduleConfig);
      setRoutes(moduleConfig.routes);
    };
    loadRoutes();
  }, [moduleCode]);

  return <Routes>{routes.map(...)</Routes>;
};
```

**Step 3：添加缓存失效机制**

```typescript
export const clearRouteConfigCache = (moduleCode?: string) => {
  if (moduleCode) {
    routeConfigCache.delete(moduleCode);
  } else {
    routeConfigCache.clear();
  }
};
```
