## 指标说明

- **unwrap()**: 直接调用 `unwrap()`，可能导致 panic，应使用 proper error handling
- **expect()**: 类似 unwrap，但带有自定义错误信息，同样可能导致 panic
- **todo!()**: 待实现的标记，说明功能尚未完成
- **unimplemented!()**: 未实现的标记，说明功能尚未完成
- **println! / eprintln!**: 直接打印到标准输出/错误，生产环境应使用 tracing/log 框架
- **.clone()**: 克隆调用，过多的 clone 可能暗示性能问题或所有权设计不佳
- **债务评分**: 综合衡量技术债务密度，每千行代码的加权问题数
