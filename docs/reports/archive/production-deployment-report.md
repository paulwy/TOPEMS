## 一、部署概述

### 1.1 部署目标

在生产环境中部署 TOPEMS 系统，验证系统在生产配置下的运行状态，确保系统功能完整、性能稳定、安全可靠。

- 后端服务：topems-unified-core（统一核心服务）

- 使用生产环境部署脚本：`scripts/deploy/production-deploy.sh`
- 使用生产环境启动脚本：`scripts/deploy/start-production.sh`

## 七、部署问题与解决

### 7.1 遇到的问题

| 问题 | 严重程度 | 解决方案 | 状态 |
|------|---------|---------|------|
| 前端 vite preview 被 SIGTERM 终止 | 中 | 使用 Python HTTP Server 替代 | ✅ 已解决 |
| 后端 nohup 进程在命令结束后被终止 | 中 | 使用 PID 文件管理和独立启动脚本 | ✅ 已解决 |
| macOS 没有 timeout 命令 | 低 | 使用 sleep + 后台进程方式 | ✅ 已解决 |
| /ready 端点返回 404 | 低 | 该端点可能未实现，不影响核心功能 | ⚠️ 待确认 |

### 7.2 改进建议

1. **前端服务**：生产环境建议使用 Nginx 托管静态文件，而非 Python HTTP Server
2. **HTTPS 配置**：生产环境应配置 HTTPS，使用 Nginx 反向代理
3. **进程管理**：生产环境建议使用 systemd（Linux）或 launchd（macOS）管理服务进程
4. **日志管理**：生产环境应配置日志轮转和集中日志收集
5. **监控告警**：生产环境应配置完整的监控告警体系
6. **备份策略**：生产环境应配置定期数据库备份和恢复演练
