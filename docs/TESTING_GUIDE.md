# TOPEMS 系统测试指南

生成时间: 2026-05-30

## 🎯 测试前的准备

### 1. 确认核心服务运行状态

```bash
cd ~/TOPEMS
lsof -i :8001 -i :8002 -i :8003 -i :8004 -i :8006 -i :8010 | grep LISTEN
```

**应该看到 6 个服务都在运行:**
- 8001: DOC (文档管理)
- 8002: IAM (身份认证)
- 8003: AI (AI服务)
- 8004: FLOW (工作流)
- 8006: LIMS (实验室管理)
- 8010: HRM (人力资源)

### 2. 启动前端开发服务器

```bash
cd ~/TOPEMS/frontend
npm run dev
```

前端应该运行在 `http://localhost:3000` (或其他可用端口)

### 3. 健康检查测试

```bash
# 测试所有服务
curl http://localhost:8002/health  # IAM
curl http://localhost:8001/health  # DOC
curl http://localhost:8003/health  # AI
curl http://localhost:8004/health  # FLOW
curl http://localhost:8006/health  # LIMS
curl http://localhost:8010/health  # HRM
```

### 1. 用户认证模块 (IAM) - 优先级: P1

#### 测试1: 用户登录
**步骤:**
1. 访问 http://localhost:3000/login
2. 输入用户名和密码
3. 点击登录按钮

**预期结果:**
- ✅ 登录成功，跳转到 Dashboard

- ✅ 右上角显示用户名
- ✅ 无 401 错误

#### 测试2: Token 自动刷新
**步骤:**
1. 登录后等待 50 分钟

**预期结果:**
