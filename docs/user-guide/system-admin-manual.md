# 系统管理手册

## 概述

本手册面向系统管理员，帮助您完成用户管理、权限配置、系统设置等管理工作。

**适用对象**: 系统管理员  
**前置条件**: 具有管理员权限的账户

---

## 1. 用户管理

### 1.1 用户列表

路径: 「系统管理」→「用户管理」

功能:
- 查看所有用户列表
- 按状态、部门、角色筛选
- 搜索用户

### 1.2 创建用户

1. 点击「新建用户」按钮
2. 填写用户信息:
   - **用户名**: 唯一标识
   - **邮箱**: 登录凭证
   - **手机号**: 联系方式
   - **部门**: 所属部门
   - **角色**: 分配系统角色
3. 点击「保存」

### 1.3 编辑用户

1. 在用户列表中点击「编辑」
2. 修改用户信息
3. 点击「保存」

### 1.4 重置密码

1. 选择目标用户
2. 点击「重置密码」
3. 设置新密码或发送重置邮件

### 1.5 禁用/启用用户

1. 选择目标用户
2. 点击「禁用」/「启用」按钮
3. 确认操作

### 1.6 用户状态

| 状态 | 说明 |
|------|------|
| 活跃 | 正常使用 |
| 禁用 | 账户被冻结，无法登录 |
| 待激活 | 账户已创建，等待激活邮件确认 |

## 2. 角色管理

### 2.1 角色列表

路径: 「系统管理」→「角色管理」

预置角色:
| 角色 | 描述 |
|------|------|
| 超级管理员 | 完全系统控制权 |
| 系统管理员 | 系统配置和用户管理 |
| 部门经理 | 部门数据管理 |
| HR管理员 | 人力资源模块管理 |
| 普通用户 | 基础功能使用 |

### 2.2 创建角色

1. 点击「新建角色」
2. 填写角色信息:
   - **角色名称**: 唯一标识
   - **角色描述**: 说明用途
3. 分配权限（勾选）
4. 点击「保存」

### 2.3 权限配置

权限类型:
- **功能权限**: 可访问的菜单和功能
- **数据权限**: 可操作的数据范围（行级权限）
- **字段权限**: 可查看/编辑的字段

配置步骤:
1. 选择角色
2. 进入「权限配置」标签
3. 勾选需要的权限
4. 点击「保存」

### 2.4 权限标识参考

| 模块 | 权限标识 |
|------|----------|
| BI | `bi:read`, `bi:write`, `bi:delete`, `bi:admin` |
| MES | `mes:read`, `mes:write`, `mes:delete`, `mes:admin` |
| QMS | `qms:read`, `qms:write`, `qms:delete`, `qms:admin` |
| SCM | `scm:read`, `scm:write`, `scm:delete`, `scm:admin` |
| 系统管理 | `system:read`, `system:write`, `system:admin` |

## 3. 部门管理

### 3.1 部门列表

路径: 「系统管理」→「部门管理」

功能:
- 查看组织架构树
- 增删改部门
- 调整部门层级

### 3.2 创建部门

1. 在部门树中点击父部门（或根节点）
2. 点击「新建子部门」
3. 填写部门信息:
   - **部门名称**: 必填
   - **部门编码**: 系统自动生成
   - **负责人**: 选择员工
   - **上级部门**: 自动填充
4. 点击「保存」

### 3.3 调整部门结构

- **移动部门**: 拖拽部门到新位置
- **删除部门**: 先转移员工，再删除

## 4. 系统设置

### 4.1 基本设置

路径: 「系统管理」→「系统设置」→「基本设置」

配置项:
- 系统名称和Logo
- 公司信息
- 默认时区和语言

### 4.2 通知设置

路径: 「系统管理」→「系统设置」→「通知设置」

配置项:
- 邮件通知开关
- 短信通知开关
- 站内信通知开关
- 通知模板编辑

### 4.3 安全设置

路径: 「系统管理」→「系统设置」→「安全设置」

配置项:
- 密码策略（长度、复杂度、有效期）
- 登录限制（IP白名单、并发登录）
- 敏感操作二次验证
- 登录失败锁定策略（连续失败次数、锁定时间）

### 4.4 AI 设置

路径: 「系统管理」→「系统设置」→「AI 设置」

配置项:
- AI 模型选择（本地 Ollama / 云端模型）
- API Key 配置（云端模型）
- 生成参数调整（Temperature、最大长度）

### 4.5 审计日志

路径: 「系统管理」→「审计日志」

功能:
- 查看用户操作记录
- 按时间、用户、操作类型筛选
- 导出日志报表

---

## 5. 数据管理

### 5.1 数据备份

路径: 「系统管理」→「数据管理」→「备份」

功能:
- 手动创建备份
- 设置自动备份计划
- 查看备份历史
- 恢复数据

### 5.2 数据导入

支持格式: Excel (.xlsx/.xls)、CSV

导入步骤:
1. 点击「数据导入」
2. 下载导入模板
3. 填写数据
4. 上传文件
5. 预览数据
6. 确认导入

### 5.3 数据导出

1. 选择要导出的数据
2. 点击「导出」
3. 选择格式（Excel/CSV/PDF）
4. 下载文件

## 6. 模块管理

### 6.1 模块列表

路径: 「系统管理」→「模块管理」

显示所有系统模块及其状态

### 6.2 模块启用/停用

1. 选择目标模块
2. 点击「启用」/「停用」
3. 确认操作

### 6.3 模块配置

根据模块不同，可配置:
- 模块参数
- 流程配置
- 字段自定义

---

## 7. 常见任务

### 7.1 新员工入职配置

1. 在「用户管理」中创建用户账号
2. 在「角色管理」中分配适当角色
3. 在「部门管理」中将员工加入部门
4. 通知员工登录修改密码

### 7.2 权限调整

1. 在「角色管理」中找到目标角色
2. 修改权限配置
3. 保存设置

### 7.3 部门调整

1. 在「部门管理」中拖拽调整结构
2. 或通过编辑功能修改上级部门
3. 系统自动更新员工归属
