# 财务管理 (Finance) 模块

## 概述

Finance 模块管理企业财务核心业务，包括凭证管理、账簿报表、收付款和预算控制。

**功能路径**: 财务管理  
**服务端口**: 8011  
**权限标识**: `finance:read`, `finance:write`, `finance:delete`, `finance:admin`

---

## 1. 凭证管理

### 1.1 查看凭证列表

路径: 「财务管理」→「凭证管理」

显示: 凭证号、日期、摘要、借方金额、贷方金额、制单人、状态

### 1.2 新增凭证

1. 点击「新增凭证」
2. 填写:
   - **凭证日期**（默认当天）
   - **凭证字**: 记/收/付/转
   - **附件张数**
   - **摘要**（每行必填）
   - **科目**（从会计科目表选择）
   - **借方金额** 或 **贷方金额**（借贷平衡）
3. 点击「保存」或「保存并审核」

---

## 2. 收付款管理

### 2.1 收款单

路径: 「财务管理」→「收款管理」

登记客户回款、其他收入，支持关联 CRM 订单核销应收账款。

### 2.2 付款单

路径: 「财务管理」→「付款管理」

登记供应商付款、费用报销，支持关联 SRM 订单核销应付账款。

---

## 3. 会计报表

路径: 「财务管理」→「财务报表」

提供以下标准财务报表:
- 资产负债表
- 利润表（损益表）
- 现金流量表
- 科目余额表
- 明细账
- 总账

支持按会计期间、辅助核算项查询与导出 Excel。

---

## 4. 预算管理

路径: 「财务管理」→「预算管理」

按部门/项目/科目维度编制年度预算，执行中实时预警与控制。
