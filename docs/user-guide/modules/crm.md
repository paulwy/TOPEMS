# 客户关系管理 (CRM) 模块

## 概述

CRM 模块管理客户信息、商机和销售流程。

**功能路径**: 客户关系管理  
**服务端口**: 8029  
**权限标识**: `crm:read`, `crm:write`, `crm:delete`, `crm:admin`

---

## 1. 客户管理

### 1.1 查看客户列表

路径: 「客户关系管理」→「客户列表」

功能:
- 卡片式展示客户
- 按行业、区域、等级筛选
- 显示名称、联系人、电话、状态

### 1.2 新增客户

1. 点击「新增客户」
2. 填写:
   - **客户名称**（必填）
   - **客户编码**: 系统自动生成
   - **统一社会信用代码**
   - **联系人**
   - **联系电话**
   - **邮箱**
   - **地址**
   - **所属行业**
   - **客户等级**: A/B/C/D
3. 点击「保存」

### 1.3 编辑/删除客户

- **编辑**: 点击卡片「编辑」
- **删除**: 点击卡片「删除」→ 确认

### 1.4 客户跟进

1. 进入客户详情页
2. 点击「跟进记录」标签
3. 点击「添加跟进记录」
4. 填写:
   - **跟进日期**
   - **跟进方式**: 电话/邮件/拜访/会议
   - **跟进内容**
   - **下一步计划**
5. 点击「保存」

---

## 2. 商机管理

### 2.1 查看商机列表

路径: 「客户关系管理」→「商机管理」

显示: 商机名称、客户、金额、状态

### 2.2 创建商机

1. 点击「新建商机」
2. 填写:
   - **商机名称**（必填）
   - **关联客户**: 选择客户
   - **预计金额**
   - **成功率**: 百分比
   - **预计成交日期**
   - **负责人**
3. 点击「保存」

### 2.3 商机状态

| 状态 | 说明 |
|------|------|
| 初步接触 | 刚获取的商机线索 |
| 需求确认 | 确认客户需求 |
| 方案报价 | 提供解决方案和报价 |
| 商务谈判 | 协商合同条款 |
| 成交 | 签订合同 |
| 失败 | 商机未成 |

### 2.4 商机跟踪

- 在商机列表查看状态
- 点击查看详情和跟进记录
- 添加跟进记录推进商机

---

## 3. 销售统计

### 3.1 业绩统计

- 按人员统计销售额
- 按时间统计趋势
- 按客户等级分析

### 3.2 导出报表

1. 选择统计维度
2. 点击「导出」
3. 下载文件
