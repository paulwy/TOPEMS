# 供应链管理 (SCM) 模块

## 概述

SCM 模块管理采购流程、供应商关系和供应链协同，实现端到端供应链数字化管理。

**功能路径**: 供应链管理
**服务端口**: 8040
**权限标识**: `scm:read`, `scm:write`, `scm:delete`, `scm:admin`

---

## 1. 采购订单管理

### 1.1 查看采购订单

路径: 「供应链管理」→「采购订单」

显示: 订单编号、供应商、订单金额、状态、创建日期

支持筛选:
- 按状态筛选: 待审批 / 已审批 / 已下单 / 部分到货 / 已完成 / 已取消
- 按供应商筛选
- 按日期范围筛选

### 1.2 创建采购订单

1. 点击「新建采购订单」
2. 填写:
   - **订单编号**: 系统自动生成
   - **供应商**: 选择供应商
   - **采购类型**: 常规采购 / 紧急采购 / 零星采购
   - **交货日期**
   - **交货地点**
3. 添加采购物料:
   - 物料编码
   - 物料名称
   - 规格型号
   - 采购数量
   - 单价
   - 金额（自动计算）
4. 点击「保存」

### 1.3 采购订单审批

1. 选择待审批订单
2. 点击「审批」
3. 填写审批意见
4. 选择: 批准 / 驳回

### 1.4 采购订单状态流转

| 状态 | 说明 | 操作 |
|------|------|------|
| 待审批 | 订单已创建，等待审批 | 审批 / 编辑 / 删除 |
| 已审批 | 订单已通过审批 | 下单 / 修改 |
| 已下单 | 订单已发送给供应商 | 到货 / 取消 |
| 部分到货 | 部分物料已到货 | 到货 / 关闭 |
| 已完成 | 全部物料已到货 | - |
| 已取消 | 订单已取消 | - |

## 2. 采购物料管理

### 2.1 查看物料列表

路径: 「供应链管理」→「采购物料」

显示: 物料编码、名称、规格、单位、当前价格、供应商

### 2.2 添加采购物料

1. 点击「新增物料」
2. 填写:
   - **物料编码**（必填）
   - **物料名称**（必填）
   - **规格型号**
   - **计量单位**
   - **分类**
   - **品牌**
   - **默认供应商**
   - **参考价格**
3. 点击「保存」

---

## 3. 供应商管理

### 3.1 查看供应商列表

路径: 「供应链管理」→「供应商管理」

显示: 供应商名称、编码、类别、状态、评分

支持筛选:
- 按类别筛选
- 按状态筛选: 启用 / 禁用
- 按评分筛选

### 3.2 新增供应商

1. 点击「新增供应商」
2. 填写:
   - **供应商编码**: 系统自动生成
   - **供应商名称**（必填）
   - **统一社会信用代码**
   - **联系人**
   - **联系电话**
   - **邮箱**
   - **地址**
   - **所属行业**
   - **供应商类别**: 战略/核心/一般/备选
3. 点击「保存」

### 3.3 供应商详情

点击供应商卡片查看详情:
- 基本信息
- 评估记录
- 交易历史
- 付款记录

---

## 4. 供应商评估

### 4.1 创建评估

路径: 「供应链管理」→「供应商评估」→「新建评估」

1. 选择供应商
2. 选择评估周期
3. 填写评估指标:
   - 质量评分
   - 交货评分
   - 服务评分
   - 价格评分
4. 填写评估说明
5. 点击「保存」

### 4.2 评估结果

查看评估记录和评分趋势。

---

## 5. 采购比价

### 5.1 创建比价单

路径: 「供应链管理」→「采购比价」→「新建比价单」

1. 填写比价单信息:
   - 比价单号
   - 比价名称
   - 物料信息
   - 比价截止日期
2. 添加参与比价的供应商
3. 发布比价单

### 5.2 比价结果

查看各供应商报价，选择最优供应商。

---

## 6. 采购需求计划 (MRP)

### 6.1 MRP 计算

路径: 「供应链管理」→「MRP计划」→「运行MRP」

1. 设置计算参数:
   - 需求日期范围
   - 考虑安全库存
   - 考虑在途数量
2. 点击「计算」
3. 查看 MRP 结果

### 6.2 建议列表

系统生成采购建议:
- 物料编码
- 建议采购数量
- 建议供应商
- 建议下单日期

### 6.3 批量生成采购订单

从 MRP 建议批量生成采购订单。

---

## 7. 采购到货检验

### 7.1 创建到货通知单

路径: 「供应链管理」→「到货管理」→「到货通知」

1. 关联采购订单
2. 填写到货信息:
   - 到货日期
   - 运输方式
   - 承运人
3. 点击「保存」

### 7.2 到货检验

1. 选择到货通知
2. 点击「检验」
3. 填写检验结果:
   - 检验数量
   - 合格数量
   - 不合格数量
   - 检验结论
4. 合格: 入库
5. 不合格: 退货 / 让步接收

---

## 8. 智能补货建议

### 8.1 补货分析

路径: 「供应链管理」→「补货建议」

系统基于:
- 安全库存水平
- 当前库存
- 消耗速率
- 交货周期

生成智能补货建议。

### 8.2 补货策略

设置补货参数:
- 安全库存
- 补货点
- 补货批量

## 10. 库存周转率分析

### 10.1 周转率计算

路径: 「供应链管理」→「库存分析」→「周转率」

计算指标:
- 库存周转率
- 周转天数

### 10.2 ABC 分类

按物料价值分类:
- **A类**: 高价值物料（占金额 80%）
- **B类**: 中价值物料（占金额 15%）
- **C类**: 低价值物料（占金额 5%）

### 10.3 趋势分析

查看周转率趋势变化。
