# 人力资源管理 (HRM) 模块

## 概述

HRM 模块提供公司架构、部门和员工的管理功能。

**功能路径**: 人力资源 → 公司架构 / 员工管理  
**服务端口**: 8010  
**权限标识**: `hrm:read`, `hrm:write`, `hrm:delete`, `hrm:admin`

---

## 1. 公司架构管理

### 1.1 查看公司列表

路径: 「人力资源」→「公司架构」

功能:
- 查看所有公司信息
- 点击公司名称查看详情
- 支持搜索和筛选

### 1.2 创建公司

1. 在公司列表页面点击「新建公司」
2. 填写信息:
   - **公司名称**（必填）
   - **公司简称**
   - **统一社会信用代码**
   - **所属行业**
   - **公司规模**: 小型/中型/大型
   - **成立日期**
   - **地址**
   - **联系人**
   - **联系电话**
   - **邮箱**
3. 点击「保存」

### 1.3 编辑公司

1. 在公司列表或详情页点击「编辑」
2. 修改信息后点击「保存」

### 1.4 删除公司

1. 选择要删除的公司
2. 点击「删除」
3. 确认删除（注意：关联部门和员工将被转移）

### 1.5 在公司下创建部门

1. 进入公司详情页
2. 在部门树区域点击「新建部门」
3. 填写:
   - **部门名称**（必填）
   - **上级部门**
   - **部门负责人**
   - **部门描述**
4. 点击「保存」

### 1.6 部门树管理

- 展开/折叠部门层级
- 拖拽调整层级结构
- 直接在树上编辑和删除

---

## 2. 员工管理

### 2.1 查看员工列表

路径: 「人力资源」→「员工管理」

功能:
- 查看所有员工
- 按公司、部门、状态筛选
- 员工卡片显示所属公司、部门信息

### 2.2 创建员工

1. 点击「新建员工」
2. 填写信息:

**基本信息**
- 姓名、工号、性别、出生日期

**工作信息**
- 所属公司、部门
- 职位、入职日期

**联系方式**
- 电话、邮箱、地址

**其他**
- 紧急联系人
- 状态: 在职/离职/试用期

3. 点击「保存」

### 2.3 编辑员工

1. 在员工列表点击「编辑」
2. 修改信息后点击「保存」

### 2.4 重置密码

1. 选择员工
2. 点击「重置密码」
3. 设置新密码

### 2.5 员工与公司架构关联

- 每个员工必须隶属于一个公司
- 员工可以隶属于某个部门
- 在公司详情页查看该公司下所有员工
- 在部门详情页查看该部门下所有员工

---

## 3. 组织架构图

### 3.1 查看架构图

1. 在公司详情页点击「组织架构图」
2. 以图形方式查看部门层级

### 3.2 架构图操作

- 缩放查看
- 点击部门查看详情
- 导出架构图

---

## 4. 统计报表

### 4.1 人员统计

- 按部门统计人数
- 按职级统计分布
- 入职/离职趋势

### 4.2 导出报表

1. 选择统计维度
2. 点击「导出」
3. 选择格式下载
