# 实验室管理 (LIMS) 模块

## 概述

LIMS 模块管理样品信息、检验记录和实验数据，实现实验室数字化管理。

**功能路径**: 实验室管理  
**服务端口**: 8051  
**权限标识**: `lims:read`, `lims:write`, `lims:delete`, `lims:admin`

---

## 1. 样品管理

### 1.1 查看样品列表

路径: 「实验室管理」→「样品管理」

显示: 样品名称、编号、状态、接收日期

支持筛选:
- 按状态筛选: 待检验 / 检验中 / 已完成
- 按项目筛选
- 按日期范围筛选

### 1.2 创建样品

1. 点击「新建样品」
2. 填写:
   - **样品名称**（必填）
   - **样品编号**: 系统自动生成
   - **描述**: 样品描述
   - **关联项目**: 选择关联项目（RS）
   - **接收日期**: 选择日期
   - **样品来源**: 供应商/生产/客户/其他
   - **规格型号**: 样品规格
3. 点击「保存」

### 1.3 查看样品详情

1. 点击样品名称查看详情
2. 详情包含:
   - 基本信息
   - 检验记录
   - 附件管理

---

## 2. 检验记录

### 2.1 创建检验记录

1. 在样品详情页点击「创建检验记录」
2. 填写:
   - **检验编号**: 系统自动生成
   - **检验仪器**: 选择检验仪器
   - **检验流程**: 选择检验流程
   - **检验人员**: 选择检验员
   - **检验日期**: 选择日期
3. 添加检验项目:
   - 项目名称
   - 检验结果
   - 合格标准
   - 判定: 合格/不合格
4. 点击「保存」

### 2.2 查看检验记录

- 在样品详情页查看所有检验记录
- 按时间筛选
- 支持导出检验报告

---

## 3. 仪器管理

### 3.1 仪器列表

路径: 「实验室管理」→「仪器管理」

显示: 仪器名称、型号、状态、位置

### 3.2 新增仪器

1. 点击「新增仪器」
2. 填写:
   - **仪器名称**（必填）
   - **仪器型号**
   - **仪器编号**: 系统自动生成
   - **生产厂商**
   - **购买日期**
   - **存放位置**
   - **状态**: 正常/维护/停用
3. 点击「保存」

### 3.3 仪器校准

1. 选择仪器
2. 点击「校准记录」
3. 添加校准信息:
   - 校准日期
   - 校准机构
   - 校准结果
   - 下次校准日期

---

## 4. 实验数据管理

### 4.1 数据录入

1. 进入样品详情页
2. 点击「数据录入」
3. 填写实验数据
4. 上传原始数据文件

### 4.2 数据导出

1. 选择检验记录
2. 点击「导出数据」
3. 选择格式: Excel/CSV/PDF
4. 下载文件

---

## 5. 检验报告

### 5.1 生成报告

1. 选择已完成的检验记录
2. 点击「生成报告」
3. 系统自动生成标准化报告

### 5.2 报告模板

- 使用预设报告模板
- 自定义报告格式
- 支持报告电子签名

---

## 6. 统计分析

### 6.1 检验统计

- 检验数量统计
- 合格率统计
- 按项目/仪器统计

### 6.2 趋势分析

- 检验结果趋势
- 仪器使用频率
- 样品来源分布
