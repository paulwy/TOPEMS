# 仓库管理 (WMS) 模块

## 概述

WMS 模块管理仓库和库存业务。

**功能路径**: 仓库管理

---

## 1. 仓库管理

### 1.1 查看仓库列表

路径: 「仓库管理」→「仓库列表」

显示: 仓库名称、编码、地址、负责人

### 1.2 新增仓库

1. 点击「新增仓库」
2. 填写:
   - **仓库名称**（必填）
   - **仓库编码**: 系统自动生成
   - **仓库类型**: 原材料仓/成品仓/半成品仓/备件仓
   - **地址**
   - **负责人**
   - **容量**
3. 点击「保存」

---

## 2. 库存管理

### 2.1 查看库存

路径: 「仓库管理」→「库存管理」

显示: 物料编码、名称、规格、数量、仓库

### 2.2 入库操作

1. 点击「入库」
2. 选择仓库
3. 添加物料:
   - 选择物料
   - 输入数量
   - 输入批次号
   - 选择有效期
4. 点击「确认入库」

### 2.3 出库操作

1. 点击「出库」
2. 选择仓库
3. 添加物料:
   - 选择物料
   - 输入数量
   - 填写出库原因
4. 点击「确认出库」

### 2.4 库存盘点

1. 点击「库存盘点」
2. 选择仓库
3. 系统生成盘点清单
4. 填写实际库存数量
5. 系统计算差异
6. 点击「确认盘点」

---

## 3. 库存预警

### 3.1 设置预警规则

1. 点击「预警设置」
2. 设置:
   - 最低库存量
   - 最高库存量
   - 预警通知对象

### 3.2 预警通知

- 库存低于最低值时通知
- 库存高于最高值时提醒

---

## 4. 库存报表

### 4.1 库存台账

- 物料出入明细
- 批次追溯

### 4.2 库存周转

- 周转率分析
- 呆滞物料统计
