# 企业资源计划 (ERP) 模块

## 概述

ERP 模块管理公司资产、财务、银行账户、凭证等企业资源。

**功能路径**: 企业资源管理  
**服务端口**: 8010  
**权限标识**: `erp:read`, `erp:write`, `erp:delete`, `erp:admin`

---

## 1. 公司管理

### 1.1 查看公司列表

路径: 「企业资源管理」→「公司管理」

功能:
- 卡片式展示所有公司
- 显示名称、简称、联系电话、状态

### 1.2 新增公司

1. 点击「新增公司」
2. 填写信息:
   - **公司名称**（必填）
   - **简称**
   - **注册号**
   - **税号**
   - **地址**
   - **联系电话**
   - **邮箱**
   - **网站**
3. 点击「保存」

### 1.3 编辑/删除公司

- **编辑**: 点击卡片「编辑」按钮
- **删除**: 点击卡片「删除」按钮 → 确认

### 1.4 公司状态

| 状态 | 说明 |
|------|------|
| 活跃 | 正常运营 |
| 停用 | 暂停运营 |

## 2. 期初余额管理

### 2.1 查看期初余额

路径: 「企业资源管理」→「期初余额」

功能:
- 按期间、公司、科目筛选
- 查看余额列表

### 2.2 新增期初余额

1. 点击「新增期初余额」
2. 填写:
   - **公司**: 选择公司
   - **期间**: 如 202601
   - **科目代码/名称**
   - **借方余额**
   - **贷方余额**
3. 点击「保存」

### 2.3 批量导入

1. 点击「批量导入」
2. 选择 Excel 文件
3. 预览数据
4. 确认导入

### 2.4 期间结转

1. 点击「期间结转」
2. 选择源期间和目标期间
3. 确认结转

---

## 3. 固定资产管理

### 3.1 查看资产列表

路径: 「企业资源管理」→「固定资产」

功能:
- 卡片式展示资产
- 按部门、状态筛选
- 显示编码、名称、原值、净值、状态

### 3.2 新增资产

1. 点击「新增资产」
2. 填写:
   - **资产名称**（必填）
   - **资产类型**: 设备/房屋/车辆等
   - **资产类别**
   - **购置日期**
   - **原值**
   - **预计使用年限**（月）
   - **残值**
   - **折旧方法**: 平均年限法等
   - **存放地点**
   - **责任人**: 选择员工
   - **所属部门**: 选择部门
3. 点击「保存」

### 3.3 计提折旧

1. 选择资产（可多选）
2. 点击「计提折旧」
3. 选择折旧期间
4. 确认计提

### 3.4 资产处置

1. 点击资产「处置」
2. 选择方式: 报废/出售/捐赠
3. 填写日期和金额
4. 确认处置

---

## 4. 银行账户管理

### 4.1 查看账户列表

路径: 「企业资源管理」→「银行账户」

显示: 银行名称、账户名称、账号、余额

### 4.2 新增账户

1. 点击「新增账户」
2. 填写:
   - **公司**: 选择公司
   - **银行名称**
   - **开户行**
   - **账户名称**
   - **账号**
   - **账户类型**: 基本户/一般户
   - **币种**
   - **初始余额**
3. 点击「保存」

### 4.3 记录交易

1. 点击「交易记录」
2. 点击「新增交易」
3. 填写:
   - **交易日期**
   - **交易类型**: 收入/支出/转账
   - **金额**
   - **对方账户/名称**
   - **备注**
4. 点击「保存」

---

## 5. 凭证管理

### 5.1 查看凭证列表

路径: 「企业资源管理」→「凭证管理」

显示: 凭证编号、日期、类型、金额

### 5.2 新增凭证

1. 点击「新增凭证」
2. 选择凭证类型: 收款/付款/转账
3. 填写日期
4. 添加分录:
   - 点击「添加分录」
   - 选择科目
   - 输入摘要
   - 输入借方/贷方金额
5. 选择凭证来源
6. 点击「保存」

### 5.3 凭证审核

1. 选择待审核凭证
2. 点击「审核」
3. 查看详情
4. 点击「通过」或「驳回」

---

## 6. 财务报表

### 6.1 资产负债表

1. 选择「资产负债表」
2. 选择期间
3. 选择公司（支持多公司合并）
4. 点击「生成报表」
5. 支持导出 Excel/PDF

### 6.2 利润表

1. 选择「利润表」
2. 选择期间和公司
3. 点击「生成」
4. 查看收入、成本、费用、利润数据

### 6.3 现金流量表

1. 选择「现金流量表」
2. 选择期间和公司
3. 点击「生成」
4. 查看经营活动/投资活动/筹资活动流量

### 6.4 报表合并

1. 点击「报表合并」
2. 新增合并范围
3. 选择参与公司
4. 设置抵消规则
5. 生成合并报表
