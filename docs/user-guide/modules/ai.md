# AI 智能助手

## 概述

AI 模块集成 Ollama 本地 LLM 和 Redis 向量搜索，提供智能对话、文档问答、代码助手、知识库管理、Prompt 模板等 AI 能力。

**功能路径**: AI 助手
**服务端口**: 8013
**API 路径**: `/api/ai/*`
**代码目录**: `svc/ai/`（后端）、`apps/web/src/pages/ai/`（前端）、`apps/web/src/api/ai/`（API 客户端）
**权限标识**: `ai:search`, `ai:chat`, `ai:generate`, `ai:read`, `ai:write`, `ai:delete`, `ai:vector:read`, `ai:vector:write`, `ai:qa:ask`, `ai:sentiment:analyze`, `ai:text:classify`, `ai:connector:manage`

---

## 1. 智能对话

### 1.1 开始对话

路径: 「AI 助手」→「对话」

1. 点击左侧导航中的「AI 助手」进入仪表盘
2. 点击「对话」进入聊天界面
3. 在底部输入框中输入问题
4. 按 Enter 或点击发送按钮

系统会将您的问题发送给本地 LLM 模型（默认 `qwen2.5:7b-instruct`），并在界面中流式返回回答。

### 1.2 管理对话历史

- **查看历史对话**: 左侧对话列表展示所有会话，按时间倒序排列
- **继续对话**: 点击任意历史会话可继续发送消息
- **重新生成**: 在任意回答下方点击「重新生成」获取新的回答
- **删除对话**: 在对话列表中右键选择删除

### 1.3 仪表盘统计

路径: 「AI 助手」→「仪表盘」

仪表盘展示以下指标：
- 对话总数和消息总数
- 文档总数和 Token 消耗量
- 活跃用户数和满意度
- 使用趋势和功能分布

## 2. 文档与知识库

### 2.1 上传文档

路径: 「AI 助手」→「文档」

1. 点击「上传文档」按钮
2. 选择 PDF、Word 或文本文件
3. 系统自动解析文档内容并分块
4. 分块内容通过 embedding 模型（默认 `nomic-embed-text`）生成向量
5. 向量存入 PostgreSQL + pgvector，原文存入文件服务

上传完成后，文档可在对话中被 AI 引用回答问题。

### 2.2 知识库管理

路径: 「AI 助手」→「知识库」

知识库按文档集合组织，支持：
- 创建知识库并关联多个文档
- 查看文档处理状态（待处理/已索引/失败）
- 删除知识库及其关联向量

系统默认开启自动索引。如需关闭，设置环境变量 `DISABLE_AUTO_INDEX=true`。

### 2.3 文档问答

在对话界面中，系统会自动检索知识库中与问题相关的文档片段，并将其作为上下文提供给 LLM 生成回答。回答中会标注引用来源。

## 3. 代码助手

路径: 「AI 助手」→「代码助手」

代码助手提供编程辅助能力：

1. 在输入框中描述您的编程需求
2. 选择编程语言（可选）
3. AI 返回代码片段及说明
4. 可点击「复制」将代码复制到剪贴板

---

## 4. Prompt 模板

路径: 「AI 助手」→「Prompt 模板」

### 4.1 使用模板

1. 浏览模板列表，按分类筛选
2. 点击模板卡片查看详情
3. 点击「使用」将模板内容填入对话输入框
4. 根据需要修改占位符后发送

### 4.2 创建模板

1. 点击「新建模板」
2. 填写模板名称、分类、内容
3. 使用 `{{变量名}}` 语法定义占位符
4. 点击保存

### 4.3 管理模板

- **收藏**: 点击星标将常用模板加入收藏
- **编辑**: 点击模板卡片中的编辑按钮修改内容
- **删除**: 点击删除按钮移除模板
- **分类管理**: 在模板列表中按分类标签筛选

## 5. 系统设置

路径: 「AI 助手」→「设置」

需要 `ai:connector:manage` 权限。

### 5.1 模型配置

- **对话模型**: 查看/切换当前 LLM 模型（Ollama 或 OpenAI 模式）
- **Embedding 模型**: 查看/切换向量生成模型
- **用量统计**: 查看 Token 消耗和成本统计

### 5.2 AI Provider 配置

系统支持双模式运行，通过环境变量配置：

| 模式 | 环境变量 | 默认值 |
|------|---------|--------|
| Ollama（本地） | `OLLAMA_URL` | `localhost:11434` |
| OpenAI（远程） | `OPENAI_BASE_URL` + `OPENAI_API_KEY` | — |

当 `OLLAMA_URL` 或 base_url 包含 `localhost:11434` 时，系统自动判定为 Ollama 模式。

## 6. 常见问题

### 对话无响应或响应很慢

LLM 推理依赖本地 GPU/CPU 资源。检查 Ollama 服务是否正常运行（`http://localhost:11434`），并确认模型已下载（`ollama list`）。HTTP 客户端超时设置为 120 秒。

### 文档上传后无法在对话中引用

确认文档处理状态为「已索引」。如果自动索引被关闭（`DISABLE_AUTO_INDEX=true`），需要手动触发索引。pgvector 扩展必须已安装。

### API 报 403 权限错误

AI 模块有 12 个权限标识。对话需要 `ai:chat`，文档上传需要 `ai:write`，向量操作需要 `ai:vector:write`。联系管理员在 IAM 中分配对应权限。
