# GIS 地理信息

## 概述

GIS 模块提供地图可视化、设备定位、轨迹追踪、地理围栏等地理信息服务，支持 WebSocket 实时数据推送和空间分析。

**功能路径**: GIS 地理信息
**服务端口**: 8071
**API 路径**: `/api/gis/*`
**WebSocket**: `/ws/gis`、`/ws/gis/map`、`/ws/gis/device/{device_code}`
**代码目录**: `svc/gis/`（后端）、`apps/web/src/pages/gis/`（前端）、`apps/web/src/api/gis/`（API 客户端）
**权限标识**: `location`, `geofence`, `device`, `track`

---

## 1. 地图查看

路径: 「GIS 地理信息」→「地图」

### 1.1 查看工厂地图

1. 点击左侧导航中的「GIS 地理信息」进入仪表盘
2. 点击「地图」进入地图视图
3. 从地图列表中选择目标工厂地图
4. 地图加载后展示厂区布局、设备点位、管线走向、仓储位置

地图支持以下交互：
- 拖拽平移、滚轮缩放
- 点击设备图标查看设备详情
- 点击管线查看管线信息
- 切换图层显示/隐藏

### 1.2 创建工厂地图

1. 在地图列表页面点击「新建地图」
2. 填写地图名称、描述
3. 上传厂区平面图作为底图（可选）
4. 设置地图边界坐标
5. 点击保存

### 1.3 地图标记管理

在地图视图中可以添加、编辑、删除标记点：
- **设备点位**: 标记设备位置，关联设备编码
- **仓储位置**: 标记仓库/储位位置
- **业务位置**: 标记办公区、生产区等业务区域
- **管线**: 绘制管线走向

## 2. 设备追踪

路径: 「GIS 地理信息」→「设备追踪」

### 2.1 查看设备实时位置

1. 进入设备追踪页面
2. 地图上实时显示所有在线设备的位置图标
3. 设备位置通过 WebSocket 推送更新（端点 `/ws/gis`）

设备图标颜色反映状态：绿色=在线、灰色=离线、红色=告警。

### 2.2 查看设备轨迹

1. 在设备列表中选择目标设备
2. 选择时间范围（最近 1 小时 / 24 小时 / 自定义）
3. 地图上绘制设备移动轨迹
4. 轨迹统计展示：总距离、平均速度、停留时间

### 2.3 单设备实时追踪

通过 WebSocket 端点 `/ws/gis/device/{device_code}` 可订阅单个设备的实时位置更新，适用于大屏监控场景。

### 2.4 管理设备点位

1. 在设备管理列表中点击「新增设备点位」
2. 填写设备编码、名称、类型
3. 在地图上点击设置初始位置坐标
4. 点击保存

设备点位支持按地图筛选查看。

## 3. 地理围栏

路径: 「GIS 地理信息」→「围栏」

### 3.1 创建围栏

1. 进入围栏管理页面
2. 点击「新建围栏」
3. 在地图上绘制围栏区域（多边形或圆形）
4. 填写围栏名称、类型（限制区/警戒区/作业区）
5. 关联需要监控的设备
6. 点击保存

### 3.2 围栏告警

当设备进出围栏区域时，系统自动触发告警事件：
- **进入告警**: 设备进入限制区
- **离开告警**: 设备离开作业区
- **停留超时**: 设备在警戒区停留超过阈值

告警记录可在围栏详情中查看。

## 4. 数据导入与导出

### 4.1 导出 GeoJSON

1. 在地图或设备列表页面点击「导出」
2. 选择导出范围（当前视图/全部/按条件筛选）
3. 选择导出格式（GeoJSON）
4. 浏览器自动下载文件

导出接口为 `GET /api/gis/geojson/export`，不需要认证。

### 4.2 导入数据

1. 在地图管理页面点击「导入」
2. 选择 GeoJSON 或 CSV 文件
3. 映射字段到系统数据模型
4. 预览导入数据
5. 确认导入

## 5. 空间分析

GIS 模块提供 8 种空间分析能力，通过 API 调用（需要认证）：

| 分析类型 | 说明 |
|---------|------|
| buffer | 缓冲区分析 — 在指定要素周围创建缓冲区域 |
| intersect | 相交分析 — 判断两个要素是否相交 |
| union | 合并分析 — 将多个要素合并为一个 |
| difference | 差异分析 — 计算两个要素的差异部分 |
| within | 包含分析 — 判断要素是否在另一要素内 |
| distance | 距离计算 — 计算两个要素之间的距离 |
| nearest | 最近邻分析 — 查找距离最近的要素 |
| cluster | 聚类分析 — 对点位进行空间聚类 |

## 6. 仪表盘统计

路径: 「GIS 地理信息」→「仪表盘」

仪表盘展示以下统计信息：
- 设备总数和在线率
- 围栏数量和告警次数
- 工厂地图数量
- 管线总长度
- 仓储位置数量

统计数据通过 `GET /api/gis/statistics` 获取，无需认证。

## 7. 常见问题

### 设备位置不更新

检查 WebSocket 连接状态（浏览器开发者工具 → Network → WS）。确认设备端正在上报位置数据，且设备编码与系统中登记的一致。WebSocket 连接数有上限，通过 `WebSocketConfig` 的 `max_connections` 控制。

### 地图加载缓慢

工厂地图底图文件过大时可能影响加载速度。建议底图使用压缩后的图片格式，并将文件大小控制在 5MB 以内。地图数据查询有 30 秒超时限制。

### 围栏告警未触发

确认围栏已关联目标设备，且设备位置数据正在实时更新。围栏判定依赖设备位置上报频率，频率越低告警延迟越大。

### API 报 429 限流

GIS 模块按 IP 限流，规则为 200 请求/60 秒。写操作和空间分析需要认证，限流按用户 IP 计算。批量数据操作建议使用导出功能替代逐条 API 调用。
