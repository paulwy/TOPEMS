# 供应商管理 (SRM) 模块

## 概述

SRM 模块管理供应商信息和采购订单。

**功能路径**: 供应商管理  
**服务端口**: 8042  
**权限标识**: `srm:read`, `srm:write`, `srm:delete`, `srm:admin`

---

## 1. 供应商管理

### 1.1 查看供应商列表

路径: 「供应商管理」→「供应商列表」

显示: 供应商名称、联系人、电话、状态

### 1.2 新增供应商

1. 点击「新增供应商」
2. 填写:
   - **供应商名称**（必填）
   - **供应商编码**: 系统自动生成
   - **统一社会信用代码**
   - **联系人**
   - **联系电话**
   - **邮箱**
   - **地址**
   - **所属行业**
   - **注册资金**
   - **合作状态**: 合作中/暂停合作/终止合作
3. 点击「保存」

### 1.3 供应商评估

1. 进入供应商详情页
2. 点击「评估」标签
3. 填写评估指标:
   - 质量评分 (1-100)
   - 交货评分 (1-100)
   - 服务评分 (1-100)
   - 价格评分 (1-100)
4. 综合评分自动计算

---

## 2. 采购订单

### 2.1 创建采购订单

1. 点击「新建采购订单」
2. 填写:
   - **订单编号**: 系统自动生成
   - **供应商**: 选择供应商
   - **采购日期**
   - **交货日期**
   - **采购物品**: 添加物料及数量、单价
   - **备注**
3. 点击「保存」

### 2.2 订单跟踪

状态: 待确认 → 已确认 → 生产中 → 已发货 → 已收货

- 查看订单状态
- 点击查看详细信息
- 上传收货确认单

---

## 3. 供应商统计

### 3.1 供货统计

- 按供应商统计供货量
- 质量合格率分析

### 3.2 采购趋势

- 采购金额趋势
- 供应商分布分析
