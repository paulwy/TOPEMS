# 环境健康安全 (EHS) 模块

## 概述

EHS 模块管理安全检查和事故处理。

**功能路径**: 环境健康安全  
**服务端口**: 8051  
**权限标识**: `ehs:read`, `ehs:write`, `ehs:delete`, `ehs:admin`

---

## 1. 安全检查

### 1.1 创建检查任务

1. 点击「新建检查任务」
2. 填写:
   - **检查编号**: 系统自动生成
   - **检查类型**: 日常/专项/定期检查
   - **检查区域**
   - **检查内容**: 添加检查项
   - **检查人员**: 选择检查人
   - **检查日期**
3. 点击「保存」

### 1.2 执行检查

1. 点击「执行检查」
2. 填写每个检查项结果: 合格/不合格
3. 对不合格项添加整改建议
4. 点击「提交检查结果」

---

## 2. 事故管理

### 2.1 上报事故

1. 点击「上报事故」
2. 填写:
   - **事故编号**: 系统自动生成
   - **事故类型**: 安全/环保/职业健康事故
   - **事故级别**: 一般/较大/重大/特别重大
   - **事故描述**
   - **发生时间**
   - **发生地点**
   - **伤亡情况**
   - **经济损失**
3. 点击「提交」

### 2.2 事故处理

- 查看事故列表和处理进度
- 添加事故处理记录
- 上传事故调查报告

---

## 3. 统计分析

### 3.1 检查统计

- 检查覆盖率
- 合格率统计
- 问题分布

### 3.2 事故统计

- 事故趋势
- 事故类型分布
- 损失统计
