# 质量管理 (QMS) 模块

## 概述

QMS 模块管理质量标准、检验流程、质量问题和质量改进，实现全面质量管理体系。

**功能路径**: 质量管理
**服务端口**: 8050
**权限标识**: `qms:read`, `qms:write`, `qms:delete`, `qms:admin`

---

## 1. 质量标准管理

### 1.1 查看标准列表

路径: 「质量管理」→「质量标准」

显示: 标准编码、名称、类别、状态、版本

支持筛选:
- 按类别筛选: 产品标准 / 工艺标准 / 检验标准
- 按状态筛选: 草稿 / 生效 / 作废
- 按关键词搜索

### 1.2 新增质量标准

1. 点击「新增标准」
2. 填写:
   - **标准编码**: 系统自动生成
   - **标准名称**（必填）
   - **标准类别**: 产品/工艺/检验标准
   - **标准版本**
   - **发布日期**
   - **标准内容**
   - **适用范围**
   - **关联产品/工艺**
3. 点击「保存」

### 1.3 版本管理

1. 在标准详情页点击「版本历史」
2. 查看所有版本
3. 点击版本号查看内容
4. 支持版本对比

## 2. 检验管理

### 2.1 创建检验任务

1. 点击「新建检验任务」
2. 填写:
   - **检验编号**: 系统自动生成
   - **检验对象**: 产品或批次
   - **检验标准**: 选择适用的质量标准
   - **检验类型**: 来料/过程/成品检验
   - **检验项目**: 添加项目及合格标准
   - **检验人员**: 选择检验员
   - **检验日期**
3. 点击「保存」

### 2.2 执行检验

1. 点击「执行检验」
2. 填写每个检验项目结果:
   - 检验值
   - 判定: 合格/不合格/待定
   - 备注说明
3. 选择整体结论: 合格/不合格/待定
4. 添加备注和附件
5. 点击「提交检验结果」

### 2.3 检验记录查询

1. 在检验任务列表筛选已完成检验
2. 点击记录查看检验报告
3. 支持导出检验报告

---

## 3. 质量问题管理

### 3.1 上报质量问题

1. 点击「上报问题」
2. 填写:
   - **问题标题**（必填）
   - **问题描述**
   - **问题分类**: 来料/工艺/设计/售后问题
   - **严重程度**: 轻微/一般/严重/重大
   - **关联产品/批次**
   - **发现日期**
   - **发现人**
3. 点击「提交」

### 3.2 问题处理

1. 选择待处理问题
2. 点击「处理」
3. 填写:
   - **处理措施**
   - **责任人**
   - **预计完成时间**
4. 点击「保存」

### 3.3 问题跟踪

| 状态 | 说明 | 操作 |
|------|------|------|
| 待处理 | 问题已上报，等待处理 | 处理 / 关闭 |
| 处理中 | 问题处理进行中 | 更新 / 解决 |
| 已解决 | 问题已处理完成 | 关闭 / 重开 |
| 已关闭 | 问题已关闭 | - |

## 4. 统计过程控制 (SPC)

### 4.1 控制图分析

路径: 「质量管理」→「SPC分析」→「控制图」

支持的控制图类型:
- **X-R 控制图**: 均值-极差控制图
- **X-s 控制图**: 均值-标准差控制图
- **p 控制图**: 不合格品率控制图
- **c 控制图**: 缺陷数控制图

### 4.2 过程能力指数

路径: 「质量管理」→「SPC分析」→「过程能力」

计算指标:
- **Cp**: 过程潜在能力指数
- **Cpk**: 过程实际能力指数
- **Pp**: 过程性能指数
- **Ppk**: 过程实际性能指数

## 5. 质量成本分析

### 5.1 成本分类

路径: 「质量管理」→「质量成本」

质量成本分类:
- **预防成本**: 质量策划、培训、设备校准

### 5.2 成本统计

- 按时间趋势统计
- 按成本类型分析
- 质量成本率计算

## 6. 8D 问题解决流程

### 6.1 创建 8D 报告

路径: 「质量管理」→「8D问题解决」→「新建8D」

8D 步骤:

| 步骤 | 名称 | 说明 |
|------|------|------|
| D1 | 团队组建 | 建立问题解决团队 |
| D2 | 问题描述 | 清晰描述问题 |
| D3 | 临时措施 | 制定临时控制措施 |
| D4 | 根本原因分析 | 识别根本原因 |
| D5 | 永久纠正措施 | 制定永久解决方案 |
| D6 | 验证效果 | 验证措施有效性 |
| D7 | 预防措施 | 防止问题重复发生 |
| D8 | 团队表彰 | 总结和表彰 |

### 6.2 8D 状态流转

- 待处理 → D1 → D2 → D3 → D4 → D5 → D6 → D7 → D8 → 已完成

## 7. FMEA 失效模式分析

### 7.1 创建 FMEA

路径: 「质量管理」→「FMEA分析」→「新建FMEA」

填写:
- FMEA 名称
- 分析范围
- 产品/工艺信息

### 7.2 失效模式评估

为每个失效模式评估:
- **S (严重度)**: 1-10 分
- **O (发生率)**: 1-10 分
- **D (探测度)**: 1-10 分
- **RPN (风险优先级)**: S × O × D

按 RPN 排序，优先处理高风险项。
