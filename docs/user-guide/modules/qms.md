# 质量管理 (QMS) 模块

## 概述

QMS 模块管理质量标准、检验流程和质量改进。

**功能路径**: 质量管理

---

## 1. 质量标准管理

### 1.1 查看标准列表

路径: 「质量管理」→「质量标准」

显示: 标准编码、名称、类别、状态

### 1.2 新增质量标准

1. 点击「新增标准」
2. 填写:
   - **标准编码**: 系统自动生成
   - **标准名称**（必填）
   - **标准类别**: 产品/工艺/检验标准
   - **标准版本**
   - **发布日期**
   - **标准内容**
   - **适用范围**
3. 点击「保存」

### 1.3 版本管理

1. 在标准详情页点击「版本历史」
2. 查看所有版本
3. 点击版本号查看内容

---

## 2. 检验管理

### 2.1 创建检验任务

1. 点击「新建检验任务」
2. 填写:
   - **检验编号**: 系统自动生成
   - **检验对象**: 产品或批次
   - **检验标准**: 选择适用的质量标准
   - **检验类型**: 来料/过程/成品检验
   - **检验项目**: 添加项目及合格标准
   - **检验人员**: 选择检验员
   - **检验日期**
3. 点击「保存」

### 2.2 执行检验

1. 点击「执行检验」
2. 填写每个检验项目结果
3. 选择结论: 合格/不合格/待定
4. 添加备注和附件
5. 点击「提交检验结果」

### 2.3 检验记录查询

1. 在检验任务列表筛选已完成检验
2. 点击记录查看检验报告

---

## 3. 质量问题管理

### 3.1 上报质量问题

1. 点击「上报问题」
2. 填写:
   - **问题标题**（必填）
   - **问题描述**
   - **问题分类**: 来料/工艺/设计/售后问题
   - **严重程度**: 轻微/一般/严重/重大
   - **关联产品**
3. 点击「提交」

### 3.2 问题处理

1. 选择待处理问题
2. 点击「处理」
3. 填写:
   - **处理措施**
   - **责任人**
   - **预计完成时间**
4. 点击「保存」

### 3.3 问题跟踪

- 状态: 待处理 → 处理中 → 已解决 → 已关闭
- 点击查看处理进度
- 支持添加处理记录

---

## 4. 质量改进

### 4.1 创建改进项目

1. 点击「新建改进项目」
2. 填写:
   - **项目名称**（必填）
   - **项目编号**: 系统自动生成
   - **改进类型**: QC小组/6S/精益生产/六西格玛
   - **目标描述**
   - **预期效果**
   - **负责人**
   - **开始/结束日期**
3. 点击「保存」

### 4.2 改进项目管理

- 查看项目列表和进度
- 编辑、删除项目
- 添加改进活动和成果记录

---

## 5. 质量统计

### 5.1 合格率统计

- 按产品统计
- 按时间趋势统计

### 5.2 问题分析

- 问题分类统计
- 问题趋势分析
