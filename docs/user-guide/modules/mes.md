# 制造执行 (MES) 模块

## 概述

MES 模块管理生产计划、工艺流程和生产执行。

**功能路径**: 制造执行

---

## 1. 生产计划

### 1.1 查看生产计划

路径: 「制造执行」→「生产计划」

显示: 计划编号、产品名称、计划数量、状态

### 1.2 创建生产计划

1. 点击「新建生产计划」
2. 填写:
   - **计划编号**: 系统自动生成
   - **产品**: 选择产品
   - **计划数量**
   - **开始/结束日期**
   - **优先级**: 高/中/低
3. 点击「保存」

### 1.3 下达生产计划

1. 选择待下达计划
2. 点击「下达」
3. 确认操作
4. 状态变为「执行中」

---

## 2. 工艺流程

### 2.1 查看工艺路线

路径: 「制造执行」→「工艺路线」

显示: 路线名称、产品、工序数量

### 2.2 创建工艺路线

1. 点击「新建工艺路线」
2. 填写:
   - **路线名称**（必填）
   - **路线编码**: 系统自动生成
   - **产品**: 选择关联产品
3. 添加工序:
   - 工序名称
   - 工序类型
   - 工序顺序
   - 设备选择
   - 人员安排
4. 点击「保存」

---

## 3. 生产执行

### 3.1 开工报工

1. 点击「生产执行」
2. 选择生产工单
3. 点击「开工」
4. 填写开工信息

### 3.2 完工报工

1. 选择已开工工单
2. 点击「完工」
3. 填写完工数量和质量信息
4. 点击「确认完工」

---

## 4. 生产统计

### 4.1 产量统计

- 按时间统计产量
- 按产品统计
- 按班组统计

### 4.2 质量统计

- 合格率统计
- 不良品分析
