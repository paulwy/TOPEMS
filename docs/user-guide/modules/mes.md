# 制造执行 (MES) 模块

## 概述

MES 模块管理生产计划、工艺流程、生产执行和质量追溯，实现生产过程的数字化管控。

**功能路径**: 制造执行
**服务端口**: 8030
**权限标识**: `mes:read`, `mes:write`, `mes:delete`, `mes:admin`

---

## 1. 生产计划

### 1.1 查看生产计划

路径: 「制造执行」→「生产计划」

显示: 计划编号、产品名称、计划数量、状态、开始/结束日期

支持筛选:
- 按状态筛选: 待下达 / 执行中 / 已完成 / 已取消
- 按产品筛选
- 按日期范围筛选

### 1.2 创建生产计划

1. 点击「新建生产计划」
2. 填写:
   - **计划编号**: 系统自动生成
   - **产品**: 选择产品（关联 PDM 产品数据）
   - **计划数量**（必填）
   - **开始/结束日期**
   - **优先级**: 高/中/低
   - **所属车间**: 选择生产车间
   - **备注说明**
3. 点击「保存」

### 1.3 下达生产计划

1. 选择待下达计划
2. 点击「下达」
3. 确认操作
4. 状态变为「执行中」，自动生成生产工单

### 1.4 生产计划状态流转

| 状态 | 说明 | 操作 |
|------|------|------|
| 待下达 | 计划已创建，等待审批 | 下达 / 编辑 / 删除 |
| 执行中 | 计划已下达，生产进行中 | 暂停 / 完成 / 终止 |
| 已暂停 | 生产暂停 | 恢复 / 终止 |
| 已完成 | 生产全部完成 | - |
| 已终止 | 计划终止 | - |

## 2. 工艺流程

### 2.1 查看工艺路线

路径: 「制造执行」→「工艺路线」

显示: 路线名称、产品、工序数量、版本

### 2.2 创建工艺路线

1. 点击「新建工艺路线」
2. 填写:
   - **路线名称**（必填）
   - **路线编码**: 系统自动生成
   - **产品**: 选择关联产品（PDM）
   - **版本**: 默认 V1.0
3. 添加工序:
   - 工序名称
   - 工序类型: 加工/装配/检验/包装
   - 工序顺序
   - 设备选择
   - 人员安排
   - 标准工时
4. 点击「保存」

### 2.3 工艺路线版本管理

- 支持版本升级
- 查看历史版本
- 对比版本差异

## 3. 生产执行

### 3.1 开工报工

1. 点击「生产执行」→「生产工单」
2. 选择待开工工单
3. 点击「开工」
4. 填写开工信息:
   - 开工时间
   - 操作人员
   - 当前工序
5. 点击「确认开工」

### 3.2 完工报工

1. 选择已开工工单
2. 点击「完工」
3. 填写完工信息:
   - 完工数量
   - 合格数量
   - 不合格数量
   - 完工时间
   - 操作人员
4. 点击「确认完工」

### 3.3 生产记录

路径: 「制造执行」→「生产记录」

查看所有生产过程记录，支持按时间、工单、工序筛选。

---

## 4. 生产排产优化 (APS)

### 4.1 高级排程

路径: 「制造执行」→「排产管理」

功能:
- 自动排产: 根据设备产能、优先级自动分配
- 手动调整: 拖拽甘特图调整计划
- 产能负载查看: 设备负载率统计

### 4.2 甘特图展示

- 查看设备排产计划
- 查看工单进度
- 查看资源占用情况

---

## 5. 物料 BOM 关联

### 5.1 物料领用

1. 路径: 「制造执行」→「物料管理」→「领用申请」
2. 选择生产工单
3. 系统自动列出所需物料（基于 BOM）
4. 填写领用数量
5. 提交申请

### 5.2 物料返还

1. 选择已领用记录
2. 填写返还数量和原因
3. 提交返还

---

## 6. 质量追溯

### 6.1 正向追溯

1. 路径: 「制造执行」→「质量追溯」→「正向追溯」
2. 输入产品批次号或序列号
3. 查看生产过程:
   - 原材料批次
   - 生产工单
   - 操作人员
   - 设备信息
   - 检验记录

### 6.2 反向追溯

1. 路径: 「制造执行」→「质量追溯」→「反向追溯」
2. 输入原材料批次号
3. 查看使用该原材料的所有成品批次

## 7. 设备管理

### 7.1 设备列表

路径: 「制造执行」→「设备管理」

显示: 设备名称、型号、状态、位置

### 7.2 OEE 计算

路径: 「制造执行」→「设备管理」→「OEE分析」

OEE = 可用率 × 性能率 × 质量率

查看设备综合效率报表。
