# 产品数据管理 (PDM) 模块

## 概述

PDM 模块管理产品和物料清单 (BOM)。

**功能路径**: 产品数据管理  
**服务端口**: 8031  
**权限标识**: `pdm:read`, `pdm:write`, `pdm:delete`, `pdm:admin`

---

## 1. 产品管理

### 1.1 查看产品列表

路径: 「产品数据管理」→「产品列表」

显示: 产品名称、编码、规格、状态

### 1.2 新增产品

1. 点击「新增产品」
2. 填写:
   - **产品名称**（必填）
   - **产品编码**: 系统自动生成
   - **产品类别**
   - **规格型号**
   - **单位**
   - **描述**
3. 点击「保存」

---

## 2. BOM 管理

### 2.1 查看 BOM 列表

路径: 「产品数据管理」→「BOM管理」

显示: 产品名称、BOM版本、物料数量

### 2.2 创建 BOM

1. 点击「新建BOM」
2. 选择产品
3. 输入BOM版本号
4. 添加物料清单:
   - 选择物料
   - 输入用量
   - 选择单位
5. 点击「保存」

### 2.3 BOM 版本管理

- 创建BOM新版本
- 查看版本历史
- 版本对比
