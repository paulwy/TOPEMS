# 项目管理 (PM) 模块

## 概述

PM 模块提供项目计划、任务管理、资源分配和进度跟踪功能，帮助团队高效协作完成项目目标。

**功能路径**: 项目管理  
**服务端口**: 8023  
**权限标识**: `pm:read`, `pm:write`, `pm:delete`, `pm:admin`

---

## 1. 项目管理

### 1.1 查看项目列表

路径: 「项目管理」→「项目列表」

显示: 项目名称、编码、负责人、状态、进度、开始日期、结束日期

### 1.2 新建项目

1. 点击「新建项目」
2. 填写:
   - **项目名称**（必填）
   - **项目编码**: 系统自动生成
   - **项目类型**: 内部项目/外部项目/研发项目
   - **负责人**（必填）
   - **开始日期**、**结束日期**
   - **预算**
   - **项目描述**
3. 点击「保存」

---

## 2. 任务管理

### 2.1 查看任务列表

路径: 「项目管理」→「任务管理」

显示: 任务名称、所属项目、负责人、状态、优先级、截止日期

### 2.2 新建任务

1. 选择项目后点击「新建任务」
2. 填写:
   - **任务名称**（必填）
   - **任务描述**
   - **负责人**
   - **优先级**: 低/中/高/紧急
   - **开始日期**、**截止日期**
   - **前置任务**
   - **预估工时**
3. 点击「保存」

---

## 3. 甘特图视图

路径: 「项目管理」→「甘特图」

以时间轴形式展示项目进度，支持拖拽调整任务时间和依赖关系。

---

## 4. 资源管理

路径: 「项目管理」→「资源分配」

管理项目成员分配、工时记录、资源利用率统计。
