# 项目管理 (PM) 模块

## 概述

PM 模块提供项目计划、任务管理、资源分配和进度跟踪功能，帮助团队高效协作完成项目目标。

**功能路径**: 项目管理  
**服务端口**: 8023  
**权限标识**: `pm:read`, `pm:write`, `pm:delete`, `pm:admin`

---

## 1. 项目管理

### 1.1 查看项目列表

路径: 「项目管理」→「项目列表」

显示: 项目名称、编码、负责人、状态、进度、开始日期、结束日期

### 1.2 新建项目

1. 点击「新建项目」
2. 填写:
   - **项目名称**（必填）
   - **项目编码**: 系统自动生成
   - **项目类型**: 内部项目/外部项目/研发项目
   - **负责人**（必填）
   - **开始日期**、**结束日期**
   - **预算**
   - **项目描述**
3. 点击「保存」

---

## 2. 任务管理

### 2.1 查看任务列表

路径: 「项目管理」→「任务管理」

显示: 任务名称、所属项目、负责人、状态、优先级、截止日期

### 2.2 新建任务

1. 选择项目后点击「新建任务」
2. 填写:
   - **任务名称**（必填）
   - **任务描述**
   - **负责人**
   - **优先级**: 低/中/高/紧急
   - **开始日期**、**截止日期**
   - **前置任务**
   - **预估工时**
3. 点击「保存」

---

## 3. 甘特图视图

路径: 「项目管理」→「甘特图」

以时间轴形式展示项目进度，支持拖拽调整任务时间和依赖关系。

---

## 4. 资源管理

路径: 「项目管理」→「资源分配」

管理项目成员分配、工时记录、资源利用率统计。

---

## 5. 统计仪表板（V176 新增）

路径: 「项目管理」→「统计仪表板」

提供多维度统计概览，支持实时查看项目整体状况。

### 5.1 功能说明

| 统计维度 | 说明 |
|---------|------|
| 项目统计 | 按状态/类型/负责人分组，平均进度、准时率、高风险数 |
| 合同统计 | 合同数量、金额、按状态/类型分组 |
| 预算统计 | 总预算、已分配/已支出/剩余、使用率、按类别分组 |
| 风险统计 | 风险总数、按等级/类别分组、开闭状态 |
| 任务统计 | 按状态/优先级分组、完成率、逾期数 |

### 5.2 使用方式

1. 进入「统计仪表板」页面
2. 可通过日期范围筛选统计数据
3. 点击各维度卡片可查看详细报表

---

## 6. 报表导出

路径: 「项目管理」→「报表中心」

### 6.1 可用报表

| 报表名称 | 说明 | 导出格式 |
|---------|------|---------|
| 项目进度报表 | 按项目维度展示进度明细 | Excel / PDF |
| 预算执行报表 | 预算使用情况分析 | Excel |
| 风险汇总报表 | 项目风险全景视图 | PDF |
| 资源利用率报表 | 人员/设备资源使用统计 | Excel |

### 6.2 导出步骤

1. 选择报表类型
2. 选择时间范围
3. 点击「生成报表」
4. 系统生成后自动下载
