# 研发管理 (RS) 模块

## 概述

RS 模块管理研发项目、实验记录和成果。

**功能路径**: 研发管理  
**服务端口**: 8080  
**权限标识**: `rs:read`, `rs:write`, `rs:delete`, `rs:admin`

---

## 1. 项目管理

### 1.1 查看项目列表

路径: 「研发管理」→「项目列表」

功能:
- 卡片式展示项目
- 显示名称、负责人、状态、进度

### 1.2 创建项目

1. 点击「新建项目」
2. 填写:
   - **项目名称**（必填）
   - **项目编号**: 系统自动生成
   - **项目类型**: 研发/产品/工艺
   - **负责人**: 选择员工
   - **开始/结束日期**
   - **项目描述**
3. 点击「保存」

### 1.3 查看项目详情

1. 点击项目名称或查看按钮
2. 详情包含:
   - 基本信息
   - 项目进度
   - 关联实验
   - 项目时间线
   - 附件管理

### 1.4 编辑/删除项目

- **编辑**: 点击「编辑」→ 修改 → 保存
- **删除**: 点击「删除」→ 确认

---

## 2. 实验管理

### 2.1 创建实验

1. 进入项目详情页
2. 点击「实验」标签
3. 点击「创建实验」
4. 填写实验信息
5. 点击「保存」

### 2.2 查看实验记录

- 在项目详情页查看所有实验
- 按状态筛选
- 查看实验详情和结果

### 2.3 实验附件

- 上传实验数据文件
- 下载历史版本
- 查看附件列表

---

## 3. 项目看板

### 3.1 查看看板

- 图形化展示项目进度
- 按状态分组显示

### 3.2 看板操作

- 拖拽卡片调整状态
- 点击查看详情
- 快速添加任务

---

## 4. 项目报表

### 4.1 进度报表

- 显示项目完成百分比
- 里程碑达成情况

### 4.2 资源使用

- 人力投入统计
- 费用使用统计
