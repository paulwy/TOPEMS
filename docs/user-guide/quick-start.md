# TOPEMS 快速入门指南

本指南帮助新用户快速了解和使用 TOPEMS 企业管理系统。

**适用对象**: 新用户  
**预计阅读时间**: 10 分钟

### 1.1 访问地址

| 环境 | 地址 |
|------|------|
| 本地部署 | http://localhost:3000 |

## 3. 快速任务

### 3.1 查看公司架构

1. 点击「人力资源」→「公司架构」
2. 查看公司列表
3. 点击公司名称查看详情和部门结构

### 3.2 创建员工

1. 点击「人力资源」→「员工管理」
2. 点击「新建员工」
3. 填写基本信息（姓名、工号、部门）
4. 点击「保存」

### 3.3 提交审批

1. 点击「工作流」→「待办审批」
2. 选择待审批任务
3. 点击「通过」或「拒绝」
4. （可选）填写审批意见

### 3.4 发送消息

1. 点击「即时通讯」
2. 选择联系人或群组
3. 输入消息内容
4. 按 Enter 或点击发送按钮
