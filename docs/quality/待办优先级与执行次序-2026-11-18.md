1. **先让验证可信**：工作树归属、目标库安全、测试库 RLS、构建/映射陈旧值不清，后面所有“已验证”都不成立。

**禁止事项**：本清单执行期间不得修改已应用迁移字节；不得用 `--no-verify`；不得在窗口外做 DDL；
不得把多个迁移合并成一次“顺手”提交。

## 6. 每波的关键风险与停手条件

| 波次 | 关键风险 | 立即停手条件 |
|---|---|---|
| 第 0 波 | 改 `.env`/默认值打断本地开发；误改已应用迁移 | 任一 workspace 构建/门禁由绿转红且 30 分钟内无法定位 |
| 第 1 波 | 二进制与迁移顺序颠倒；窗口内并发写 | 二进制 sha 不等于 `97484f3a…9147`；账本/策略/表数任一偏离 |
| 第 2 波 | 权威源判断错误；历史流水口径缺失 | 任一项拿不出代码/数据级证据 → 停在 ADR |
| 第 3 波 | 删除仍被动态调用的 handler；F1 决策停滞 | 删除项无法给出“全仓零引用 + 运行态零调用”证据 |
| 第 4 波 | DROP 不可逆；回填归属错误；迁移并行 | 备份缺失、回滚未演练、账本出现非预期版本 |
| 第 5 波 | 大项跨服务回归；压测阈值未书面化 | 三项前置缺一，或双写对账差异 > 0 |
