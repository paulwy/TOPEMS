## 3. 缺陷与修复清单（P0-P3）

### P0（构建阻断，已修复）
- **prod build 白屏死结**：rolldown build CJS interop 系统性错位（React 系条件入口转换剥离 `createContext`）→ dist /login `TypeError: Jt is not a function`。修复链 5 项（`apps/web/vite.config.ts`）：build-only production CJS alias（react/react-dom/client/jsx-runtime/jsx-dev-runtime/react-is）+ `fix-cjs-named-exports-general` 限定 `apply:'serve'` + `legacy.inconsistentCjsInterop: true` + treeshake 回退 false + `fix-cjs-interop-build` closeBundle 兜底。验证：dist /login 实机 0 pageerror，Lighthouse 基线可跑

### P1（功能缺陷，已修复）
- `/help/faq`、`/help/guide` 双前缀 404：`src/api/help.ts` 绝对路径重复 `/api/core` → 改相对路径
- `/attachments` ErrorBoundary 崩溃：后端分页信封被当数组 → 双形态兼容
- `/mes/analytics/mtbf` NaN：除零防护 + 数值兜底
- `/notification/settings` 受控/非受控警告：首帧 undefined → `?? 0` 兜底
- CrudPage 列表 500 静默空表格（无错误态 + 双层重试延迟 ~10s）→ 解构 `isError/error/refetch` + `retry:false`（全仓受益）
- TreeBuilder tree 视图 500 静默 → 新增 error/onRefresh props 渲染 ErrorEmptyState

### P2（契约/服务缺陷，已修复）
- 契约门禁 19 FAIL 根因：qms 未跑迁移 91 + id 类型绑定；aps baseURL 错位 + schedules 占位符同号冲突；mes/mobile 动态 SQL 占位符与 LIMIT 同号；file 模块 flow 影子表缺 tenant 列；wms serial UPDATE 非法 SQL + 同号 bind + 超限；help stub 缺失

### P3（可访问性/i18n 缺陷，已修复）
- a11y 12 项（Escape 键盘关闭、ImageUpload 键盘可达、Select label 关联、对比度 6 处、viewport 缩放等）
- main landmark / h1 语义 / 空 heading 清零（登录页、PageHeader、DetailPageTemplate、MuiStatCard）
- 被引用 i18n 缺失 key 归零（zh→en 216 + en→zh 105）；en/utils.json 裸 k0-k9 假占位清理
