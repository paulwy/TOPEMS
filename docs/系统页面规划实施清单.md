## 页面模版使用规范

### 1. ListPageTemplate - 列表页

```tsx
import { ListPageTemplate } from '@/components/templates';

const CustomerListPage: React.FC = () => {
  return (
    <ListPageTemplate
      title="客户列表"
      breadcrumbs={[
        { label: '首页', href: '/dashboard' },
        { label: '客户', href: '/crm' },
        { label: '客户列表' }
      ]}
      columns={columns}
      data={customers}
      loading={loading}
      rowActions={rowActions}
      searchable
      searchPlaceholder="搜索客户..."
      pagination={{ page, pageSize, total, onPageChange }}
      actions={[
        { label: '新建客户', icon: <Plus />, onClick: () => navigate('/crm/customers/create') }
      ]}
    />
  );
};
```

### 2. DetailPageTemplate - 详情页

```tsx
import { DetailPageTemplate } from '@/components/templates';

const CustomerDetailPage: React.FC = () => {
  return (
    <DetailPageTemplate
      title={customer.name}
      subtitle={customer.code}
      breadcrumbs={[
        { label: '首页', href: '/dashboard' },
        { label: '客户', href: '/crm' },
        { label: '客户列表', href: '/crm/customers' },
        { label: customer.name }
      ]}
      backHref="/crm/customers"
      tabs={tabs}
      infoCard={infoCard}
      onEdit={() => navigate(`/crm/customers/${id}/edit`)}
      onDelete={handleDelete}
    />
  );
};
```

### 3. FormPageTemplate - 表单页

```tsx
import { FormPageTemplate } from '@/components/templates';

const CreateCustomerPage: React.FC = () => {
  return (
    <FormPageTemplate
      title="新建客户"

        { label: '客户', href: '/crm' },

        { label: '新建客户' }

      schema={customerSchema}
      onSubmit={handleSubmit}
      onCancel={() => navigate('/crm/customers')}

    />
  );

```

## 路由配置规范

### 路由文件结构

```
/routes
├── index.ts              # 主路由入口
├── hrm.ts               # HRM模块路由
├── crm.ts               # CRM模块路由
├── finance.ts           # Finance模块路由 (新建)
├── pm.ts                # PM模块路由
├── flow.ts              # Flow模块路由
├── im.ts                # IM模块路由 (重构)
└── bi.ts                # BI模块路由
```

### 路由路径规范

| 页面类型 | 路径格式 | 示例 |
|---------|---------|------|
| 仪表盘 | `/module` | `/finance` |
| 列表页 | `/module/entities` | `/finance/vouchers` |
| 详情页 | `/module/entities/:id` | `/finance/vouchers/:id` |
| 创建页 | `/module/entities/create` | `/finance/vouchers/create` |
| 编辑页 | `/module/entities/:id/edit` | `/finance/vouchers/:id/edit` |
| 表单页 | `/module/forms/:formName` | `/finance/period-close` |
