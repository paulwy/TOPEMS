# 赛博朋克主题 UI 优化设计文档

> 版本：V1.0
> 日期：2026-07-20
> 状态：待审阅

## 概述

基于用户偏好的赛博朋克视觉风格，为 TOPEMS 平台新增一套"赛博朋克"主题选项，与现有亮色/暗色主题并存。通过霓虹配色、玻璃拟态、发光效果和微动效，打造科技感十足的现代化界面。

## 设计原则

1. **可选而非强制**：新增主题，不破坏现有体验，用户自由切换
2. **一致性优先**：新主题从零设计，确保全局统一，避免"打补丁"观感
3. **渐进式落地**：先做核心组件，再扩展到全量页面
4. **性能友好**：动效克制，使用 CSS 原生能力，避免过度动画影响性能
5. **可访问性**：霓虹色确保对比度符合 WCAG AA 标准

## 一、配色系统

### 1.1 主色调

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色（霓虹青） | `#00FFFF` | 品牌主色，用于主要按钮、选中态、强调文字 |
| 次色（霓虹品红） | `#FF00FF` | 装饰性点缀，渐变、图标、次要强调 |
| 点缀色（金黄） | `#FFD700` | 高亮数据、特殊标记、VIP 标识 |
| 背景（深空黑） | `#0A0A1A` | 页面底色，深邃科技感 |
| 表面（深灰蓝） | `#1A1A2E` | 卡片/面板底色 |

### 1.2 语义色

| 语义 | 颜色值 | 用途 |
|------|--------|------|
| success | `#00FF88` | 荧光绿，成功状态 |
| error | `#FF4444` | 警示红，错误状态 |
| warning | `#FFAA00` | 琥珀橙，警告状态 |
| info | `#00AAFF` | 科技蓝，信息提示 |

### 1.3 文字色阶

| 层级 | 颜色值 | 用途 |
|------|--------|------|
| primary | `#E6F1FF` | 主要文字 |
| secondary | `#8892B0` | 次要文字、说明文字 |
| muted | `#5A6A8A` | 弱化文字、辅助说明 |
| disabled | `#3A4A6A` | 禁用文字 |

### 1.4 渐变预设

| 名称 | 渐变 | 用途 |
|------|------|------|
| 霓虹渐变 | `linear-gradient(135deg, #00FFFF, #FF00FF)` | 标题文字、图标、边框 |
| 金色渐变 | `linear-gradient(135deg, #FFD700, #FFA500)` | VIP、高亮数据 |
| 成功渐变 | `linear-gradient(135deg, #00FF88, #00CC66)` | 成功状态条 |
| 背景渐变 | `linear-gradient(135deg, #0A0A1A 0%, #1A1A2E 50%, #16213E 100%)` | 页面背景 |

## 二、玻璃拟态设计

### 2.1 卡片层级

| 层级 | 透明度 | 模糊度 | 边框 | 阴影 |
|------|--------|--------|------|------|
| 底层（页面背景） | 100% | - | - | - |
| 中层（卡片） | 5% | 10px | 1px solid rgba(0,255,255,0.2) | 0 4px 24px rgba(0,0,0,0.3) |
| 顶层（弹窗/下拉） | 8% | 12px | 1px solid rgba(0,255,255,0.3) | 0 8px 32px rgba(0,0,0,0.4) |

### 2.2 卡片状态

**默认态：**
- 背景：`rgba(255, 255, 255, 0.05)`
- 边框：`1px solid rgba(0, 255, 255, 0.2)`
- 阴影：`0 4px 24px rgba(0, 0, 0, 0.3), inset 0 1px 0 rgba(255, 255, 255, 0.1)`

**悬浮态：**
- 背景：`rgba(255, 255, 255, 0.08)`
- 边框：`1px solid rgba(0, 255, 255, 0.5)`
- 阴影：`0 8px 32px rgba(0, 255, 255, 0.2), inset 0 1px 0 rgba(255, 255, 255, 0.15)`
- 位移：`translateY(-2px)`
- 文字：主标题变为霓虹青色，带发光效果

**渐变边框卡片（VIP/重要数据）：**
- 外层：1px 渐变边框（霓虹青 → 霓虹品红）
- 内层：`rgba(10, 10, 26, 0.9)` 背景 + 10px 模糊
- 文字：渐变填充（`-webkit-background-clip: text`）

## 三、微动效系统

### 3.1 悬浮发光

- **触发**：鼠标悬停在可交互元素上
- **效果**：元素外发光（box-shadow glow）、文字颜色变霓虹色并带 text-shadow
- **时长**：200ms
- **缓动**：ease-out
- **应用**：按钮、卡片、菜单项、表格行

### 3.2 数字滚动动画

- **触发**：统计数字首次渲染或数据更新
- **效果**：数字从 0（或旧值）滚动到目标值
- **时长**：800ms
- **缓动**：`cubic-bezier(0.16, 1, 0.3, 1)`
- **应用**：Dashboard 统计卡片、数据大屏

### 3.3 扫光效果

- **触发**：卡片/按钮悬停时
- **效果**：一道半透明光从左扫到右
- **时长**：600ms
- **实现**：伪元素 + translateX 动画
- **应用**：主要按钮、特色卡片

### 3.4 霓虹骨架屏

- **触发**：数据加载中
- **效果**：霓虹色流光从左到右循环流动
- **时长**：1.5s / 循环
- **渐变**：`linear-gradient(90deg, transparent, rgba(0,255,255,0.1), transparent)`
- **应用**：表格、卡片、列表加载态

### 3.5 页面过渡

- **触发**：路由切换
- **效果**：淡入 + 轻微上移
- **时长**：300ms
- **缓动**：ease-out
- **实现**：React Transition Group 或 Framer Motion

### 3.6 主题切换动画

- **触发**：切换亮色/暗色/赛博朋克主题
- **效果**：全局 300ms 淡入淡出过渡
- **实现**：CSS transition + `data-theme` 属性切换

## 四、组件设计规范

### 4.1 按钮

| 类型 | 默认态 | 悬浮态 | 禁用态 |
|------|--------|--------|--------|
| Primary | 霓虹青渐变背景 + 发光阴影 | 发光增强 + 轻微放大 | 50% 透明度 |
| Secondary | 透明背景 + 霓虹青边框 | 半透明背景 + 发光边框 | - |
| Ghost | 纯文字 | 霓虹青文字 + 下划线发光 | - |

### 4.2 输入框

- 背景：`rgba(255, 255, 255, 0.03)`
- 边框：`1px solid rgba(255, 255, 255, 0.1)`
- 聚焦：边框变霓虹青 + 外发光 + 背景略亮
- 错误：边框变警示红 + 红色发光

### 4.3 表格

- 表头：半透明背景 + 底部霓虹青边框线
- 行：默认透明，hover 时半透明背景 + 左侧霓虹青指示条
- 选中行：霓虹青 10% 透明度背景 + 左侧 2px 霓虹青边框
- 斑马纹：极淡的交替背景（可选）

### 4.4 侧边栏

- 背景：半透明玻璃态
- 选中项：左侧 3px 霓虹青边框 + 渐变背景（从左到右淡出）
- 悬浮项：半透明背景 + 文字变亮
- 分组标题：弱化文字 + 大写 + 字间距

### 4.5 顶部导航

- 背景：毛玻璃效果（backdrop-filter: blur）
- 底部边框：极细的霓虹青渐变线
- 阴影：轻微向下发光

## 五、主题切换机制

### 5.1 主题列表

| 主题 ID | 名称 | 说明 |
|---------|------|------|
| `light` | 亮色 | 现有默认主题 |
| `dark` | 暗色 | 现有深色主题 |
| `cyberpunk` | 赛博朋克 | 新增霓虹科技风主题 |

### 5.2 实现方案

基于 MUI v9 的 `colorSchemes` 机制扩展：

```ts
// theme.ts 中扩展
createTheme({
  colorSchemes: {
    light: { /* ... */ },
    dark: { /* ... */ },
    cyberpunk: { /* 新增 */ },
  },
  cssVariables: {
    colorSchemeSelector: 'class', // 使用 .cyberpunk 类名切换
  },
});
```

### 5.3 切换流程

1. 用户在设置中选择主题
2. 更新 `themeStore` 中的主题模式
3. 在 `<html>` 或 `<body>` 上切换 `data-theme` 属性 / CSS class
4. CSS 变量自动切换，300ms 平滑过渡
5. 持久化到 localStorage

### 5.4 主题选择器 UI

- 位置：顶栏用户菜单中，或设置页面
- 形式：三个预览卡片（亮色/暗色/赛博朋克），点击切换
- 每个选项有小预览图 + 名称 + 简短描述

## 七、技术实现要点

### 7.1 CSS 变量驱动

所有主题颜色通过 CSS 变量定义，切换主题时只需切换 class，性能最优：

```css
:root.cyberpunk {
  --color-primary: #00FFFF;
  --color-secondary: #FF00FF;
  --color-background: #0A0A1A;
  /* ... */
}
```

### 7.2 性能优化

- 发光效果（box-shadow / text-shadow）使用 `will-change: opacity` 优化
- 动画使用 transform 和 opacity，避免触发重排
- 减少大面积模糊的使用，必要时使用 `backdrop-filter` 降级方案
- 提供"减少动效"选项，尊重 `prefers-reduced-motion`

### 7.3 可访问性

- 霓虹色文字确保对比度 ≥ 4.5:1（WCAG AA）
- 发光效果不作为唯一的状态标识，配合形状/文字说明
- 支持键盘导航和屏幕阅读器
- 提供关闭动效的选项

### 7.4 向后兼容

- 不修改现有 light/dark 主题的任何代码
- 新增主题完全增量式
- 所有新属性均为可选
- 默认主题保持为 light，不影响现有用户
