# QMS 前端完善设计方案

**项目**: TOPEMS-QMS 质量管理模块前端
**版本**: v1.0
**日期**: 2026-06-06
**状态**: 待审核

---

## 1. 概述

### 1.1 背景
当前 QMS（Quality Management System）前端仅有基础的列表展示功能，缺少完整的 CRUD 操作、搜索筛选、详情查看和统计看板等功能。需要进行全面完善以提升用户体验和功能完整性。

### 1.2 目标
- 完善四个核心模块的 CRUD 功能（质量标准、质量检查、质量问题、纠正措施）
- 增强列表功能（搜索、筛选、分页）
- 添加详情查看面板
- 新增统计看板页面
- 统一组件和样式，提升代码复用性

### 1.3 技术栈
- React 18 + TypeScript
- Tailwind CSS
- React Router（路由管理）
- Recharts（图表）
- Headless UI 或自定义模态框

│   ├── QualityInspectionList.tsx   # 质量检查列表（增强）

### 2.2 组件设计原则
- **单一职责**：每个组件只负责一个功能
- **可复用性**：通用组件放置在 common 目录
- **一致性**：统一的表单验证、错误处理、加载状态

## 3. 功能详细设计

### 3.1 通用组件

#### 3.1.1 Modal 模态框
- 属性：`isOpen`, `onClose`, `title`, `size`
- 尺寸支持：`sm`, `md`, `lg`, `xl`
- 支持点击遮罩关闭
- 支持 ESC 键关闭

#### 3.1.2 FormModal 表单模态框
- 继承 Modal 的基本功能
- 额外属性：`onSubmit`, `loading`, `submitText`
- 包含取消和提交按钮
- 提交时显示 loading 状态

#### 3.1.3 SearchBar 搜索栏
- 属性：`onSearch`, `onFilterChange`, `filters`
- 支持关键词搜索输入
- 支持筛选条件下拉选择
- 搜索防抖处理（300ms）

#### 3.1.4 Pagination 分页组件
- 属性：`currentPage`, `pageSize`, `total`, `onChange`
- 显示：当前页 / 总页数
- 支持每页条数选择：10, 20, 50, 100
- 首页、上一页、下一页、末页按钮

#### 3.1.5 StatusBadge 状态徽章
- 属性：`status`, `statusMap`
- 预设状态样式（可扩展）
- 颜色映射表可配置

#### 3.1.6 ConfirmDialog 确认对话框
- 属性：`isOpen`, `title`, `message`, `onConfirm`, `onCancel`
- 用于删除等危险操作确认

#### 3.1.7 DetailDrawer 详情抽屉
- 从右侧滑出的面板
- 属性：`isOpen`, `onClose`, `title`, `data`
- 支持显示任意结构的数据
- 400px 宽度，可滚动

## 6. 错误处理

### 6.1 表单验证
- 必填字段为空时显示错误提示
- 输入框失焦时触发验证
- 提交时再次验证所有字段
- 错误信息显示在对应字段下方

### 6.2 API 错误处理
- 网络错误：显示 "网络连接失败，请重试"
- 401 未授权：跳转登录页
- 403 权限不足：显示 "您没有权限执行此操作"
- 404 资源不存在：显示 "数据不存在"
- 500 服务器错误：显示 "服务器错误，请稍后重试"

### 6.3 加载状态
- 列表加载：显示全屏 loading 指示器
- 表单提交：按钮显示 loading 状态，禁止重复提交
- 删除操作：显示确认对话框
