## 关键发现

1. **单点依赖**: 所有服务都依赖 Core (8000) 进行认证
2. **MES-PDM 强耦合**: 两者互相依赖，需部署在同一环境
3. **QMS-LIMS 关联**: QMS 创建质检单，可能需要调用 LIMS 检验
4. **ERP 核心地位**: ERP 是客户/供应商数据的主数据源
5. **BI/Report/Portal**: 聚合服务，依赖其他业务服务提供数据
6. **AI 已整合**: AI 能力已整合到 Core 平台，提供 chat/summarize/generate 等能力

## 启动顺序

```
1. Core (8000)           # 必须最先启动
2. Database (5432)       # Core 依赖

# 业务服务可并行启动
3. mes (8030) / pdm (8031)     # 生产套件
4. qms (8050) / lims (8051) / ehs (8052)  # 质量套件
```
