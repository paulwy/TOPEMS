# 健康检查组件使用指南

> 文档版本: v1.0
> 创建日期: 2026-06-08
> 最后更新: 2026-06-08

## 概述

`topems-shared` 库中的健康检查组件提供了标准化的健康检查功能，包括：
- 数据库健康检查
- 服务健康状态响应
- 运行时间统计
- 响应时间追踪

## 快速开始

### 1. 导入必要的组件

```rust
use topems_shared::{
    ServiceHealth, SimpleHealthConfig, simple_health_check
};
```

### 2. 在应用状态中添加健康配置

```rust
#[derive(Clone)]
struct AppState {
    pool: PgPool,
    auth_state: AuthState,
    health_config: SimpleHealthConfig,  // 添加这一行
}
```

### 3. 创建健康配置

在 main 函数中创建健康检查配置：

```rust
// 创建健康检查配置（不包含数据库）
let health_config = SimpleHealthConfig::new("my-service-name");

// 或者，创建包含数据库检查的健康配置
let health_config = SimpleHealthConfig::new("my-service-name")
    .with_db(pool.clone());
```

### 4. 在应用状态中包含健康配置

```rust
let app_state = AppState {
    pool: pool.clone(),
    auth_state: auth_state.clone(),
    health_config,
};
```

### 5. 创建健康检查路由处理函数

```rust
async fn health_check(State(app_state): State<AppState>) -> ServiceHealth {
    simple_health_check(&app_state.health_config).await
}
```

### 6. 在路由中添加健康检查端点

```rust
let public_routes = Router::new()
    .route("/health", get(health_check));
```

### 完整示例

见 `/services/report-service/src/main.rs` 中的完整实现。

## 响应格式

健康检查返回标准化的 `ServiceHealth` 结构：

```json
{
  "service_name": "topems-report",
  "status": "Healthy",
  "message": "topems-report is running",
  "timestamp": "2026-06-08T12:34:56Z",
  "uptime": "1h 30m 45s",
  "dependencies": [
    {
      "name": "database",
      "status": "Healthy",
      "message": "Database is healthy (23ms)"
    }
  ],
  "response_time_ms": 25,
  "last_check": "2026-06-08T12:34:56Z"
}
```

### 状态码

- **Healthy**: 200 OK
- **Degraded**: 200 OK（警告状态）
- **Unhealthy**: 503 Service Unavailable

## 可用的组件

### SimpleHealthConfig

健康检查配置结构体，包含：
- 服务名称
- 启动时间
- 可选的数据库连接池

### simple_health_check

执行标准健康检查的异步函数：
- 检查数据库连接（如果配置了）
- 计算响应时间
- 统计运行时间
- 返回完整的健康状态

### build_health_response

快速构建简单健康响应的函数：

```rust
let response = build_health_response("my-service", true);
```

## 进阶使用

### 自定义健康检查

你也可以直接使用 `ServiceHealth` 结构来完全自定义健康检查：

```rust
use topems_shared::{ServiceHealth, HealthStatus, DependencyHealth};

async fn custom_health_check() -> ServiceHealth {
    ServiceHealth {
        service_name: "my-service".to_string(),
        status: HealthStatus::Healthy,
        message: "服务正常运行".to_string(),
        timestamp: Utc::now().to_rfc3339(),
        uptime: Some("1h 23m".to_string()),
        dependencies: Some(vec![
            DependencyHealth {
                name: "redis".to_string(),
                status: HealthStatus::Healthy,
                message: "Redis连接正常".to_string(),
            }
        ]),
        response_time_ms: Some(15),
        last_check: Some(Utc::now().to_rfc3339()),
    }
}
```

### 添加自定义依赖项检查

你可以添加对其他服务的依赖检查：

```rust
use topems_shared::{DependencyHealth, HealthStatus};

async fn check_redis_health() -> DependencyHealth {
    // 实现你的 Redis 健康检查逻辑
    DependencyHealth {
        name: "redis".to_string(),
        status: HealthStatus::Healthy,
        message: "Redis连接正常".to_string(),
    }
}
```
