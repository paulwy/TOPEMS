## 1. 产品概述

### 1.1 TOPEMS 是什么

**TOPEMS** 是一套面向中大型企业的**一站式数字化运营平台**，覆盖从办公协同、生产制造、供应链管理到质量管控、研发管理、数据分析的全业务场景。

基于微服务架构和插件化设计，企业可以**按需选择模块、逐步扩展**，避免一次性投入过大，同时保证未来业务增长时系统能够平滑升级。

### 1.2 核心理念

| 理念 | 说明 |
|------|------|
| **一体化** | 一个平台管所有业务，不用在N个系统间切换、数据不通 |
| **渐进式** | 从1-2个模块开始，用起来再扩，降低决策风险 |
| **技术先进** | Rust 后端 + React 前端，性能强、体验好、安全可靠 |
| **AI 原生** | AI 能力深度融入每个业务场景，不是简单加个聊天框 |
| **灵活扩展** | 21个服务独立部署，想用哪个开哪个，也能定制开发 |

### 1.3 适用企业

- 员工规模：**100人以上**的中大型企业
- 行业：制造、医药、化工、电子、能源、建筑等（全行业适用，制造业基因最强）
- 痛点：多系统数据不通、信息化投入大但效果不好、想做数字化但不知道从哪下手

## 2. 核心价值主张

### 2.1 一句话电梯演讲

> **"TOPEMS 是一个能跟着企业一起长大的数字化平台——先从你最痛的地方用起，以后需要什么再加什么，不用推倒重来。"**

### 2.2 三大核心卖点

#### 卖点一：一体化平台，告别数据孤岛

**客户痛点**：上了 ERP 又上 CRM，上了 CRM 又上 MES，每个系统数据不通，报表要靠人工拼。

**我们的答案**：
- 21个模块**统一架构、统一认证、统一数据**
- 一个账号登所有，数据天然打通
- 报表直接跨模块取数，不用导 Excel

**一句话**：*"别人卖你一堆软件，我们给你一个平台。"*

---

#### 卖点二：渐进式上线，风险低、见效快

**客户痛点**：上一套大系统动辄半年一年，投入几百万，还不一定能用起来。

**我们的答案**：
- 从**最痛的1-2个模块**开始（比如质量管理或人力资源）
- **2-4周**就能上线第一个模块
- 用得好再继续加，**不用一次性赌上身家**
- 老系统数据可以平滑迁移

**一句话**：*"先上车再补票，用起来才是硬道理。"*

---

#### 卖点三：技术底子厚，未来不担心

**客户痛点**：买了套系统，用两年就跟不上了，想改改不了，想换换不起。

**我们的答案**：
- **Rust 后端**：性能是 Java 的 3-5 倍，服务器成本省一半
- **微服务架构**：21个服务独立，想加就加，想换就换
- **AI 原生**：本地大模型 + 向量搜索，数据不出门也能用 AI
- **开源可定制**：代码全给你，想怎么改怎么改，不绑死

**一句话**：*"今天够用，明天还能打，投资不打水漂。"*

### 2.3 给不同角色的价值

| 角色 | 最关心的 | 我们能给的 |
|------|---------|-----------|
| **老板/CEO** | 投入产出、战略价值 | 一体化平台，支撑未来5-10年发展 |
| **CIO/IT总监** | 技术选型、系统稳定性 | 先进技术栈，易维护，好扩展 |
| **业务部门** | 好不好用、能不能解决问题 | 模块按需选，快速落地见效 |
| **财务** | 成本控制、ROI | 渐进式投入，不用一次性花大钱 |

### 3.1 理想客户特征

| 维度 | 特征描述 |
|------|---------|
| **企业规模** | 员工 100-5000 人，年营收 5000 万 - 50 亿 |
| **行业** | 制造、医药、化工、电子、能源、食品饮料等流程/离散制造 |
| **信息化阶段** | 已经用过 1-2 套系统（如财务软件、OA），感受到痛点，想升级 |
| **决策特点** | 老板重视 + 有懂行的 IT 负责人 + 业务部门有意愿 |
| **预算范围** | 首年 10-100 万，后续逐年增加 |

### 3.2 典型切入场景（6个最容易成单的）

#### 场景一：质量管理升级
> 客户有 QMS 需求，或者还在用 Excel 管质量

**切入点**：QMS + LIMS + EHS 质量三件套
**价值**：从不合规到符合 ISO/GMP，质量成本下降 20%+
**决策链**：质量总监 → 生产副总 → 总经理

#### 场景二：人力资源数字化
> 客户还在用 Excel 算工资、管考勤

**切入点**：HRM 单模块
**价值**：人事效率提升 50%，考勤算薪零出错
**决策链**：HR 总监 → 总经理

#### 场景三：研发管理提效
> 客户有研发团队，项目进度不透明

**切入点**：RS 研发管理 + PDM 产品数据
**价值**：研发周期缩短 15%，文档版本不混乱
**决策链**：研发总监 → CTO/总经理

#### 场景四：供应链协同
> 客户供应商多，采购、库存、物流管理乱

**切入点**：SCM + WMS + SRM 供应链三件套
**价值**：库存周转率提升 20%，采购成本下降 10%
**决策链**：供应链总监 → 运营副总 → 总经理

#### 场景五：生产执行透明化
> 客户有工厂，生产进度靠人工报，不实时

**切入点**：MES 制造执行 + PDM 产品数据
**价值**：生产效率提升 15%，在制品减少 20%
**决策链**：生产总监 → 运营副总 → 总经理

#### 场景六：AI 赋能知识工作者
> 客户文档多、知识散，想试试 AI 但不知从哪下手

**切入点**：文档管理 + AI 知识库
**价值**：知识检索效率提升 3 倍，新人上手快一倍
**决策链**：IT 总监 → 知识管理部门 → COO

## 5. 核心功能与亮点

### 5.1 技术亮点（对 IT/技术负责人讲）

| 亮点 | 说明 | 客户价值 |
|------|------|---------|
| **Rust 高性能后端** | 比 Java 快 3-5 倍，内存占用少 80% | 服务器成本省一半，响应速度快 |
| **微服务架构** | 21个服务独立部署、独立扩展 | 想加哪个加哪个，不影响其他 |
| **React 19 前端** | 现代化 UI，响应式设计 | 体验好，上手快，移动端也能用 |
| **本地 AI + 向量搜索** | Ollama + pgvector，数据不出门 | 安全，又能用上 AI 能力 |
| **Schema 隔离** | 每个模块独立 Schema，互不干扰 | 数据安全，升级不打架 |
| **开源可定制** | 全代码交付，想改就改 | 不绑死，自主可控 |

### 5.2 各模块核心卖点

#### 🏭 QMS 质量管理
- **全流程质量闭环**：从质量计划 → 来料检验 → 过程检验 → 不合格品处理 → 改进措施
- **合规无忧**：满足 ISO 9001、IATF 16949、GMP 等体系要求
- **质量追溯**：一物一档，正向反向追溯，出了问题秒查

#### 🔬 LIMS 实验室管理
- **样品全生命周期**：采样 → 登记 → 分配 → 检验 → 审核 → 报告
- **仪器对接**：自动采集检验数据，减少人工录入
- **试剂耗材管理**：库存预警，效期管理，不浪费

#### 🌍 EHS 环境健康安全
- **风险分级管控**：辨识风险，分级管控，责任到人
- **隐患排查治理**：发现 → 整改 → 验收，闭环管理
- **应急管理**：应急预案、演练记录、事故处理

#### 👥 HRM 人力资源
- **员工全生命周期**：入职 → 试用 → 转正 → 调岗 → 离职
- **考勤薪酬一体化**：打卡、请假、加班自动算工资
- **组织架构管理**：部门、岗位、职级，一目了然

#### 🔬 RS 研发管理
- **项目全流程**：立项 → 计划 → 执行 → 评审 → 结项
- **文档管理**：研发文档版本控制，不混乱
- **专利管理**：专利申请、维护、费用提醒

#### 🏭 MES 制造执行
- **生产透明化**：订单进度、工序状态、设备效率，实时看
- **质量追溯**：每批产品用了什么料、谁做的、检没检，全知道
- **设备管理**：设备台账、维护保养、OEE 分析

#### 📦 WMS 仓储管理
- **条码/RFID 管理**：扫码出入库，准确率 99.9%
- **库位管理**：东西放哪了，系统告诉你
- **库存预警**：该补的补，该清的清，不积压

### 6.2 应对常见竞品的话术

#### 对比「用友/金蝶」等传统大厂

**客户说**："用友/金蝶是大品牌，你们小公司不靠谱。"

**应答思路**：
1. 肯定对方："用友金蝶确实是行业前辈，财务这块做得很深。"
2. 点出痛点："但他们的架构是 20 年前的，太重了，上个系统半年起，改个功能要等半年。"
3. 讲我们的优势：
   - "我们的架构更先进，微服务 + 插件化，想加什么加什么，不用推倒重来"
   - "实施快，2-4周就能看到效果，不用等半年"
   - "性价比高，同样的钱，我们能覆盖更多场景"
4. 给安全感："代码全交付，你们完全自主可控，不用担心我们倒了怎么办。"

**一句话**：*"选大牌子像买百货公司，什么都有但不一定合脚；选我们像定制西装，更合身、更灵活，还更便宜。"*

---

#### 对比「黑湖/质璇」等垂直 SaaS

**客户说**："人家 SaaS 便宜，还开箱即用。"

**应答思路**：
1. 肯定对方："SaaS 确实轻量，上手快，适合小团队。"
2. 点出痛点：
   - "但 SaaS 数据在人家服务器上，你们的核心数据放心吗？"
   - "而且按年付费，用 3 年花的钱比私有化还多，最后东西还不是你的"
   - "想定制？SaaS 改不了，只能忍着"
3. 讲我们的优势：
   - "私有化部署，数据全在你们自己手里"
   - "一次购买，终身使用，越用越划算"
   - "代码全给你，想怎么改怎么改"
   - "我们也有 SaaS 模式，灵活切换"

**一句话**：*"SaaS 像租房，每月交钱，最后房子不是你的；私有化像买房，一次投入，永远是你的。"*

---

#### 对比「定制开发」

**客户说**："我找个外包团队定制，完全按我的需求来。"

**应答思路**：
1. 肯定对方："定制开发确实灵活，想要什么做什么。"
2. 点出痛点：
   - "但定制开发周期长，半年一年很正常，中间需求变变更痛苦"
   - "外包团队做完就走，后期维护没人管，出问题找不到人"
   - "看起来便宜，实际上改改改，最后花的钱远超预期"
3. 讲我们的优势：
   - "我们有成熟的产品底座，80% 的功能开箱即用，20% 定制，又快又稳"
   - "产品持续迭代，你们也能免费升级，不用自己养团队维护"
   - "代码全交付，真要定制也完全可以，还比从零开发省 70% 时间"

**一句话**：*"从零定制像自己盖房子，费时费力还可能盖歪；用我们的平台像买精装修，拎包入住，想改也能改。"*

### 6.3 常见异议处理

| 异议 | 应答要点 |
|------|---------|
| **"太贵了"** | 拆分到每个模块、每个人头上算；对比竞品总价；讲 ROI（效率提升、成本节约） |
| **"我们还没准备好"** | 那就从一个模块开始，不用全上；先做试点，用起来再扩 |
| **"担心实施失败"** | 渐进式实施，风险低；有成功案例；有明确的实施方法论 |
| **"你们品牌不够大"** | 技术更先进（Rust/微服务）；代码全交付，自主可控；服务更灵活，大厂不会理你小需求 |
| **"我们有老系统"** | 支持数据迁移；支持系统集成；可以并行运行一段时间 |
| **"数据安全怎么办"** | 私有化部署，数据不出门；有完善的权限体系；有审计日志；支持等保 |

## 7. 定价策略

> ⚠️ 以下为建议定价框架，具体报价请根据实际情况调整

### 7.1 定价模式

#### 模式一：模块授权（推荐）
- 按模块收费，想用几个买几个
- 一次购买，终身使用
- 每年收 15-20% 服务费（升级 + 技术支持）

#### 模式二：按用户数
- 基础平台 + 按账号数收费
- 适合用户数少的企业
- 按年订阅或一次性购买

#### 模式三：SaaS 订阅
- 按月/按年付费
- 适合中小企业，不想自己运维
- 公有云或专属云

### 7.2 价格区间参考

| 版本 | 模块数 | 用户数 | 首年费用 | 年服务费 | 适合 |
|------|--------|--------|---------|---------|------|
| 入门版 | 1-2 | 50人内 | 10-20万 | 15% | 小型企业/试点 |
| 成长版 | 3-5 | 200人内 | 30-60万 | 18% | 中型企业 |
| 企业版 | 6-10 | 500人内 | 80-150万 | 20% | 中大型企业 |
| 集团版 | 全模块 | 不限 | 200万+ | 面议 | 集团/定制 |

### 7.3 报价策略

#### 报价三原则

1. **锚定高价**：先报全功能全模块的价格，让客户有个锚点
2. **按需删减**：根据客户预算和需求，往下减模块，让客户觉得"省了很多"
3. **打包优惠**：多买多折扣，3个模块9折，5个8折，10个7折

#### 费用构成

| 费用项 | 说明 | 占比 |
|--------|------|------|
| 软件授权费 | 模块授权费用 | 60-70% |
| 实施服务费 | 调研、配置、培训、上线 | 20-30% |
| 首年服务费 | 升级、技术支持 | 10-15% |
| 定制开发费（可选） | 按需定制功能 | 另计 |

### 7.4 折扣权限

| 角色 | 折扣权限 |
|------|---------|
| 销售 | 9折 |
| 销售经理 | 8折 |
| 总监/VP | 7折 |
| CEO | 特殊情况 |

> 低于底价需要特批，且不能只降价，要换东西（比如少服务、减模块、签更长年限）

## 8. 销售话术与 FAQ

### 8.1 开场破冰（30秒引起兴趣）

#### 话术一：痛点切入
> "王总，我们接触了很多制造企业，发现大家都有个头疼的问题——上了好几个系统，数据还不通，每个月做报表要好几个人拼 Excel。你们这边有没有类似的情况？"

#### 话术二：价值切入
> "李总，我们是做企业数字化平台的，跟别人不太一样的是，我们可以从你们最痛的一个模块开始上，2-4周就能看到效果，不用一下投入几百万。不知道你们现在哪块最头疼？"

#### 话术三：同行案例切入
> "张总，我们最近刚给 XX 行业的一家企业上了质量管理系统，他们的质量成本降了 20% 多。你们这块现在是怎么做的？"

### 8.2 需求挖掘（SPIN 提问法）

| 类型 | 示例问题 |
|------|---------|
| **现状问题** | 你们现在用什么系统？质量/生产/人力这块怎么管的？ |
| **痛点问题** | 现在这套方式，最让你头疼的是什么？出过什么问题吗？ |
| **影响问题** | 这个问题不解决，对你们的业务有什么影响？成本大概损失多少？ |
| **需求问题** | 如果有一套系统能解决这个问题，你最希望它帮你做到什么？ |

### 8.3 产品演示要点

**演示前必问的3个问题**：
1. "今天的参会人都有谁？各自关心什么？"
2. "你们最想通过这次演示了解什么？"
3. "目前这块是怎么做的？最大的痛点是什么？"

**演示原则**：
- 不讲全功能，只讲客户关心的 3-5 个场景
- 用客户的行业/业务举例，不要讲抽象概念
- 多问"你们平时是不是这样的？"，让客户参与进来
- 留 1/3 时间答疑和互动

### 8.4 常见问题 FAQ

#### 产品相关

**Q: 你们和用友/金蝶有什么区别？**
> A: 用友金蝶财务很强，但生产、质量、供应链这些就弱了，而且架构重，实施周期长，改起来费劲。我们是一体化平台，21个模块全在一个架构上，数据天然打通，而且是微服务架构，想加哪个加哪个，灵活得多。

**Q: 支持私有化部署吗？**
> A: 支持，而且我们本来就是私有化为主。代码全交付，数据全在你们自己服务器上，安全可控。

**Q: 能对接我们现有的系统吗？**
> A: 可以的，我们有标准的 API 接口，也支持数据库直连、消息队列等方式对接。实施的时候我们会做调研，给出对接方案。

**Q: 支持移动端吗？**
> A: 支持，有 H5 移动端，也支持 PWA，手机浏览器直接用，不用装 APP。也可以做小程序和原生 APP 定制。

#### 实施相关

**Q: 实施周期多长？**
> A: 看模块多少。1个模块 2-4 周，3-5个模块 2-3 个月，全模块 6 个月左右。我们是渐进式实施，第一个模块上线就能用起来，不用等全部做完。

**Q: 需要我们投入多少人？**
> A: 关键用户（每个模块 1-2 个懂业务的人）+ IT 对接人（1 个）。不用全脱产，每周投入 10-20 小时就行。

**Q: 数据能从老系统迁过来吗？**
> A: 可以的，我们有数据迁移工具和方案。老系统的数据导出来，我们做清洗、转换，再导入新系统。迁移前会先测试，确保数据准确。

#### 服务相关

**Q: 出了问题多久能响应？**
> A: 工作时间 2 小时内响应，紧急问题 30 分钟内响应。有专门的技术支持团队，也可以安排驻场。

**Q: 系统升级怎么办？**
> A: 我们每季度会有版本更新，购买了服务费的客户可以免费升级。升级不影响现有数据，有完整的迁移方案。

**Q: 你们公司要是倒了怎么办？**
> A: 这个担心很正常。我们是全代码交付的，代码都在你们手里，就算我们不做了，你们自己也能维护，或者找其他团队接。而且我们也提供 escrow 服务（代码存放到第三方托管）。

## 9. 销售流程与工具

### 9.1 销售七步法

```
线索获取 → 初步沟通 → 需求调研 → 方案演示 → 报价谈判 → 签约成交 → 交付实施
   1          2          3          4          5          6          7
```

#### 第1步：线索获取
- **目标**：找到有需求的潜在客户
- **动作**：市场活动、转介绍、官网、渠道伙伴
- **产出**：有效线索（有痛点、有预算、有决策权）

#### 第2步：初步沟通
- **目标**：确认需求真实性，约到下一步
- **动作**：电话/微信沟通，了解基本情况
- **产出**：预约演示/调研会议
- **关键问题**：现在怎么做的？有什么痛点？谁负责？大概预算？

#### 第3步：需求调研
- **目标**：深入了解业务痛点和决策链
- **动作**：现场拜访/线上会议，跟业务部门聊
- **产出**：需求调研报告（痛点、目标、范围）
- **关键**：见到最终决策者和业务使用者

#### 第4步：方案演示
- **目标**：展示产品价值，获得认可
- **动作**：定制化产品演示，针对痛点讲
- **产出**：演示反馈、下一步计划
- **关键**：让客户说"这个正是我们需要的"

#### 第5步：报价谈判
- **目标**：达成价格和合作条款一致
- **动作**：出方案报价、谈判、砍价应对
- **产出**：双方认可的报价和方案
- **关键**：不轻易降价，降价要换东西（年限/服务/模块）

#### 第6步：签约成交
- **目标**：签合同、收款
- **动作**：合同审核、走流程、签约
- **产出**：签约合同、首付款
- **关键**：趁热打铁，别拖

#### 第7步：交付实施
- **目标**：成功上线，客户满意
- **动作**：实施团队进场，按计划交付
- **产出**：上线验收、回款
- **关键**：销售要跟到底，确保客户成功，争取续费和转介绍
