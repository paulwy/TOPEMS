# TOPEMS AI 智造助手 —— 报名帖

> 参赛赛道：社会服务  
> 作品类型：Web 应用 / 移动端 PWA  
> 开发工具：TRAE IDE + TRAE Work

---

## 1. 创意名称 + 创意介绍

**创意名称：TOPEMS AI 智造助手**

**想解决什么问题：**
制造业一线工人每天面对复杂的设备操作、繁琐的质量检验流程，但企业知识分散在纸质手册、Excel 表格和老旧系统中。新员工培训周期长，老师傅经验难以沉淀，质量问题发生时找不到历史案例参考，导致效率低、出错率高、事故风险大。

**为什么会想到做这个：**
我们团队长期服务制造企业，发现车间里最常见的场景是：工人围着一台报警的设备手足无措，质检员拿着产品对照着厚厚的检验标准书逐项核对，班组长每天被重复的问题咨询淹没。而企业花了大价钱上的 ERP/MES 系统，工人根本不会用。我们想让 AI 成为每个工人口袋里触手可及的"老师傅"。

**大概是什么产品：**
一款面向制造业一线工人的 AI 智能助手 Web 应用（支持 PWA 离线使用），基于自然语言对话和图像识别，让工人"说话就能查操作、拍照就能判质量"，并自动关联企业内部的 SOP、工艺文件和历史案例。

---

## 2. 目标用户及痛点

**面向哪些用户：**
- 制造业一线操作工人（车工、钳工、焊工、装配工等）
- 质量检验员（IQC、IPQC、OQC）
- 班组长/线长（日常管理、异常处理）
- 新员工（快速上岗培训）

**在什么场景下使用：**
- 设备报警时，工人需要快速知道如何处理
- 换线生产时，工人需要确认新产品的工艺参数
- 质检时，检验员需要对照标准判定是否合格
- 发现异常时，班组长需要查询历史类似案例
- 新员工入职时，需要学习岗位操作规范

**当前痛点：**
- 纸质 SOP 翻找耗时，版本更新不及时
- 老师傅经验"只会在脑子里"，退休后带走
- 质量问题重复发生，没有知识沉淀
- 现有 ERP/MES 系统太复杂，工人不会用
- 培训成本高，新员工上手慢

---

## 3. 价值与意义

**效率提升：**
- 问题查询从"翻书10分钟"变为"对话10秒钟"
- 新员工培训周期从 2 周缩短至 3 天
- 质量判定效率提升 60%，减少人为误判

**社会价值：**
- 帮助制造业工人跨越"数字鸿沟"，用自然语言与系统交互
- 沉淀老师傅的隐性知识，避免人才流失造成的技能断层
- 降低生产事故率，保障工人职业安全
- 助力中国制造从"人口红利"向"知识红利"转型

**商业价值：**
- 企业质量成本下降 15-20%
- 培训成本降低 50%
- 设备停机时间减少 30%
- 以 SaaS 模式服务中小制造企业，年费 2-5 万/企业

---

## 4. 为什么选择 TRAE

本项目基于我们自研的 TOPEMS 企业数字化平台开发，使用 TRAE IDE 的 AI 助手能力：
- 用自然语言生成 Rust API 接口和 React 前端组件
- AI 辅助完成向量搜索索引设计和 RAG 流程实现
- 通过 TRAE Work 快速生成产品原型和交互设计
- 大幅缩短从创意到可运行 Demo 的开发周期

---

## 5. 技术亮点

- **Rust 高性能后端**：响应速度 < 100ms，支持高并发车间场景
- **本地大模型 + 向量搜索**：Ollama 本地部署，数据不出厂，保障企业隐私
- **RAG 检索增强**：精准匹配企业私有知识库，避免 AI 幻觉
- **PWA 离线支持**：车间网络不稳定也能正常使用
- **多模态交互**：支持语音输入、拍照识别、自然语言对话
