### 1.4 豁免登记（DB-03 核心交付）

#### A. `crm.customer_segments`

| 项 | 现状（本地实测） |
|---|---|
| 表结构 | `id uuid PK`、`name text NOT NULL`、`description text`、`criteria jsonb`、`customer_count bigint default 0`、`created_at/updated_at timestamptz`、`name_en varchar(255)`、`deleted_at timestamptz` |
| tenant_id 列 | **无** |
| RLS | **未启用**（`relrowsecurity=f`，无任何 policy） |
| 现有索引 | 仅 `customer_segments_pkey(id)` |
| 应用层 | 审计报告 P1 级：代码全局无租户过滤（全局共享设计） |
| **RLS 风险** | 任意租户可读写全部分组；若未来按租户分组客户，将跨租户泄露/串改。当前因产品定位为**全局共享客户分群**，风险可接受。 |
| **处置** | **豁免登记（不改结构）**。待产品确认：① 是否维持全局共享；② 若需租户隔离，再行补 `tenant_id uuid NOT NULL` + RLS（含 FORCE）+ 数据回填。 |
| 关联 | `crm.customer_recommendations`（同一未隔离簇） |

#### B. `crm.customer_recommendations`

| 项 | 现状（本地实测） |
|---|---|
| 表结构 | `id uuid PK`、`customer_id uuid`、`customer_name text`、`recommendations jsonb`、`recommendation_type text`、`model text default 'TOPEMS-AI'`、`confidence numeric(5,2)`、`created_at timestamptz`、`deleted_at timestamptz` |
| tenant_id 列 | **无**（仅 `customer_id` 软关联客户） |
| RLS | **未启用**（`relrowsecurity=f`） |
| 现有索引 | `customer_recommendations_pkey(id)` + `idx_crm_customer_recommendations_customer(customer_id)` |
| **RLS 风险** | AI 推荐结果按 `customer_id` 反查；无 tenant_id 时，若 `customer_id` 跨租户可枚举，则推荐记录可跨租户读取。当前依赖应用层按客户隔离。 |
| **处置** | **豁免登记（不改结构）**。待产品确认：推荐结果是否租户私有；若是，补 `tenant_id`（可由 `customer_id` 反查 `crm.core_crm_customers.tenant_id` 回填）+ RLS。 |
| 关联 | 随 `customer_segments` 一并决策。 |

### 2.2 已补项（本分片新增迁移）

迁移文件：**`database/migrations/20261023000020_erp_biz_unique_constraints.sql`**

| # | 约束名 | 表 | 键 | 说明 |
|---|---|---|---|---|
| 1 | `suppliers_tenant_id_code_key` | `erp.suppliers` | `(tenant_id, code)` | 租户内供应商编码唯一 |
| 2 | `materials_tenant_id_code_key` | `erp.materials` | `(tenant_id, code)` | 租户内物料编码唯一 |
| 3 | `purchase_orders_tenant_id_order_no_key` | `erp.purchase_orders` | `(tenant_id, order_no)` | 租户内采购订单号唯一 |

实现要点：
- **幂等**：每段 `DO $$ ... IF NOT EXISTS (pg_constraint ...) THEN ...`，重放 no-op。
- **存量安全**：先 `GROUP BY ... HAVING count(*)>1` 检测重复，有重复则 `RAISE NOTICE` 跳过，**绝不因存量脏数据在生产硬失败**；清洗后重放即可。
- **可空兼容**：三表 `tenant_id` 可空，Postgres 唯一约束视 NULL 互异，与现网可空设计兼容。
- 本地 `BEGIN; \i; ROLLBACK;` 空跑验证：3 约束建成、二次执行幂等无报错、已回滚未持久化。
