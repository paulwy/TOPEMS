## 二、草稿 1：srm.supplier_users 供应商账号映射

### 背景
上轮 srm supplier_portal 拆分后，供应商账号级自助需要 supplier→user 映射。
实测（topems_test，只读）：`srm.suppliers` 共 24 列，只有
`contact_person / phone / email` 文本联系信息，**无任何 user_id 列**；
`srm.suppliers` 已 ENABLE + FORCE RLS；`iam.users` 存在。

### 核心 SQL 摘要
- `CREATE TABLE IF NOT EXISTS srm.supplier_users`：
  `id uuid PK default gen_random_uuid()`、`supplier_id uuid NOT NULL FK→srm.suppliers(id) ON DELETE CASCADE`、
  `user_id uuid NOT NULL`（暂未建 FK）、`tenant_id uuid NOT NULL`、
  `role varchar(32) default 'contact'`、`status varchar(16) default 'active'`、
  `created_at/updated_at/deleted_at`。
- 部分唯一索引 `supplier_users_tenant_supplier_user_key (tenant_id, supplier_id, user_id) WHERE deleted_at IS NULL`。
- RLS ENABLE + FORCE：
  - `tenant_isolation_supplier_users`：`tenant_id = COALESCE(NULLIF(current_setting('app.tenant_id',true),'')::uuid, 全零uuid)`；
  - `supplier_scope_supplier_users`（SELECT）：`supplier_id = app.supplier_id` GUC 草案。

### 待确认清单（产品 / 财务 / 安全）

- [ ] Q2 是否回写 `srm.suppliers` 加 `primary_contact_user_id`（当前倾向不加）。
- [ ] Q3 `user_id` 是否 `REFERENCES iam.users(id)`（视门户账号是否都在 iam.users）。
- [ ] Q4 认证 GUC 方案：`app.tenant_id + app.supplier_id` 双 GUC，还是仅 tenant_id、supplier 范围走应用层。
- [ ] Q5 一个 user 是否允许绑定多家供应商（当前唯一约束允许一人多户；若要求一人一户需再加 `UNIQUE (tenant_id, user_id)`）。

## 三、草稿 2：erp.financial_vouchers 凭证号唯一索引

### 背景与勘误
`database/migrations/20261023000020_erp_biz_unique_constraints.sql` 注释已登记候选键
`(tenant_id, period, voucher_number)`，口径待财务确认。

- 实测列：`tenant_id uuid 可空`、`period varchar NOT NULL`、`voucher_number varchar NOT NULL`、
  `deleted_at timestamptz 可空`、`organization_id uuid NOT NULL`、`status varchar default 'draft'`。

```sql
CREATE UNIQUE INDEX IF NOT EXISTS uq_finance_voucher_tenant_period_no
    ON erp.financial_vouchers (tenant_id, period, voucher_number)
    WHERE deleted_at IS NULL;
```
