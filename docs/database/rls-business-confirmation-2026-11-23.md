## 5. W13 业务归属清单与四条规则

> 适用：订单（销售订单、采购订单）与客户的公司归属回填，以及搜索投影切换。第一段只做结构与双写；第二段（回填 → 零空值 → 影子比对 → 切换 → 下线）未获以下回复前不开跑。

### 5.1 归属清单字段要求（可直接转业务）

CSV 表头固定三列 `entity_type,entity_id,company_id`，一行一实体：

| 字段 | 要求 |
|---|---|
| `entity_type` | 取值仅限 `sales_order` / `purchase_order` / `customer` |
| `entity_id` | 对应源表主键 UUID |
| `company_id` | 必须属于该实体所在租户的公司（`hrm.companies`），不得跨租户 |
| 行约束 | 一行一实体；脚本不推断、不猜公司；同一实体重复且公司冲突时拒绝执行 |

### 5.2 四条归属规则（问题 + 选项，待回执）

**规则 1：有客户 / 供应商的订单，公司归属按哪个口径？**

- ☐ A. 一律按客户 / 供应商所属公司
- ☐ B. 按订单创建时的操作公司
- ☐ C. 其他（请写）
- 卡住：W13 第二段回填。不回复后果：清单无法定稿，回填不启动。

**规则 2：无客户或跨公司单据如何归属？历史缺公司上下文的如何处理？**

- ☐ A. 按创建时请求的公司上下文兜底；历史缺上下文的先补全再切换
- ☐ B. 统一归母公司；历史缺上下文的归母公司
- ☐ C. 其他（请写处理方式）
- 卡住：W13 第二段回填与切换。不回复后果：这部分订单保持空归属，第二段不切换。

**规则 3：无法判定的历史行如何处理？**

- ☐ A. 允许源表先留空，补全后再切换（切换前必须无空值）
- ☐ B. 归母公司
- ☐ C. 指定主办公司（请写规则）
- ☐ 其他（请写）
- 卡住：W13 第二段回填与零空值校验。不回复后果：无法进入切换，第二段挂起。
