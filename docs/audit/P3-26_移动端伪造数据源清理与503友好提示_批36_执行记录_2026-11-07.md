## 3. 503 处理位置与文案

公共判别（两处各自内联一份，避免跨模块依赖）：

- `useMobileProduction.ts:26–36` `isServiceUnavailableError(err)`：判定 `err.response?.status === 503 || err.response?.data?.code === 503 || err.code === 503`
- `MobileAttendancePage.tsx:54–68` `isAttendanceServiceUnavailableError(err)`：同上

写操作 onError 分支：

| 位置 | 触发端点 | 503 提示标题 / 文案（i18n key） |
|---|---|---|
| `useMobileProduction.ts:171–180` | `submitWorkReport` | `mobile.production.message.service_unavailable_title` / `_desc` |
| `useMobileProduction.ts:225–234` | `startOrder` / `pauseOrder` | 同上 |
| `MobileAttendancePage.tsx:153–160` | `checkIn` | `mobile.mobile_attendance_page.service_unavailable_title` / `_desc` |
| `MobileAttendancePage.tsx:210–217` | `checkOut` | 同上 |
| `MobileAttendancePage.tsx:266–273` | `applyLeave` | 同上 |

中文文案（zh/mobile.json）：

- 生产：「生产服务未接入」/「生产服务未接入，操作未执行。请稍后再试或联系管理员。」
- 考勤：「考勤服务未接入」/「考勤服务未接入，操作未执行。请稍后再试或联系管理员。」

503 时 `addNotification({ type: 'warning' })`，**未**进入 `onSuccess`，**未**更新缓存，**未**关 dialog；通用 `type:'error'` 分支仅在非 503 错误时触发。

## 4. 空态「服务未接入」vs「查无数据」区分

读接口返回 200 + `message` 含「未接入」时，前端在 `queryFn` 内置位（`setItemsNotConnected(true)` 等），EmptyState 标题/描述切换为 `*_not_connected_title / _desc` 变体：

- 库存 4 tab × 2 套文案（`empty_material_*` / `empty_stocktake_*` / `empty_inbound_*` / `empty_outbound_*`）
- 生产 3 tab × 2 套文案（`empty_orders_*` / `empty_reports_*` / `empty_equipment_*`）

判定关键字：`未接入` / `upstream` / `not connected`（与后端 message 对齐）。
