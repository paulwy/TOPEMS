## 四、`erp.search` 供应商读取修正

### 修正前

`svc/erp/src/modules/search.rs:160` 读 `erp.core_erp_suppliers`——该表 0 writer 0 reader，**全局搜索供应商结果恒为空**。

### 修正后

```sql
SELECT id, name as title, description, module, path, type_name
FROM (
    SELECT id, name,
           COALESCE(NULLIF(email, ''), NULLIF(phone, ''), name) as description,
           'supplier' as module,
           '/srm/suppliers' as path, '供应商' as type_name,
           supplier_no,
           ROW_NUMBER() OVER (PARTITION BY supplier_no ORDER BY (src = 'scm') DESC) as rn
    FROM (
        SELECT id, supplier_no, name, email, phone, 'scm' as src
        FROM scm.suppliers WHERE deleted_at IS NULL AND (...)
        UNION ALL
        SELECT id, supplier_no, name, email, phone, 'srm' as src
        FROM srm.suppliers WHERE deleted_at IS NULL AND (...)
    ) u
) ranked
WHERE rn = 1
LIMIT $2
```

- **去重键**：`supplier_no`，`ROW_NUMBER ... ORDER BY (src = 'scm') DESC` → **scm 优先**
- **软删**：两表均加 `deleted_at IS NULL`
- **宏白名单**：`only_own_schema_query!("erp", sql, "scm", "srm")`（客户段 `"crm"` 保持不动）
- **description**：`COALESCE(NULLIF(email,''), NULLIF(phone,''), name)` 三级回退
- **path**：保留 `/srm/suppliers`（前端路由不变）

### 跨 schema 合规性（前置已确认）

- `only_own_schema_query!`（`lib/shared-boundary/src/lib.rs:288`）第三段起是**变长 extra schema 列表**（`Parse` 实现 `while input.peek(Token![,])`），`DEFAULT_SHARED_SCHEMAS = ["public","unified_core","information_schema"]`（`:192`），erp 读 crm/scm/srm 必须显式列出 → 已列出，合规
- RLS：`scm.suppliers` / `srm.suppliers` 均 `relrowsecurity=t` + `relforcerowsecurity=t`，且两表 `tenant_id IS NULL` **均为 0 行**（NULL 放行分支不构成跨租户泄露）
