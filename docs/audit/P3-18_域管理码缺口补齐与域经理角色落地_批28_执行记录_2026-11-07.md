## 三、额外发现并修复：域管理码授权不一致（13 个新缺口）

### 3.1 实测发现

可达性实测的路由码从批 27 的 379 增至 **395**（并行会话新增 master-data / lims test-method 相关路由），暴露 **13 个 admin 不可达的路由码**，全部零持有：

| 码 | 根因 |
|---|---|
`master-data` 11 个 `:read`（data-asset / schema / lineage / quality / governance / semantic / versioning / knowledge / disaster / commercial / ai_governance） | `master-data:admin` 存在但仅 superadmin 持有 → admin 无通配 |
`lims:test-method:read` | `lims:admin` 存在但仅 superadmin 持有 → admin 无通配 |
`admin:iam:dashboard:approve` | 四段码，模块=admin；`admin:admin` / `admin:iam:admin` 均不存在，`iam:admin` 通配不覆盖四段码 |

### 3.2 一致性复核（顺带发现）

查全部 manager 是否持自家域 `X:admin`：**erp_manager / lims_manager / pdm_manager / srm_manager 四个既有 manager 不持有**，而其余 14 个 manager 均持有。同为域经理却能力不一致，域内新增码时不会自动覆盖。

### 3.3 修复（迁移 `20261107000023`，只补授权不建码）

| 码 | 授给 |
|---|---|
`lims:admin` | admin, lims_manager |
`master-data:admin` | admin |
`erp:admin` | erp_manager |
`pdm:admin` | admin, pdm_manager |
`srm:admin` | admin, srm_manager |
`admin:iam:dashboard:approve` | admin, superadmin |

`INSERT 0 8` + 补跑 `INSERT 0 2`（pdm/srm 的 admin 首版漏配，已修正），二次全 0。
