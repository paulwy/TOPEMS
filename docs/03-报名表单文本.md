## 二、创意简介（200字以内）

TOPEMS AI 智造助手是一款面向制造业一线工人的智能助手，基于自然语言对话和图像识别技术，让工人"说话就能查操作、拍照就能判质量"。产品基于团队自研的 TOPEMS 企业数字化平台，采用 Rust + React 技术栈，集成 Ollama 本地大模型和向量搜索，构建企业私有知识库 RAG 系统，实现精准的设备操作指导、质量判定辅助和历史案例查询，帮助制造业工人跨越数字鸿沟，沉淀老师傅经验，助力中国制造转型升级。

---

## 三、解决的问题（150字以内）

制造业一线工人面临知识获取难、经验传承难、系统使用难三大痛点。企业 SOP 分散在纸质文档中，老师傅经验难以沉淀，传统 ERP/MES 系统工人不会用。本产品通过 AI 智能问答、拍照质检、语音播报等功能，让工人用自然语言与系统交互，快速获取操作指导和质量标准，将问题查询从"翻书10分钟"缩短至"对话10秒钟"。

---

## 四、目标用户（100字以内）

制造业一线操作工人（车工、钳工、焊工、装配工）、质量检验员（IQC/IPQC/OQC）、班组长/线长、新员工。核心场景包括设备报警处理、换线工艺确认、质量检验判定、异常案例查询、新员工上岗培训等。

---

## 五、核心价值（150字以内）

**效率提升**：问题查询从10分钟缩短至10秒，新员工培训周期从2周缩短至3天，质量判定效率提升60%。

**社会价值**：帮助3.8亿制造业工人跨越数字鸿沟，沉淀老师傅隐性知识，降低生产事故率，助力中国制造从"人口红利"向"知识红利"转型。

**商业价值**：企业质量成本下降15-20%，培训成本降低50%，以SaaS模式服务中小制造企业。

## 六、技术亮点（150字以内）

- **Rust 高性能后端**：响应速度 < 100ms，支持高并发车间场景
- **本地大模型 + 向量搜索**：Ollama 本地部署，数据不出厂，保障企业隐私
- **RAG 检索增强**：精准匹配企业私有知识库，避免 AI 幻觉，答案附带出处
- **PWA 离线支持**：车间网络不稳定也能正常使用
- **多模态交互**：支持语音输入、拍照识别、自然语言对话

## 七、使用 TRAE 的过程（200字以内）

本项目充分使用 TRAE 工具链完成开发：

1. **TRAE Work**：完成产品创意构思、赛道选择和原型设计，通过多轮对话明确产品定位和功能边界
2. **TRAE IDE AI 助手**：自然语言生成 Rust API 接口代码，包括知识库查询、向量搜索、RAG 流程等核心模块
3. **TRAE IDE AI 助手**：生成 React 前端组件，包括语音交互界面、拍照上传组件、对话聊天窗口
4. **TRAE IDE AI 助手**：完成 PostgreSQL + pgvector 向量索引设计和优化
5. **效率提升**：开发效率提升约 60%，从创意到可运行 Demo 仅需 2 周
