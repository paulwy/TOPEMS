## 维护指南

### 日常维护

1. **新增页面**：必须使用 PageContainer
2. **路由变更**：同步更新 NavigationRegistry
3. **组件复用**：优先使用页面模板
4. **TypeScript**：保持编译无错误

### 定期检查

1. **每周**：运行 TypeScript 编译检查
2. **每月**：运行页面规范检查脚本
3. **每季度**：审视导航结构

### 文档更新

- 代码变更时更新相关文档
- PR 包含文档更新
- 定期审视文档准确性
