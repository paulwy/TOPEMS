## 三、页面模板规范

### 3.1 四种核心页面模板

#### 1. DashboardTemplate (仪表盘)

**适用场景**: 模块首页概览、数据统计分析、快捷操作入口、最近事项展示

**必需元素**:
- 页面标题
- 面包屑导航
- 统计卡片 (2-6个)
- 快捷操作 (4-8个)
- 最近事项 (5-10条)

**可选元素**:
- 图表区域
- 数据可视化

**路由**: `/module`

**示例文件**: `pages/finance/DashboardPage.tsx`

---

#### 2. DetailPageTemplate (详情页)

**适用场景**: 查看单条数据详情、包含多个信息维度、需要Tab切换不同内容区域、需要编辑、删除等操作

**必需元素**:
- 页面标题
- 面包屑导航
- 返回按钮
- 信息卡片 (展示核心信息和统计数据)
- Tab切换 (1-5个)
- 编辑/删除按钮

**可选元素**:
- 自定义操作按钮
- 操作日志Tab

**路由**: `/module/entities/:id`

**示例文件**: `pages/finance/VoucherDetailPage.tsx`

---

#### 3. FormPageTemplate (表单页)

**适用场景**: 新建数据记录、编辑已有数据、复杂的数据录入表单

**必需元素**:
- 页面标题 ("新建" 或 "编辑" + 实体名称)
- 面包屑导航
- 表单Section (按逻辑分组)
- 必填字段标记 (*)
- 提交/取消按钮
- 表单验证

**可选元素**:
- 帮助文本
- 实时验证提示
- 提交Loading状态

**路由**:
- 新建: `/module/entities/create`
- 编辑: `/module/entities/:id/edit`

**示例文件**: `pages/finance/VoucherCreatePage.tsx`

---

#### 4. ListPageTemplate (列表页)

**适用场景**: 展示数据列表、搜索筛选排序、批量操作、分页浏览

**必需元素**:
- 页面标题 (实体名称 + "列表")
- 面包屑导航
- 搜索框
- 数据表格
- 行操作按钮 (查看、编辑、删除)
- 分页组件

**可选元素**:
- 高级筛选
- 批量操作
- 导出功能
- 选择功能

**路由**: `/module/entities`

**示例文件**: `pages/crm/CustomerManagementPage.tsx` (待重构)

### 6.2 Header导航配置

在 `navigation.ts` 或 `navigation-v2.ts` 中添加:

```typescript
{
  label: '财务',
  path: '/finance',
  icon: <DollarSign />,

```

## 十一、经验总结

### 11.1 成功经验

1. **模板化设计**: 通过统一的页面模板,大幅提高了开发效率和代码一致性
2. **示范先行**: 先创建完整示例,再推广到其他页面,确保了规范的可行性

4. **渐进式实施**: 分优先级实施,确保了核心功能的优先完成

1. **持续集成**: 建议添加自动化测试,确保页面质量
