## 🔧 技术实现细节

### 1. LIMS 仪器管理
- 使用独立的仪器标签页，与样品、流程、任务并列
- 仪器状态通过颜色标签区分（绿色-正常，橙色-维修中，蓝色-校准中，红色-报废）
- 维护记录采用独立模态框管理
- 校准日期自动提醒显示

### 2. RS 配方管理
- 配方管理作为独立的第三标签页
- 支持配方与项目的关联
- 版本管理功能支持配方的迭代更新
- 审批流程支持配方的审核确认
- 配方成分和工艺流程详细记录

## 📝 使用说明

### LIMS 仪器管理
1. 访问 LIMS 模块
2. 点击"仪器管理"标签页
3. 可进行以下操作：
   - 添加新仪器
   - 编辑仪器信息
   - 查看仪器详情
   - 添加维护记录
   - 删除仪器

### RS 配方管理
1. 访问 RS 模块
2. 点击"配方管理"标签页
3. 可进行以下操作：
   - 添加新配方
   - 编辑配方信息
   - 查看配方详情
   - 管理配方版本
   - 审批配方
   - 删除配方
