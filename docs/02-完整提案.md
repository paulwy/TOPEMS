## 二、创意背景

### 2.1 行业痛点

中国制造业从业人员约 3.8 亿，其中一线工人占比超过 60%。然而，绝大多数工人面临以下困境：

- **知识获取难**：企业内部的 SOP、工艺文件、质量标准分散在纸质文档、Excel、老旧系统中，查找耗时
- **经验传承难**：老师傅的隐性经验"只会在脑子里"，退休后带走，新员工上手慢
- **系统使用难**：传统的 ERP/MES 系统界面复杂、操作繁琐，一线工人根本不会用
- **问题处理慢**：设备报警、质量异常时，缺乏快速查询和历史案例参考的手段

### 2.2 市场机会

- 中国中小制造企业超过 300 万家，其中 80% 数字化程度低
- 制造业培训市场规模超过 2000 亿元/年
- 工业 AI 应用市场年增长率超过 40%
- 国家政策大力支持"智能制造"和"产业工人队伍建设"

### 2.3 灵感来源

我们团队长期服务制造企业，在一次客户拜访中目睹了这样的场景：

> 一位 50 多岁的车工老师傅，面对一台新引进的智能数控机床报警，翻遍了厚厚的纸质手册也找不到解决方案。最后只能停工等待技术员从办公室过来处理，整整耽误了 2 小时。

而在另一个车间，一位质检员拿着产品对照着 30 多页的质量标准书逐项核对，一个批次就要花掉 40 分钟。

我们意识到：企业花了大价钱上的数字化系统，最终用户——一线工人——根本用不起来。**技术再先进，如果工人不会用，就是零价值。**

于是，我们决定做一款"工人友好"的 AI 助手，让最不懂技术的人也能享受技术带来的便利。

## 三、产品方案

### 3.1 产品定位

**一句话定位**：制造业一线工人的"随身智能导师"

**核心价值主张**：
- 说话就能查 —— 自然语言查询设备和工艺信息
- 拍照就能判 —— 图像识别辅助质量判定
- 经验能沉淀 —— 老师傅知识自动入库，新人随时学

### 3.2 核心功能

#### 功能一：AI 智能问答

| 场景 | 用户提问 | AI 回答 |
|------|---------|---------|
| 设备操作 | "CNC-003 换刀步骤是什么？" | 分步语音播报 + 图文 SOP |
| 工艺参数 | "这款产品焊接温度要求多少？" | 自动定位工艺文件中的参数 |
| 异常处理 | "设备报警 E-204 怎么处理？" | 历史案例 + 处理步骤 |
| 质量标准 | "这个划痕允许多深？" | 引用质量标准条款 |

**技术实现**：基于 TOPEMS 的 Ollama 本地大模型 + pgvector 向量搜索，构建企业私有知识库 RAG 系统。

#### 功能二：拍照质检助手

- 工人拍摄产品照片
- AI 自动识别产品类型和检测部位
- 对照质量标准进行初步判定
- 标记疑似缺陷，提示人工复核重点

**技术实现**：调用视觉大模型进行图像分析，结合企业质量标准库进行规则校验。

#### 功能三：SOP 语音播报

- 查询到的操作步骤支持语音播报
- 解放双手，边听边操作
- 支持倍速播放和分段重复

#### 功能四：知识沉淀

- 老师傅处理异常后，AI 自动提取关键步骤生成案例
- 经审核后入库，成为后续问答的知识来源
- 形成"问题 → 解决 → 沉淀 → 复用"的闭环

#### 功能五：学习路径

- 根据岗位自动生成学习计划
- 新人完成学习后自动考核
- 学习进度与上岗资质挂钩

### 3.3 产品形态

- **Web 应用**：适配车间大屏、平板、手机
- **PWA 支持**：可离线使用，网络恢复后自动同步
- **语音优先**：支持语音输入和播报，减少文字输入
- **大字体/高对比度**：车间环境友好设计

## 四、目标用户画像

### 用户一：张师傅（52岁，车工）

- **背景**：30 年车工经验，不太会用智能手机，对电脑一窍不通
- **痛点**：新引进的智能设备不会操作，培训时记不全，经常要麻烦年轻技术员
- **使用场景**：设备报警时，对着手机说"这个报警怎么处理"，AI 语音播报解决步骤

### 用户二：小李（24岁，质检员）

- **背景**：入职 6 个月，还在熟悉各种质量标准
- **痛点**：质量标准书太厚，查起来慢，怕判错被批评
- **使用场景**：遇到不确定的缺陷，拍照上传问 AI"这个合格吗"，AI 引用标准条款并给出判定建议

### 用户三：王班长（38岁，线长）

- **背景**：管理 15 人的生产线，每天处理各种异常
- **痛点**：同样的问题反复发生，每次都要重新解释怎么处理
- **使用场景**：遇到异常时，先问 AI"以前有没有类似情况"，查看历史案例，然后把解决方案一键推送给相关工人

### 5.2 关键技术

| 技术 | 选型 | 说明 |
|------|------|------|
| 后端 | Rust + Axum | 高性能，响应 < 100ms |
| 前端 | React + PWA | 跨平台，支持离线 |
| 数据库 | PostgreSQL + pgvector | 关系数据 + 向量搜索 |
| 大模型 | Ollama + Qwen2.5 | 本地部署，数据不出厂 |
| 向量搜索 | Redis HNSW | 高性能相似度搜索 |
| 语音识别 | Web Speech API | 浏览器原生支持 |
| 图像识别 | 视觉大模型 API | 产品缺陷识别 |

### 5.3 数据安全

- **本地部署**：大模型和数据全部部署在企业内网
- **权限隔离**：工人只能查询自己岗位相关的知识
- **审计日志**：所有查询和操作记录可追溯
- **数据加密**：传输和存储全程加密

## 六、创新点

### 6.1 交互创新：为工人设计的 AI

- **语音优先**：车间环境嘈杂、双手占用，语音是最自然的交互方式
- **大字体/高对比度**：车间光线复杂，界面清晰易读
- **一步直达**：无需登录、无需导航，打开就说

### 6.2 技术创新：RAG + 制造业知识库

- 不是通用 AI 聊天，而是基于企业私有知识库的精准问答
- 向量搜索 + 关键词混合召回，确保准确率
- 答案附带出处，可追溯原文

### 6.3 模式创新：知识自动沉淀

- 老师傅解决问题的过程自动记录
- AI 提取关键步骤生成标准化案例
- 从"人传人"变为"人传 AI，AI 传人"

### 6.4 社会创新：缩小数字鸿沟

- 让 50 多岁的老师傅也能用 AI
- 让初中毕业的工人也能享受技术红利
- 让制造业工人的经验被尊重、被记录、被传承
