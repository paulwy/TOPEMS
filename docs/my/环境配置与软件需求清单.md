### 2.3 数据库服务

#### 2.3.1 PostgreSQL

| 项目 | 说明 |
| ------ | ------ |
| **版本要求** | PostgreSQL 15.x 或更高版本 |
| **推荐版本** | PostgreSQL 16.x |
| **用途** | 主数据库，存储业务数据 |
| **官网** | [PostgreSQL官网](https://www.postgresql.org/) |

**安装方式**:

```bash
# macOS (使用Homebrew)
brew install postgresql@16
brew services start postgresql@16

# Ubuntu/Debian
sudo apt install postgresql postgresql-contrib

# 或使用Docker
docker run -d --name postgres \
  -e POSTGRES_USER=user \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=pomp \
  -p 5432:5432 \
  -v postgres_data:/var/lib/postgresql/data \
  postgres:16

# Windows
# 下载安装包: https://www.postgresql.org/download/windows/
```

**必需扩展**:

```sql
-- 创建数据库后执行
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "pgcrypto";
```

### 2.5 向量数据库

系统支持两种向量数据库方案：

#### 2.5.1 PostgreSQL + pgvector (推荐)

| 项目 | 说明 |
| ------ | ------ |
| **版本要求** | PostgreSQL 15+ + pgvector 0.4+ |
| **用途** | 存储和查询向量嵌入，支持语义搜索 |
| **官网** | [pgvector官网](https://github.com/pgvector/pgvector) |

**安装方式**:

```bash
# macOS (使用Homebrew)
brew install pgvector

# Ubuntu/Debian
sudo apt install postgresql-server-dev-16
cargo install pgvector

# 在PostgreSQL中启用扩展
psql -d pomp -c "CREATE EXTENSION vector;"

# Docker (使用已包含pgvector的镜像)
docker run -d --name postgres \
  -e POSTGRES_USER=user \
  -e POSTGRES_PASSWORD=password \
  -e POSTGRES_DB=pomp \
  -p 5432:5432 \
  ankane/pgvector:latest

# 创建扩展
psql -h localhost -U user -d pomp -c "CREATE EXTENSION vector;"
```

**向量数据类型**:

## 4. 开发环境安装步骤

### 4.1 macOS安装步骤

#### 第一步：安装Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

#### 第二步：安装必需软件

```bash
# 安装Node.js
brew install node@20

# 安装Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 安装PostgreSQL
brew install postgresql@16
brew services start postgresql@16

# 安装Redis
brew install redis
brew services start redis

# 安装Git (通常已预装)
brew install git
```

#### 第三步：克隆代码

```bash
git clone https://your-repo-url/sksf-ems.git
cd sksf-ems
```

#### 第四步：配置环境变量

```bash
# 复制环境变量模板
cp backend/core/.env.example backend/core/.env

# 编辑环境变量
nano backend/core/.env
```

#### 第五步：初始化数据库

```bash
# 创建数据库
createdb -h localhost -U user pomp

# 或者使用psql
psql -U user -h localhost -c "CREATE DATABASE pomp;"
```

#### 第六步：安装前端依赖

```bash
cd frontend
npm install
```

#### 第七步：安装后端依赖

```bash
cd ../backend/core
cargo build
```

#### 第八步：启动服务

```bash
# 终端1：启动后端
cd backend/core
cargo run

# 终端2：启动前端
cd frontend
npm run dev
```

#### 第九步：访问应用

```bash
前端: http://localhost:5173
后端API: http://localhost:8000
```

## 5. 生产环境部署

### 5.1 Docker部署

#### 5.1.1 创建Docker配置文件

**Dockerfile (后端)**:

```dockerfile
FROM rust:1.80-bookworm AS builder

WORKDIR /app
COPY Cargo.toml Cargo.lock ./
COPY src ./src

RUN cargo build --release

FROM debian:bookworm-slim
RUN apt-get update && apt-get install -y ca-certificates
COPY --from=builder /app/target/release/sksfems_backend /usr/local/bin/
EXPOSE 8000
CMD ["sksfems_backend"]
```

**Dockerfile (前端)**:

```dockerfile
FROM node:20-alpine AS builder

WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

**docker-compose.yml**:

```yaml
version: '3.8'

services:
  # 前端服务
  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - app-network

  # 后端服务
  backend:
    build:
      context: ./backend/core
      dockerfile: Dockerfile
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgres://user:password@postgres:5432/pomp
      - REDIS_URL=redis://redis:6379
      - JWT_SECRET=${JWT_SECRET}
    depends_on:
      - postgres
      - redis
    networks:
      - app-network

  # PostgreSQL数据库
  postgres:
    image: postgres:16-alpine
    environment:
      - POSTGRES_USER=user
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=pomp
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    networks:
      - app-network

  # Redis缓存
  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data
    ports:
      - "6379:6379"
    networks:
      - app-network

networks:
  app-network:
    driver: bridge

volumes:
  postgres_data:
  redis_data:
```

**nginx.conf**:

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    location /ws {
        proxy_pass http://backend:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

### 5.2 手动部署

#### 5.2.1 服务器准备

```bash
# Ubuntu 22.04
sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx certbot python3-certbot-nginx
```

#### 5.2.2 部署后端

```bash
# 安装Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env

# 克隆代码
git clone https://your-repo-url/sksf-ems.git
cd sksf-ems/backend/core

# 配置环境变量
cp .env.example .env
nano .env

# 构建发布版本
cargo build --release

# 配置systemd服务
sudo nano /etc/systemd/system/sksfems-backend.service
```

**sksfems-backend.service**:

```ini
[Unit]
Description=SKSF EMS Backend Service
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/sksf-ems/backend/core
ExecStart=/opt/sksf-ems/backend/core/target/release/sksfems_backend
Restart=always
RestartSec=5
Environment="RUST_LOG=info"

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
sudo systemctl enable sksfems-backend
sudo systemctl start sksfems-backend
sudo systemctl status sksfems-backend
```


**Nginx配置**:

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/sksf-ems;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /ws {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

```bash

sudo systemctl reload nginx
```
