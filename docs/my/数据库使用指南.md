## 二、数据库 Schema

### 2.1 Schema 概览

| Schema | 说明 | 表数量 |
| ------ ------ ------ |
| **iam** | 身份认证与权限管理 | 6 |
| **doc** | 文档管理系统 | 4 |
| **ai** | AI 知识库 | 3 |
| **flow** | 工作流引擎 | 3 |

### 2.2 IAM Schema（身份认证）

```sql
-- 用户表
SELECT * FROM iam.users;

-- 角色表
SELECT * FROM iam.roles;

-- 权限表
SELECT * FROM iam.permissions;

-- 用户角色关联
SELECT u.username, r.name as role
FROM iam.users u
JOIN iam.user_roles ur ON u.id = ur.user_id
JOIN iam.roles r ON ur.role_id = r.id;

-- 审计日志
SELECT * FROM iam.audit_logs ORDER BY created_at DESC LIMIT 10;
```

**用户表结构**:

| 字段 | 类型 | 说明 |
| ------ ------ ------ |
| id | UUID | 主键 |
| username | VARCHAR(50) | 用户名 |
| email | VARCHAR(100) | 邮箱 |
| password_hash | VARCHAR(255) | 密码哈希 |
| full_name | VARCHAR(100) | 全名 |
| is_active | BOOLEAN | 是否激活 |
| is_superuser | BOOLEAN | 是否超管 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| last_login_at | TIMESTAMPTZ | 最后登录 |

### 2.3 DOC Schema（文档管理）

```sql
-- 文件夹
SELECT * FROM doc.folders;

-- 文件
SELECT f.name, fl.path 
FROM doc.files f
JOIN doc.folders fl ON f.folder_id = fl.id;

-- 文件版本
SELECT * FROM doc.file_versions;

-- 文件权限
SELECT * FROM doc.file_permissions;
```

**文件夹表结构**:

| 字段 | 类型 | 说明 |
| ------ ------ ------ |
| id | UUID | 主键 |
| name | VARCHAR(255) | 文件夹名 |
| parent_id | UUID | 父文件夹 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| created_by | VARCHAR(100) | 创建人 |

**文件表结构**:

| 字段 | 类型 | 说明 |
| ------ ------ ------ |
| id | UUID | 主键 |
| name | VARCHAR(255) | 文件名 |
| folder_id | UUID | 所属文件夹 |
| size | BIGINT | 文件大小 |
| content_type | VARCHAR(100) | MIME类型 |
| checksum | VARCHAR(64) | 校验和 |
| created_at | TIMESTAMPTZ | 创建时间 |
| updated_at | TIMESTAMPTZ | 更新时间 |
| created_by | VARCHAR(100) | 创建人 |

### 2.4 AI Schema（AI 知识库）

```sql
-- 文档
SELECT id, title, content_preview, created_at 
FROM ai.documents;

-- 标签
SELECT * FROM ai.tags;

-- 文档标签关联
SELECT d.title, t.name as tag
FROM ai.document_tags dt
JOIN ai.documents d ON dt.document_id = d.id
JOIN ai.tags t ON dt.tag_id = t.id;
```

### 2.5 FLOW Schema（工作流）

```sql
-- 工作流定义
SELECT id, name, description, is_active 
FROM flow.workflows;

-- 工作流实例
SELECT id, status, started_at, completed_at 
FROM flow.workflow_instances;

-- 审批记录
SELECT * FROM flow.approvals ORDER BY created_at DESC LIMIT 10;
```

## 三、常用查询

### 3.1 用户管理

```sql
-- 查询所有用户
SELECT username, email, is_active, created_at FROM iam.users;

-- 查询活跃用户
SELECT username, last_login_at 
FROM iam.users 
WHERE is_active = true 
ORDER BY last_login_at DESC;

-- 统计用户数量
SELECT COUNT(*) as total_users, 
       SUM(CASE WHEN is_active THEN 1 ELSE 0 END) as active_users
FROM iam.users;
```

### 3.2 文档统计

```sql
-- 统计文件数量和大小
SELECT COUNT(*) as total_files, 
       SUM(size) as total_size,
       AVG(size) as avg_size
FROM doc.files;

-- 按文件夹统计
SELECT fl.name, COUNT(f.id) as file_count, SUM(f.size) as total_size
FROM doc.folders fl
LEFT JOIN doc.files f ON fl.id = f.folder_id
GROUP BY fl.id, fl.name
ORDER BY total_size DESC;

-- 最近更新的文件
SELECT name, updated_at, size 
FROM doc.files 
ORDER BY updated_at DESC 
LIMIT 10;
```

### 3.3 工作流统计

```sql
-- 工作流状态统计
SELECT status, COUNT(*) as count
FROM flow.workflow_instances
GROUP BY status;

-- 待审批任务
SELECT wi.id, wi.name, a.assignee, a.created_at
FROM flow.workflow_instances wi
JOIN flow.approvals a ON wi.id = a.workflow_instance_id
WHERE a.status = 'pending'
ORDER BY a.created_at DESC;

-- 本月工作流统计
SELECT COUNT(*) as total,
       SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) as completed,
       AVG(EXTRACT(EPOCH FROM (completed_at - started_at))/3600) as avg_hours
FROM flow.workflow_instances
WHERE started_at >= DATE_TRUNC('month', CURRENT_DATE);
```

## 四、数据维护

### 4.1 备份与恢复

```bash
# 备份数据库
pg_dump -h localhost -U topems -d topems > topems_backup_$(date +%Y%m%d).sql

# 恢复数据库
psql -h localhost -U topems -d topems < topems_backup_20260522.sql

# Docker 备份
docker exec topems-postgres pg_dump -U topems topems > backup.sql
```

### 4.2 清理数据

```sql
-- 清理旧审计日志（保留90天）
DELETE FROM iam.audit_logs 
WHERE created_at < NOW() - INTERVAL '90 days';

-- 清理未完成的工作流实例（保留30天）
DELETE FROM flow.workflow_instances 
WHERE status = 'draft' 
AND started_at < NOW() - INTERVAL '30 days';
```

### 4.3 索引优化

```sql
-- 查看索引使用情况
SELECT indexrelname, idx_scan, idx_tup_read
FROM pg_stat_user_indexes
WHERE schemaname IN ('iam', 'doc', 'ai', 'flow')
ORDER BY idx_scan DESC;

-- 创建缺失索引（根据查询模式）
CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_files_updated_at 
ON doc.files(updated_at DESC);

CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_workflow_instances_started_at 
ON flow.workflow_instances(started_at DESC);
```

## 五、性能监控

### 5.1 监控查询

```sql
-- 活动连接
SELECT pid, usename, application_name, client_addr, backend_start, state
FROM pg_stat_activity
WHERE datname = 'topems';

-- 慢查询（超过1秒）
SELECT pid, now() - query_start as duration, query
FROM pg_stat_activity
WHERE state = 'active' AND now() - query_start > interval '1 second';

-- 表膨胀检查
SELECT schemaname, tablename, 
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as size,
       n_live_tup, n_dead_tup
FROM pg_stat_user_tables
WHERE schemaname IN ('iam', 'doc', 'ai', 'flow')
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC;
```

### 5.2 关键指标

```sql
-- 数据库大小
SELECT pg_size_pretty(pg_database_size('topems'));

-- 各 Schema 大小
SELECT schemaname, 
       pg_size_pretty(SUM(pg_total_relation_size(schemaname||'.'||relname))) as size
FROM pg_stat_user_tables
WHERE schemaname IN ('iam', 'doc', 'ai', 'flow')
GROUP BY schemaname
ORDER BY size DESC;

-- 表大小排名
SELECT schemaname, tablename, 
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) as size
FROM pg_stat_user_tables
WHERE schemaname IN ('iam', 'doc', 'ai', 'flow')
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
LIMIT 10;
```

## 六、安全管理

### 6.1 用户权限

```sql
-- 撤销公共访问（生产环境）
REVOKE ALL ON SCHEMA doc, ai, flow FROM PUBLIC;
REVOKE ALL ON ALL TABLES IN SCHEMA doc, ai, flow FROM PUBLIC;

-- 授予应用用户权限
GRANT USAGE ON SCHEMA doc, ai, flow TO topems;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA doc, ai, flow TO topems;
GRANT ALL PRIVILEGES ON ALL SEQUENCES IN SCHEMA doc, ai, flow TO topems;
```

### 6.2 密码策略

```sql
-- 修改用户密码
ALTER USER topems WITH PASSWORD 'new_password';

-- 设置密码过期（90天）
ALTER USER topems VALID UNTIL '2026-08-22';
```

## 七、故障排查

### 7.1 常见问题

### Q: 连接被拒绝**

```bash
# 检查 PostgreSQL 是否运行
docker ps | grep postgres

# 检查端口
lsof -i :5432
```

### Q: 认证失败-用户名或密码错误**

```bash
# 检查用户名密码
docker exec topems-postgres psql -U topems -d topems -c "SELECT 1"

# 重置密码
docker exec topems-postgres psql -U postgres -c "ALTER USER topems WITH PASSWORD 'topems_secret';"
```

### Q: 数据库满了-空间不足**

```sql
-- 查看数据库大小
SELECT pg_size_pretty(pg_database_size('topems'));

-- 清理日志
SELECT pg_stat_reset();
```

### 7.2 日志查看

```bash
# Docker 日志
docker logs topems-postgres --tail 100

# 实时日志
docker logs -f topems-postgres
```
