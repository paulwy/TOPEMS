# TOPEMS 用户手册

## 概述

欢迎使用 TOPEMS 企业管理系统！本手册将帮助您了解系统的基本功能和使用方法。

**版本**: v1.1  
**最后更新**: 2026-06-10  
**适用环境**: 本地部署 / SaaS

---

## 系统介绍

TOPEMS (Total Operations and Project Management System) 是一个综合企业管理平台，包含以下核心模块：

| 模块 | 说明 |
|------|------|
| **IAM** | 身份认证与权限管理 |
| **HRM** | 人力资源管理（公司、员工、部门管理） |
| **ERP** | 企业资源计划（资产、财务、采购） |
| **研发管理 (RS)** | 项目管理、实验管理 |
| **实验室管理 (LIMS)** | 样品管理、检验记录 |
| **质量管理 (QMS)** | 质量控制、审核管理 |
| **文档管理 (DOC)** | 文件存储、版本控制 |
| **工作流 (FLOW)** | 审批流程、任务管理 |
| **即时通讯 (IM)** | 消息沟通、群组聊天 |
| **商业智能 (BI)** | 数据分析、报表展示 |
| **生产管理 (MES)** | 生产计划、工艺流程 |
| **供应链 (SCM)** | 供应链管理 |
| **仓储管理 (WMS)** | 仓库管理 |
| **客户管理 (CRM)** | 客户关系管理 |

## 快速入门

### 1. 系统访问

**本地部署地址**: http://localhost:3000  
**SaaS部署地址**: https://topems.example.com

### 2. 登录系统

打开浏览器访问系统地址，进入登录页面：

1. 输入邮箱地址或用户名
2. 输入密码
3. 点击「登录」按钮

### 2. 系统主界面

登录成功后，您将看到系统主界面，包含：

- **顶部导航栏**：显示系统名称、搜索框、通知、用户信息
- **左侧菜单栏**：各功能模块入口
- **主内容区域**：当前模块的内容展示

### 3. 基本操作

#### 搜索
- 在顶部搜索框输入关键词进行全局搜索
- 支持搜索项目、文件、用户等

#### 通知
- 点击通知图标查看系统通知
- 包括审批提醒、消息通知等

#### 用户菜单
- 点击用户头像可以：
  - 修改个人信息
  - 修改密码
  - 退出登录

## 模块使用指南

### 一、人力资源管理 (HRM)

#### 公司架构管理

**公司架构模块整合了公司、部门和员工的管理，提供一站式组织架构管理体验。**

##### 查看公司架构
1. 点击左侧菜单「人力资源」→「公司架构」
2. 进入公司列表页面，显示所有公司信息
3. 点击公司名称进入公司详情页，包含：
   - 公司基本信息
   - 部门树形结构（内嵌部门管理）
   - 员工列表（该公司下的所有员工）

##### 创建公司
1. 在公司列表页面点击「新建公司」按钮
2. 填写公司信息：
   - **公司名称**：必填
   - **公司简称**：可选
   - **统一社会信用代码**：可选
   - **所属行业**：下拉选择
   - **公司规模**：小型/中型/大型
   - **成立日期**：选择日期
   - **地址**：详细地址
   - **联系人**：联系人姓名
   - **联系电话**：联系电话
   - **邮箱**：公司邮箱
3. 点击「保存」按钮完成创建

##### 编辑公司
1. 在公司列表或详情页点击「编辑」按钮
2. 修改公司信息后点击「保存」

##### 删除公司
1. 在公司列表中选择要删除的公司
2. 点击「删除」按钮
3. 确认删除操作（注意：删除后不可恢复，关联部门和员工将被转移）

##### 在公司下创建部门
1. 进入公司详情页
2. 在部门树区域点击「新建部门」按钮
3. 填写部门信息：
   - **部门名称**：必填
   - **上级部门**：选择上级部门（可选）
   - **部门负责人**：选择负责人
   - **部门描述**：可选
4. 点击「保存」，部门将自动关联到当前公司

##### 部门树形管理
- 在公司详情页查看部门层级树
- 可展开/折叠部门层级
- 支持拖拽调整层级结构
- 直接在部门树上进行编辑和删除操作

##### 查看公司员工
1. 进入公司详情页
2. 切换到「员工」标签页
3. 显示该公司下的所有员工列表
4. 支持按部门筛选、搜索

#### 员工管理

##### 查看员工列表
1. 点击左侧菜单「人力资源」→「员工管理」
2. 显示所有员工列表
3. 支持按公司、部门、状态筛选
4. 员工卡片显示所属公司和部门信息

##### 创建员工
1. 点击「新建员工」按钮
2. 填写员工信息：
   - **基本信息**：姓名、工号、性别、出生日期
   - **工作信息**：所属公司、部门、职位、入职日期
   - **联系方式**：电话、邮箱、地址
   - **紧急联系人**：姓名、电话
   - **状态**：在职/离职/试用期
3. 点击「保存」，员工将自动关联到所选公司和部门

##### 编辑员工
1. 在员工列表中点击「编辑」按钮
2. 可修改员工的公司、部门、职位等信息
3. 修改完成后点击「保存」

##### 员工与公司架构的关联
- 每个员工必须隶属于一个公司（通过公司ID关联）
- 员工可以隶属于某个部门（通过部门ID关联）
- 在公司架构详情页可以查看该公司下的所有员工
- 在部门详情页可以查看该部门下的所有员工

##### 重置密码
1. 在员工列表中选择员工
2. 点击「重置密码」按钮
3. 设置新密码

### 九、AI 智能助手

TOPEMS 内置 AI 智能助手，帮助您更高效地完成日常工作。

#### AI 功能入口

在支持 AI 的表单页面，您会看到以下 AI 辅助按钮：

- **AI 生成**：点击自动生成编码或内容
- **AI 优化**：优化文本内容，使其更专业
- **AI 校验**：检查表单数据的完整性和正确性
- **AI 补全**：根据已有信息自动补全相关字段

#### 智能编码生成

当您需要为部门、员工、项目等创建编码时：

1. 在编码输入框旁边找到「AI 生成」按钮
2. 点击按钮，AI 会根据上下文自动生成 3 个编码方案
3. 选择满意的编码，或点击「重新生成」获取更多方案
4. 也可以手动编辑生成的编码

**支持场景**：
- 部门编码生成
- 员工工号生成
- 项目编号生成
- 合同编号生成

#### 智能文本优化

当您需要撰写部门职责、员工简介、合同条款等文本时：

1. 找到「AI 优化」按钮
2. （可选）添加关键词指导 AI 生成方向
3. 选择优化风格：
   - **专业正式**：使用专业术语，正式表达
   - **简洁明了**：精简内容，突出重点
   - **详尽完整**：详细展开，全面覆盖
   - **亲切友好**：语气柔和，易于理解
4. 点击「AI 优化」生成内容
5. 如需调整，可多次点击「重新生成」
6. 使用「← →」按钮查看历史版本
7. 满意后点击「使用此文本」

#### 智能表单校验

提交表单前，AI 会自动检查：

1. **完整性检查**：必填项是否已填写
2. **格式检查**：邮箱、电话、日期等格式是否正确
3. **逻辑检查**：如结束日期是否晚于开始日期
4. **合理性检查**：如金额是否在合理范围

**使用方法**：
1. 填写完表单后，点击「AI 校验」按钮
2. 查看校验结果：
   - ✅ 绿色标记表示该项检查通过
   - ⚠️ 黄色标记表示警告，建议检查
   - ❌ 红色标记表示错误，需要修复
3. 点击「一键修复」自动修复可修复的问题
4. 或手动修改后点击「重新校验」

#### 智能数据补全

当您输入部分信息时，AI 会自动推测并补全相关字段：

1. 输入基本信息（如员工姓名、所在部门）
2. 系统自动触发 AI 补全
3. 查看推荐补全值（带置信度标记）
4. 点击确认接受建议，或自行修改

#### AI 设置

在系统右上角用户菜单中，可以配置 AI 功能：

1. 点击用户头像 → 「AI 设置」
2. 选择 AI 模型：
   - **本地模型（Ollama）**：免费，使用本地运行的模型
   - **云端模型**：使用第三方 AI 服务（需配置 API Key）
3. 调整生成参数：
   - **Temperature**：控制创造性（0-1）
   - **最大长度**：限制生成内容长度

#### 知识库管理

知识库是 AI 智能助手的核心支撑，为 AI 提供上下文信息。

##### 访问知识库

1. 点击左侧菜单「AI 智能助手」→「知识库管理」
2. 或直接访问 `/knowledge-base` 路径

##### 上传文档

**支持格式**：txt、md、json、pdf、doc、docx

**上传方式**：
1. **拖拽上传**：将文件拖拽到上传区域
2. **选择文件**：点击「选择文件」按钮浏览文件

**步骤**：
1. 点击「上传文档」按钮
2. 选择或拖拽文件到上传区域
3. 系统自动处理并添加到知识库
4. 上传完成后可在列表中查看

##### 文档管理

**查看文档列表**：
- 显示所有已上传的文档
- 支持搜索文档标题或文件名
- 支持按分类过滤

**查看文档详情**：
1. 点击文档右侧的「查看」按钮（眼睛图标）
2. 查看文档的详细信息：
   - 文档标题
   - 文件名和大小
   - 文件类型
   - 创建和更新时间
   - 分类和标签
   - 文件路径

**编辑文档信息**：
1. 点击文档右侧的「编辑」按钮（编辑图标）
2. 可修改：
   - 文档标题
   - 分类（技术文档、业务流程、产品说明等）
   - 标签（多个标签用逗号分隔）
   - 描述信息
3. 点击「保存」完成编辑

**删除文档**：
1. 点击文档右侧的「删除」按钮（垃圾桶图标）
2. 确认删除操作
3. 文档将从知识库和系统中永久删除

##### 文档分类

系统支持以下文档分类：
- **技术文档**：技术规范、API 文档等
- **业务流程**：业务操作流程、工作流程等
- **产品说明**：产品介绍、使用手册等
- **培训资料**：培训文档、学习材料等
- **规章制度**：公司制度、管理规定等
- **其他**：其他类型文档

##### 文档统计

知识库页面顶部显示统计信息：
- **总文档数**：知识库中的文档总数
- **分类数量**：文档分类的数量
- **已处理**：已成功处理的文档数量

##### 重新加载

#### 常见问题

**Q: AI 生成的内容不满意怎么办？**

A: 可以点击「重新生成」获取新的方案，或手动编辑生成的内容。多次生成会选择最满意的结果。

**Q: AI 功能没有响应？**

A: 检查：
1. Ollama 服务是否正在运行
2. 网络连接是否正常
3. AI 设置中的配置是否正确

**Q: 如何提高 AI 生成质量？**

A:
1. 提供更详细的上下文信息
2. 添加相关的关键词
3. 选择合适的优化风格
4. 使用历史版本功能选择最佳结果

## 常见问题

### Q: 忘记密码怎么办？

A: 在登录页面点击「忘记密码」，输入注册邮箱，系统会发送重置链接。

### Q: 如何修改个人信息？

A: 点击右上角用户头像，选择「个人信息」，修改后保存。

### Q: 如何联系其他用户？

A: 在即时通讯模块搜索用户名称，发送消息。

### Q: 如何上传大文件？

A: 系统支持最大100MB的文件上传，超过大小建议压缩后上传。

### Q: 审批流程卡住怎么办？

A: 联系流程管理员或查看审批历史确认当前处理人。
