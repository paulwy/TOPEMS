# TOPEMS 用户手册

## 概述

欢迎使用 TOPEMS 企业管理系统！本手册将帮助您了解系统的基本功能和使用方法。

**版本**: v1.1  
**最后更新**: 2026-06-10  
**适用环境**: 本地部署 / SaaS

---

## 系统介绍

TOPEMS (Total Operations and Project Management System) 是一个综合企业管理平台，包含以下核心模块：

| 模块 | 说明 |
|------|------|
| **IAM** | 身份认证与权限管理 |
| **HRM** | 人力资源管理（公司、员工、部门管理） |
| **ERP** | 企业资源计划（资产、财务、采购） |
| **研发管理 (RS)** | 项目管理、实验管理 |
| **实验室管理 (LIMS)** | 样品管理、检验记录 |
| **质量管理 (QMS)** | 质量控制、审核管理 |
| **文档管理 (DOC)** | 文件存储、版本控制 |
| **工作流 (FLOW)** | 审批流程、任务管理 |
| **即时通讯 (IM)** | 消息沟通、群组聊天 |
| **商业智能 (BI)** | 数据分析、报表展示 |
| **生产管理 (MES)** | 生产计划、工艺流程 |
| **供应链 (SCM)** | 供应链管理 |
| **仓储管理 (WMS)** | 仓库管理 |
| **客户管理 (CRM)** | 客户关系管理 |

---

## 快速入门

### 1. 系统访问

**本地部署地址**: http://localhost:3000  
**SaaS部署地址**: https://topems.example.com

### 2. 登录系统

打开浏览器访问系统地址，进入登录页面：

1. 输入邮箱地址或用户名
2. 输入密码
3. 点击「登录」按钮

### 2. 系统主界面

登录成功后，您将看到系统主界面，包含：

- **顶部导航栏**：显示系统名称、搜索框、通知、用户信息
- **左侧菜单栏**：各功能模块入口
- **主内容区域**：当前模块的内容展示

### 3. 基本操作

#### 搜索
- 在顶部搜索框输入关键词进行全局搜索
- 支持搜索项目、文件、用户等

#### 通知
- 点击通知图标查看系统通知
- 包括审批提醒、消息通知等

#### 用户菜单
- 点击用户头像可以：
  - 修改个人信息
  - 修改密码
  - 退出登录

## 模块使用指南

### 一、人力资源管理 (HRM)

#### 公司架构管理

**公司架构模块整合了公司、部门和员工的管理，提供一站式组织架构管理体验。**

##### 查看公司架构
1. 点击左侧菜单「人力资源」→「公司架构」
2. 进入公司列表页面，显示所有公司信息
3. 点击公司名称进入公司详情页，包含：
   - 公司基本信息
   - 部门树形结构（内嵌部门管理）
   - 员工列表（该公司下的所有员工）

##### 创建公司
1. 在公司列表页面点击「新建公司」按钮
2. 填写公司信息：
   - **公司名称**：必填
   - **公司简称**：可选
   - **统一社会信用代码**：可选
   - **所属行业**：下拉选择
   - **公司规模**：小型/中型/大型
   - **成立日期**：选择日期
   - **地址**：详细地址
   - **联系人**：联系人姓名
   - **联系电话**：联系电话
   - **邮箱**：公司邮箱
3. 点击「保存」按钮完成创建

##### 编辑公司
1. 在公司列表或详情页点击「编辑」按钮
2. 修改公司信息后点击「保存」

##### 删除公司
1. 在公司列表中选择要删除的公司
2. 点击「删除」按钮
3. 确认删除操作（注意：删除后不可恢复，关联部门和员工将被转移）

##### 在公司下创建部门
1. 进入公司详情页
2. 在部门树区域点击「新建部门」按钮
3. 填写部门信息：
   - **部门名称**：必填
   - **上级部门**：选择上级部门（可选）
   - **部门负责人**：选择负责人
   - **部门描述**：可选
4. 点击「保存」，部门将自动关联到当前公司

##### 部门树形管理
- 在公司详情页查看部门层级树
- 可展开/折叠部门层级
- 支持拖拽调整层级结构
- 直接在部门树上进行编辑和删除操作

##### 查看公司员工
1. 进入公司详情页
2. 切换到「员工」标签页
3. 显示该公司下的所有员工列表
4. 支持按部门筛选、搜索

#### 员工管理

##### 查看员工列表
1. 点击左侧菜单「人力资源」→「员工管理」
2. 显示所有员工列表
3. 支持按公司、部门、状态筛选
4. 员工卡片显示所属公司和部门信息

##### 创建员工
1. 点击「新建员工」按钮
2. 填写员工信息：
   - **基本信息**：姓名、工号、性别、出生日期
   - **工作信息**：所属公司、部门、职位、入职日期
   - **联系方式**：电话、邮箱、地址
   - **紧急联系人**：姓名、电话
   - **状态**：在职/离职/试用期
3. 点击「保存」，员工将自动关联到所选公司和部门

##### 编辑员工
1. 在员工列表中点击「编辑」按钮
2. 可修改员工的公司、部门、职位等信息
3. 修改完成后点击「保存」

##### 员工与公司架构的关联
- 每个员工必须隶属于一个公司（通过公司ID关联）
- 员工可以隶属于某个部门（通过部门ID关联）
- 在公司架构详情页可以查看该公司下的所有员工
- 在部门详情页可以查看该部门下的所有员工

##### 重置密码
1. 在员工列表中选择员工
2. 点击「重置密码」按钮
3. 设置新密码

##### 删除项目

### 八、企业资源管理 (ERP)

#### 8.1 公司管理

##### 查看公司列表

1. 点击左侧菜单「企业资源管理」→「公司管理」
2. 页面展示所有公司卡片列表
3. 显示公司名称、简称、联系电话、状态等信息

##### 搜索公司

1. 在搜索框输入关键词
2. 支持按公司名称、简称、邮箱搜索
3. 实时筛选匹配结果

##### 新增公司

1. 点击页面右上角「新增公司」按钮
2. 在弹窗中填写公司信息：
   - **公司名称**：必填，公司全称
   - **简称**：可选，公司简称
   - **注册号**：可选，营业执照注册号
   - **税号**：可选，税务登记号
   - **地址**：可选，公司地址
   - **联系电话**：可选，联系电话
   - **邮箱**：可选，公司邮箱
   - **网站**：可选，公司官网
3. 点击「保存」完成创建
4. 创建成功后自动刷新公司列表

##### 编辑公司

1. 在公司卡片中点击「编辑」按钮（铅笔图标）
2. 修改公司信息
3. 点击「保存」完成更新

##### 删除公司

1. 在公司卡片中点击「删除」按钮（垃圾桶图标）
2. 确认删除操作
3. 删除成功后自动刷新列表

##### 公司状态

- **活跃**：正常运营的公司
- **停用**：暂时停止运营的公司

#### 8.2 期初余额管理

##### 查看期初余额

1. 点击左侧菜单「企业资源管理」→「期初余额」
2. 页面展示期初余额列表
3. 支持按期间、公司、科目筛选

##### 新增期初余额

1. 点击「新增期初余额」按钮
2. 填写信息：
   - **公司**：选择公司
   - **期间**：选择会计期间（如202601）
   - **科目代码**：输入科目代码
   - **科目名称**：输入科目名称
   - **借方余额**：输入借方金额
   - **贷方余额**：输入贷方金额
3. 点击「保存」完成创建

##### 批量导入期初余额

1. 点击「批量导入」按钮
2. 选择Excel文件（支持.xlsx/.xls格式）
3. 预览导入数据
4. 点击「确认导入」

##### 期间结转

1. 点击「期间结转」按钮
2. 选择源期间和目标期间
3. 点击「确认结转」
4. 系统自动将源期间余额结转到目标期间

#### 8.3 固定资产管理

##### 查看资产列表

1. 点击左侧菜单「企业资源管理」→「固定资产」
2. 页面展示资产卡片列表
3. 显示资产编码、名称、原值、净值、状态等信息
4. 支持按部门、状态筛选

##### 新增资产

1. 点击「新增资产」按钮
2. 填写资产信息：
   - **资产编码**：系统自动生成，可修改
   - **资产名称**：必填
   - **资产类型**：选择类型（设备、房屋、车辆等）
   - **资产类别**：选择类别
   - **购置日期**：选择日期
   - **原值**：输入金额
   - **预计使用年限**：按月计算
   - **残值**：输入残值金额
   - **折旧方法**：选择（平均年限法等）
   - **存放地点**：输入地点
   - **责任人**：选择员工（关联HRM模块）
   - **所属部门**：选择部门（关联HRM模块）
3. 点击「保存」完成创建

##### 资产折旧

1. 选择需要折旧的资产（可多选）
2. 点击「计提折旧」按钮
3. 选择折旧期间
4. 系统自动计算折旧金额
5. 点击「确认计提」

##### 资产处置

1. 在资产卡片中点击「处置」按钮
2. 选择处置方式（报废、出售、捐赠等）
3. 填写处置日期和金额
4. 点击「确认处置」

#### 8.4 银行账户管理

##### 查看账户列表

1. 点击左侧菜单「企业资源管理」→「银行账户」
2. 页面展示账户列表
3. 显示银行名称、账户名称、账号、余额等信息

##### 新增账户

1. 点击「新增账户」按钮
2. 填写账户信息：
   - **公司**：选择公司
   - **银行名称**：输入银行名称
   - **开户行**：输入开户支行
   - **账户名称**：输入账户名称
   - **账号**：输入账号
   - **账户类型**：选择（基本户、一般户等）
   - **币种**：选择币种
   - **初始余额**：输入初始余额
3. 点击「保存」完成创建

##### 记录交易

1. 在账户列表中点击「交易记录」按钮
2. 点击「新增交易」
3. 填写交易信息：
   - **交易日期**：选择日期
   - **交易类型**：选择（收入、支出、转账等）
   - **金额**：输入金额
   - **对方账户**：输入对方账号（可选）
   - **对方名称**：输入对方名称（可选）
   - **备注**：输入备注信息
4. 点击「保存」完成记录

#### 8.5 凭证管理

##### 查看凭证列表

1. 点击左侧菜单「企业资源管理」→「凭证管理」
2. 页面展示凭证列表
3. 显示凭证编号、日期、类型、金额等信息
4. 支持按日期范围、凭证类型筛选

##### 新增凭证

1. 点击「新增凭证」按钮
2. 选择凭证类型（收款凭证、付款凭证、转账凭证）
3. 填写凭证日期
4. 添加分录：
   - 点击「添加分录」
   - 选择科目
   - 输入摘要
   - 输入借方或贷方金额
   - 可添加多条分录
5. 选择凭证来源（HRM薪资、CRM发票、SRM付款等）
6. 点击「保存」完成创建

##### 凭证审核

1. 在凭证列表中选择待审核凭证
2. 点击「审核」按钮
3. 查看凭证详情和分录
4. 点击「通过」或「驳回」

##### 生成资产负债表

1. 点击左侧菜单「企业资源管理」→「财务报表」
2. 选择「资产负债表」
3. 选择期间
4. 选择公司（支持多公司合并）
5. 点击「生成报表」
6. 查看资产、负债、所有者权益数据
7. 支持导出Excel/PDF

##### 生成利润表

1. 在财务报表页面选择「利润表」
2. 选择期间
3. 选择公司
4. 点击「生成报表」

### 九、AI 智能助手

TOPEMS 内置 AI 智能助手，帮助您更高效地完成日常工作。

#### AI 功能入口

在支持 AI 的表单页面，您会看到以下 AI 辅助按钮：

- **AI 生成**：点击自动生成编码或内容
- **AI 优化**：优化文本内容，使其更专业
- **AI 校验**：检查表单数据的完整性和正确性
- **AI 补全**：根据已有信息自动补全相关字段

#### 智能编码生成

当您需要为部门、员工、项目等创建编码时：

1. 在编码输入框旁边找到「AI 生成」按钮
2. 点击按钮，AI 会根据上下文自动生成 3 个编码方案
3. 选择满意的编码，或点击「重新生成」获取更多方案
4. 也可以手动编辑生成的编码

**支持场景**：
- 部门编码生成
- 员工工号生成
- 项目编号生成
- 合同编号生成

#### 智能文本优化

当您需要撰写部门职责、员工简介、合同条款等文本时：

1. 找到「AI 优化」按钮
2. （可选）添加关键词指导 AI 生成方向
3. 选择优化风格：
   - **专业正式**：使用专业术语，正式表达
   - **简洁明了**：精简内容，突出重点
   - **详尽完整**：详细展开，全面覆盖
   - **亲切友好**：语气柔和，易于理解
4. 点击「AI 优化」生成内容
5. 如需调整，可多次点击「重新生成」
6. 使用「← →」按钮查看历史版本
7. 满意后点击「使用此文本」

#### 智能表单校验

提交表单前，AI 会自动检查：

1. **完整性检查**：必填项是否已填写
2. **格式检查**：邮箱、电话、日期等格式是否正确
3. **逻辑检查**：如结束日期是否晚于开始日期
4. **合理性检查**：如金额是否在合理范围

**使用方法**：
1. 填写完表单后，点击「AI 校验」按钮
2. 查看校验结果：
   - ✅ 绿色标记表示该项检查通过
   - ⚠️ 黄色标记表示警告，建议检查
   - ❌ 红色标记表示错误，需要修复
3. 点击「一键修复」自动修复可修复的问题
4. 或手动修改后点击「重新校验」

#### 智能数据补全

当您输入部分信息时，AI 会自动推测并补全相关字段：

1. 输入基本信息（如员工姓名、所在部门）
2. 系统自动触发 AI 补全
3. 查看推荐补全值（带置信度标记）
4. 点击确认接受建议，或自行修改

#### AI 设置

在系统右上角用户菜单中，可以配置 AI 功能：

1. 点击用户头像 → 「AI 设置」
2. 选择 AI 模型：
   - **本地模型（Ollama）**：免费，使用本地运行的模型
   - **云端模型**：使用第三方 AI 服务（需配置 API Key）
3. 调整生成参数：
   - **Temperature**：控制创造性（0-1）
   - **最大长度**：限制生成内容长度

#### 常见问题

**Q: AI 生成的内容不满意怎么办？**

A: 可以点击「重新生成」获取新的方案，或手动编辑生成的内容。多次生成会选择最满意的结果。

**Q: AI 功能没有响应？**

A: 检查：
1. Ollama 服务是否正在运行

2. 添加相关的关键词
3. 选择合适的优化风格
4. 使用历史版本功能选择最佳结果

2. 填写路线信息：
   - **路线名称**：必填
   - **路线编码**：系统自动生成
   - **产品**：选择关联产品
3. 添加工序：
   - 输入工序名称
   - 选择工序类型
   - 设置工序顺序
   - 选择设备和人员
4. 点击「保存」完成创建

#### 13.3 生产执行

##### 开工报工

1. 点击左侧菜单「制造执行」→「生产执行」
2. 选择生产工单
3. 点击「开工」按钮
4. 填写开工信息

##### 完工报工

1. 在生产执行列表中选择已开工的工单
2. 点击「完工」按钮
3. 填写完工数量和质量信息
4. 点击「确认完工」

### 十五、客户关系管理 (CRM)

#### 15.1 客户管理

##### 查看客户列表

1. 点击左侧菜单「客户关系管理」→「客户列表」
2. 页面展示客户卡片列表
3. 显示客户名称、联系人、电话、状态等信息
4. 支持按行业、区域、等级筛选

##### 新增客户

1. 点击「新增客户」按钮
2. 填写客户信息：
   - **客户名称**：必填
   - **客户编码**：系统自动生成，可修改
   - **统一社会信用代码**：可选
   - **联系人**：输入联系人姓名
   - **联系电话**：输入电话号码
   - **邮箱**：输入邮箱地址
   - **地址**：输入详细地址
   - **所属行业**：选择行业分类
   - **客户等级**：选择（A、B、C、D）
3. 点击「保存」完成创建

##### 客户跟进

1. 在客户详情页点击「跟进记录」标签
2. 点击「添加跟进记录」
3. 填写跟进信息：
   - **跟进日期**：选择日期
   - **跟进方式**：选择（电话、邮件、拜访、会议）
   - **跟进内容**：输入跟进详情
   - **下一步计划**：输入后续计划
4. 点击「保存」

#### 15.2 商机管理

##### 创建商机

1. 点击左侧菜单「客户关系管理」→「商机管理」
2. 点击「新建商机」按钮
3. 填写商机信息：
   - **商机名称**：必填
   - **关联客户**：选择客户
   - **预计金额**：输入金额
   - **成功率**：选择百分比
   - **预计成交日期**：选择日期
   - **负责人**：选择负责人
4. 点击「保存」完成创建

##### 商机跟踪

- 在商机列表中查看商机状态（初步接触、需求确认、方案报价、商务谈判、成交、失败）
- 点击商机查看详细信息和跟进记录

### 十六、环境健康安全 (EHS)

#### 16.1 安全检查

##### 创建检查任务

1. 点击左侧菜单「环境健康安全」→「安全检查」
2. 点击「新建检查任务」按钮
3. 填写检查信息：
   - **检查编号**：系统自动生成
   - **检查类型**：选择（日常检查、专项检查、定期检查）
   - **检查区域**：选择区域
   - **检查内容**：添加检查项
   - **检查人员**：选择检查人
   - **检查日期**：选择日期
4. 点击「保存」完成创建

##### 执行检查

1. 在检查任务列表中点击「执行检查」按钮
2. 填写每个检查项的结果（合格、不合格）
3. 对不合格项添加整改建议
4. 点击「提交检查结果」

#### 16.2 事故管理

##### 上报事故

1. 点击左侧菜单「环境健康安全」→「事故管理」
2. 点击「上报事故」按钮
3. 填写事故信息：
   - **事故编号**：系统自动生成
   - **事故类型**：选择（安全事故、环保事故、职业健康事故）
   - **事故级别**：选择（一般、较大、重大、特别重大）
   - **事故描述**：详细描述事故情况
   - **发生时间**：选择日期时间
   - **发生地点**：输入地点
   - **伤亡情况**：填写伤亡人数
   - **经济损失**：估算损失金额
4. 点击「提交」完成上报

##### 事故处理

- 查看事故列表和处理进度
- 支持添加事故处理记录
- 可上传事故调查报告
