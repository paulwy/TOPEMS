# AI 知识库模块

## 模块概述

AI 知识库模块是基于大语言模型和向量检索技术的智能知识管理平台，为企业提供文档智能处理和语义检索能力。模块支持多种格式文档的上传、解析、自动分块、向量化存储和语义检索，帮助企业构建智能化的知识管理体系，实现知识的快速沉淀、共享和检索，提升员工工作效率和客户服务质量。

## 核心功能

- **知识库 CRUD**：支持知识库的创建、查询、更新和删除，支持多种知识库类型（通用/产品/内部/FAQ）
- **文档上传**：支持多种格式文档上传（PDF、Word、Markdown、文本等），自动解析文档内容
- **自动分块**：智能文本分块算法，根据语义和长度自动切分文档为合适大小的块
- **向量化**：调用 Embedding 模型将文本块转换为向量表示，存储到向量数据库
- **语义检索**：基于向量相似度的语义检索，支持自然语言查询，返回最相关的知识片段
- **问答交互**：结合 RAG 技术，基于知识库内容生成精准回答，支持问答历史记录
- **处理状态跟踪**：实时跟踪文档处理进度，支持失败重试和错误信息查看

## 技术栈

- **pgvector**：基于 PostgreSQL 的向量扩展，用于向量存储和相似度检索
- **Chunking**：智能文本分块，支持按语义、按长度等多种分块策略
- **Embedding**：文本向量化，调用大模型 Embedding 接口生成向量表示
- **RAG**：检索增强生成，结合检索结果和大语言模型生成高质量回答

## 数据模型

- **ai_knowledge_bases**：知识库表，存储知识库基本信息、类型、状态、文档数量等
- **ai_knowledge_documents**：知识文档表，存储文档基本信息、解析状态、分块数量等
- **ai_knowledge_chunks**：文档分块表，存储文档分块的文本内容、元数据、token 数等
- **ai_knowledge_embeddings**：向量嵌入表，存储分块对应的向量数据，用于相似度检索
- **ai_knowledge_qa_history**：问答历史表，记录用户提问、回答、来源引用和用户反馈

## 处理流水线

文档处理采用流水线架构，依次执行以下步骤：
1. **上传**：用户上传文档文件，系统保存原始文件
2. **解析**：解析不同格式文档，提取纯文本内容
3. **分块**：智能文本分块，将长文本切分为合适大小的块
4. **嵌入**：调用 Embedding 模型生成每个文本块的向量表示
5. **索引**：将向量存储到 pgvector，建立向量索引，支持高效检索

## 主要 API

- `GET /knowledge-bases` - 分页查询知识库列表
- `POST /knowledge-bases` - 创建知识库
- `GET /knowledge-bases/{id}` - 获取知识库详情
- `PUT /knowledge-bases/{id}` - 更新知识库
- `DELETE /knowledge-bases/{id}` - 删除知识库
- `GET /knowledge-bases/{kb_id}/documents` - 获取知识库文档列表
- `POST /knowledge-bases/{kb_id}/documents` - 上传文档
- `GET /documents/{id}` - 获取文档详情
- `DELETE /documents/{id}` - 删除文档
- `GET /documents/{id}/chunks` - 获取文档分块列表
- `POST /knowledge-bases/{kb_id}/search` - 语义检索
- `POST /knowledge-bases/{kb_id}/qa` - 智能问答
- `GET /qa-history` - 获取问答历史

## 使用说明

AI 知识库模块通过 RESTful API 提供服务，使用前需先创建知识库，然后上传文档。文档上传后系统自动进行解析、分块、向量化和索引建库，处理完成后即可进行语义检索和智能问答。建议根据业务场景创建不同类型的知识库，如产品知识库、内部规章制度库、FAQ 库等，以提高检索精准度。检索时支持相似度阈值配置，可根据实际需求调整返回结果的相关度。
