### 🚀 部署说明

#### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| SERVER_PORT | 8054 | 服务端口（优先） |
| PORT | 8054 | 服务端口（备选） |
| DATABASE_URL | - | 数据库连接URL（必需） |
| JWT_SECRET | - | JWT密钥（必需） |

#### 启动命令

```bash
# 开发模式
cd svc/gis
cargo run

# 生产模式
cargo run --release

# 指定端口
SERVER_PORT=8054 cargo run --release
```
