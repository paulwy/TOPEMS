# TOPEMS 系统架构概览

## 1. 整体架构

TOPEMS 采用微服务架构，包含以下核心组件：

```
┌─────────────────────────────────────────────────────────┐
│                    统一门户入口                         │
│              (统一工作台 + 统一待办中心)               │
└───────────────────────────┬─────────────────────────────┘
                            │
┌───────────────────────────▼─────────────────────────────┐
│                    API 网关层                           │
│            (统一认证、统一路由、统一限流)                │
└───────────────────────────┬─────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 中台底座系统  │  │ 业务系统     │  │ 数据系统     │
│ - IAM        │  │ - RS         │  │ - BI         │
│ - FLOW       │  │ - LIMS       │  │ - 数据仓库   │
│ - DOC        │  │ - QMS        │  │              │
│ - AI         │  │ - EHS        │  │              │
│ - IM         │  │ - ERP        │  │              │
└──────────────┘  └──────────────┘  └──────────────┘
```

## 3. 数据架构

### 3.1 数据库策略

- **PostgreSQL 16**：主数据库，支持 pgvector 向量检索
- **Redis 7**：缓存、会话、消息队列
- **独立 Schema**：每个服务独立数据库 Schema

### 3.2 数据流

```
RS研发 → LIMS实验数据 → QMS质量管控 → ERP生产/供应链
    ↓                                              ↓
EHS安全环保 ← SRM供应商 ← 采购协同 → 仓储管理
    ↓
GIS空间定位 → DOC文件存储 → AI智能分析 → BI数据可视化
    ↓
FLOW统一审批 → MOBILE移动端 → IM即时通讯
```

## 4. 安全架构

### 4.1 认证授权

- JWT Token 认证
- SSO 单点登录
- RBAC 权限模型
- 行级数据权限

### 4.2 网络安全

- API 网关统一入口
- 服务间 mTLS 通信
- 内外网隔离部署
- 审计日志完整记录

## 5. 部署架构

### 5.1 开发环境

```
Docker Compose
├── PostgreSQL (5432)
├── Redis (6379)
├── topems-doc (8001)
├── topems-iam (8002)
├── topems-ai (8003)
└── topems-flow (8004)
```

### 5.2 生产环境

```
Kubernetes Cluster
├── API Gateway
├── Service Mesh (可选)
├── 中台底座服务
├── 业务服务
└── 数据服务
```

## 6. 监控运维

- **日志**：统一日志收集（ELK/Loki）
- **监控**：Prometheus + Grafana
- **追踪**：Jaeger 分布式追踪
- **告警**：AlertManager
