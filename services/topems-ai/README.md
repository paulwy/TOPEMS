# TOPEMS-AI 智能AI知识库

TOPEMS-AI 是 TOPEMS 平台的智能AI知识库，为全平台提供AI能力支持。

## 核心功能

- 多格式文档解析
- 向量库管理
- RAG 问答
- 智能检索
- 文档摘要
- 智能标签

## 技术栈

- **后端**：Rust + Axum + SQLx
- **前端**：React 18 + TypeScript 5
- **数据库**：PostgreSQL + pgvector
- **AI服务**：Ollama / OpenAI API

## 快速开始

```bash
cd backend
cargo run
```
