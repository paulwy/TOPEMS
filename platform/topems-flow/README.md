# TOPEMS-FLOW 统一OA流程中台

TOPEMS-FLOW 是 TOPEMS 平台的统一OA流程中台，是全系统业务流转的核心。

## 核心功能

- 组织架构管理
- 流程审批
- 待办中心
- 消息通知
- 考勤管理
- 统一审批入口

## 技术栈

- **后端**：Rust + Axum + SQLx
- **前端**：React 18 + TypeScript 5
- **数据库**：PostgreSQL 15+

## 快速开始

```bash
cd backend
cargo run
```
