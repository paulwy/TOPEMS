# TOPEMS 工具目录

这个目录包含了TOPEMS系统的开发工具和示例数据。

## 目录结构

```
tools/
├── mock_data/              # 示例数据目录
│   ├── workflow_mock_data.json   # 工作流示例数据
│   └── ai_mock_data.json         # AI服务示例数据
└── README.md               # 本文档
```

## 示例数据说明

### mock_data/

此目录包含各服务的示例数据，用于开发和测试环境的数据初始化。

#### workflow_mock_data.json

工作流服务的示例数据，包含：
- 工作流定义（如员工入职审批流程、采购申请流程等）
- 流程实例
- 审批记录

#### ai_mock_data.json

AI服务的示例数据，包含：
- 数据连接器配置
- 聊天响应示例
- 查询结果示例

## 数据初始化

各服务的数据初始化已集成到服务启动过程中：

- **HRM服务**：启动时自动初始化部门和员工示例数据
- **ERP服务**：启动时自动初始化公司、部门、员工等示例数据
- **Flow服务**：可使用 `mock_data/workflow_mock_data.json` 中的数据

## 添加新的示例数据

如需为新服务添加示例数据：

1. 在 `mock_data/` 目录下创建 `<service>_mock_data.json` 文件
2. 按照服务需求定义数据结构
3. 在服务的初始化代码中读取并导入数据

## 注意事项

- 示例数据仅用于开发和测试环境
- 生产环境请使用真实业务数据
- 所有服务默认使用真实的PostgreSQL数据库
