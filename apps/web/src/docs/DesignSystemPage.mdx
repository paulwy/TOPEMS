# TOPEMS Design System

TOPEMS Design System 为整个 TOPEMS 平台提供统一的设计语言。所有设计令牌（Design Tokens）定义在 `apps/web/src/theme/tokens.ts` 中，模块渐变色定义在 `apps/web/src/theme/gradients.ts` 中。

## Spacing

间距系统基于 4px 基准网格，提供一致的留白和布局节奏。

<SpacingDemo />

**使用方式：** 在 MUI `sx` prop 中直接使用数字（已映射为 px），或通过 `designTokens.spacing` 获取值。

```tsx

<Box sx={{ gap: 3 }}> // 24px
<Box sx={{ mt: '2xl' }}> // 48px (需通过 theme token 使用)
```

## Icon System

TOPEMS 使用 [lucide-react](https://lucide.dev/) 作为图标库，替代 MUI 内置图标。

### Import Pattern

```tsx
import { User, Settings, Search } from 'lucide-react';
```

### Size Prop

```tsx
<Search size={16} />   // 小尺寸（表格、列表）
<Search size={20} />   // 默认尺寸（按钮、输入框）
<Search size={24} />   // 大尺寸（页面标题）
```

### Style Prop (替代 MUI sx)

lucide-react 图标通过 `style` prop 控制样式，**不要使用 MUI 的 `sx` prop**。

```tsx
// 正确用法
<Settings
  size={20}
  style={{ color: '#6b7280', cursor: 'pointer' }}
/>

// 错误用法 — sx 不生效
<Settings sx={{ color: 'text.secondary' }} />
```

## Dark Mode

TOPEMS 支持暗色模式切换，通过在根元素添加 `.dark` CSS class 激活。

### 激活方式

```tsx
// 方式 1：通过 ThemeProvider 切换
const [isDark, setIsDark] = useState(false);
<ThemeProvider theme={isDark ? darkTheme : lightTheme}>
  <App />
</ThemeProvider>

// 方式 2：通过 CSS class 切换
document.documentElement.classList.toggle('dark');
```

### Token 切换规则

暗色模式下，以下令牌会自动切换：

| Token 类别 | Light Mode | Dark Mode |
|-----------|-------------|-----------|
| `background.default` | `#f8fafc` | `#0f172a` |
| `background.paper` | `#ffffff` | `#1e293b` |
| `text.primary` | `#1e293b` | `#f1f5f9` |
| `text.secondary` | `#64748b` | `#94a3b8` |
| `border.default` | `#e2e8f0` | `#334155` |
| Shadows | 低透明度 | 高透明度 |
| `surface.*` | 浅色系 | 深色系 |

> 详细暗色模式 Shadow 对比见上方 [Shadows](#shadows) 章节。
