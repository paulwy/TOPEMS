# 色彩系统

TOPEMS 色彩系统遵循 **Tailwind CSS 色阶规范**，每个颜色族包含 50-900 共 10 个色阶，并提供 main / light / dark 语义化快捷值。所有颜色值源自 `@topems/tokens`，通过 CSS Variables 注入 MUI 主题。

import React from 'react';

{/* 色板色阶展示组件 */}
const ColorSwatch = ({ name, hex }) => {
  const getContrastColor = (hex) => {
    const r = parseInt(hex.slice(1, 3), 16);
    const g = parseInt(hex.slice(3, 5), 16);
    const b = parseInt(hex.slice(5, 7), 16);
    const luminance = (0.299 * r + 0.587 * g + 0.114 * b) / 255;
    return luminance > 0.55 ? '#1e293b' : '#ffffff';
  };

  return (
    <Tooltip title={`${name}: ${hex}`} arrow placement="top">
      <Box
        sx={{
          backgroundColor: hex,
          color: getContrastColor(hex),
          borderRadius: '8px',
          p: 2,
          minHeight: 72,
          display: 'flex',
          flexDirection: 'column',
          justifyContent: 'flex-end',
          cursor: 'pointer',
          transition: 'transform 0.15s ease, box-shadow 0.15s ease',
          '&:hover': {
            transform: 'translateY(-2px)',
            boxShadow: 3,
          },
          fontSize: '0.75rem',
          fontFamily: 'monospace',
        }}
        onClick={() => {
          navigator.clipboard?.writeText(hex);
        }}
      >
        <Box sx={{ fontWeight: 600, opacity: 0.9 }}>{name}</Box>
        <Box sx={{ opacity: 0.7, fontSize: '0.625rem' }}>{hex}</Box>
      </Box>
    </Tooltip>
  );
};

const ColorFamily = ({ title, tokenKey }) => {
  const colorData = designTokens.colors[tokenKey];
  const shades = ['50', '100', '200', '300', '400', '500', '600', '700', '800', '900'];
  const semanticKeys = ['main', 'light', 'dark', 'contrastText'].filter(k => colorData[k] !== undefined);

  return (
    <Box sx={{ mb: 4 }}>
      <Typography variant="h6" sx={{ mb: 1.5, textTransform: 'capitalize' }}>
        {title}
      </Typography>
      <Typography variant="body2" color="text.secondary" sx={{ mb: 2 }}>
        Token 路径：<code>designTokens.colors.{tokenKey}</code>
      </Typography>
      <Typography variant="subtitle2" color="text.secondary" sx={{ mb: 1, fontSize: '0.75rem', textTransform: 'uppercase', letterSpacing: '0.1em' }}>
        色阶
      </Typography>
      <Box sx={{ display: 'grid', gridTemplateColumns: 'repeat(10, 1fr)', gap: 1, mb: 2 }}>
        {shades.map(shade => (
          colorData[shade] && (
            <ColorSwatch key={shade} name={`${tokenKey}.${shade}`} hex={colorData[shade]} />
          )
        ))}
      </Box>
      {semanticKeys.length > 0 && (
        <>
          <Typography variant="subtitle2" color="text.secondary" sx={{ mb: 1, fontSize: '0.75rem', textTransform: 'uppercase', letterSpacing: '0.1em' }}>
            语义别名
          </Typography>
          <Box sx={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(80px, 1fr))', gap: 1 }}>
            {semanticKeys.map(key => (
              <ColorSwatch key={key} name={`${tokenKey}.${key}`} hex={colorData[key]} />
            ))}
          </Box>
        </>
      )}
    </Box>
  );
};

## 语义化颜色映射

以下列出了 `semanticTokens` 中的关键语义映射：

| 语义 | Token 路径 | 值 | 用途 |
|------|-----------|-----|------|
| 页面背景 | `semanticTokens.background.page` | `#f8fafc` | 页面底色 |
| 卡片背景 | `semanticTokens.background.card` | `#ffffff` | 卡片/面板底色 |
| 悬浮层背景 | `semanticTokens.background.elevated` | `#ffffff` | 弹出层底色 |
| 主文本 | `semanticTokens.text.heading.1.color` | `#1e293b` | 页面主标题 |
| 次要文本 | `semanticTokens.text.body.secondary.color` | `#64748b` | 表格/列表次要信息 |
| 辅助文本 | `semanticTokens.text.caption.color` | `#94a3b8` | 标签/小字说明 |
| 输入框边框 | `semanticTokens.border.input` | `1px solid #e2e8f0` | 表单输入默认边框 |
| 输入框聚焦 | `semanticTokens.border.inputFocus` | `2px solid #3b82f6` | 输入框聚焦态 |
| 强调边框 | `semanticTokens.border.emphasis` | `2px solid #3b82f6` | 选中态边框 |
| 卡片阴影 | `semanticTokens.elevation.card` | shadow-sm | 卡片默认层级 |
| 下拉阴影 | `semanticTokens.elevation.dropdown` | shadow-lg | 下拉菜单层级 |
| 对话框阴影 | `semanticTokens.elevation.dialog` | shadow-xl | 模态对话框层级 |

## 使用指南

### 在组件中使用

```tsx
import { designTokens, semanticTokens } from '@topems/tokens';

// 使用基础色阶
const primaryMain = designTokens.colors.primary.main; // '#3b82f6'

// 使用语义令牌（推荐）
const cardBorder = semanticTokens.border.card;         // '1px solid #e2e8f0'
const dialogRadius = semanticTokens.radius.dialog;      // 16
```

### 在 sx prop 中使用

```tsx
<Box sx={{
  backgroundColor: 'background.paper',    // MUI 主题变量
  border: semanticTokens.border.card,    // 语义令牌
  borderRadius: semanticTokens.radius.card, // 语义圆角
  boxShadow: semanticTokens.elevation.card, // 语义阴影
}}>
```

### 主题切换

所有颜色通过 CSS Variables 注入，亮/暗色主题切换仅需在根元素切换 class：

```tsx
// 切换暗色模式
document.documentElement.classList.add('dark');
// 切换亮色模式
document.documentElement.classList.remove('dark');
```
