# TOPEMS 设计系统

## 概述

TOPEMS 设计系统基于 **MUI v9** 构建，采用 CSS Variables 主题方案，为企业级应用提供一套完整的设计令牌（Design Tokens）、共享组件和页面模板。

## 架构分层

| 层级 | 包名 | 说明 |
|------|------|------|
| **令牌层** | `@topems/tokens` | 颜色、间距、排版、阴影、动效的单一数据源 |
| **常量层** | `@topems/shared-constants` | 运行时颜色常量，从令牌派生 |
| **类型层** | `@topems/shared-types` | UI 类型定义 |
| **组件层** | `@topems/shared-components` | 22+ 共享组件（DataTable、FormField、StatusBadge 等） |
| **Hooks 层** | `@topems/shared-hooks` | useCrud、useDebounce 等通用 Hooks |
| **工具层** | `@topems/shared-utils` | 日期、数值、校验等工具函数 |
| **模板层** | `apps/web/components/templates` | 16+ 页面模板 |
| **图表层** | `apps/web/components/charts` | Bar、Line、Pie、Area、Radar 图表封装 |
| **移动端** | `apps/web/components/mobile` | 12+ 移动端优化组件 |
