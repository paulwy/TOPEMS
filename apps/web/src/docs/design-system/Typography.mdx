# 排版系统

TOPEMS 排版系统基于 **Inter + Noto Sans SC** 字体栈，提供从 h1 到 caption 的完整排版层级，所有排版参数源自 `@topems/tokens`。

## 语义化排版令牌

`semanticTokens.text` 将基础排版令牌与语义场景结合：

| 语义 | Token 路径 | 基础令牌 | 颜色 |
|------|-----------|---------|------|
| 页面主标题 | `semanticTokens.text.heading.1` | h1 | `#1e293b` |
| 区域标题 | `semanticTokens.text.heading.2` | h2 | `#1e293b` |
| 卡片标题 | `semanticTokens.text.heading.3` | h3 | `#1e293b` |
| 子区块标题 | `semanticTokens.text.heading.4` | h4 | `#1e293b` |
| 小节标题 | `semanticTokens.text.heading.5` | h5 | `#1e293b` |
| 标签标题 | `semanticTokens.text.heading.6` | h6 | `#64748b` |
| 默认正文 | `semanticTokens.text.body.default` | body1 | `#1e293b` |
| 次要正文 | `semanticTokens.text.body.secondary` | body2 | `#64748b` |
| 辅助说明 | `semanticTokens.text.body.muted` | caption | `#94a3b8` |
| 按钮文本 | `semanticTokens.text.button` | button | — |
| 标签 | `semanticTokens.text.caption` | caption | `#94a3b8` |
| 大号标签 | `semanticTokens.text.overline` | overline | `#64748b` |

## 使用指南

```tsx
import { designTokens, semanticTokens } from '@topems/tokens';

// 使用基础排版令牌
const h1Style = designTokens.typography.h1;
// { fontSize: '2.5rem', fontWeight: 700, lineHeight: 1.2, letterSpacing: '-0.025em' }

// 使用语义排版令牌（推荐 — 包含颜色）
const heading1 = semanticTokens.text.heading['1'];
// { fontSize: '2.5rem', fontWeight: 700, lineHeight: 1.2, letterSpacing: '-0.025em', color: '#1e293b' }

// 在 sx prop 中
<Typography sx={heading1}>页面标题</Typography>
```
