# 组件库

TOPEMS 共享组件库包含 **22+** 个精心设计的企业级组件，分为 8 大类别。所有组件位于 `packages/shared-components` 中，支持 `sx` prop、TypeScript 类型安全和亮/暗色主题。

import React from 'react';

{/* 组件分类卡片 */}

      <Typography variant="h6">{icon} {title}</Typography>
      <Chip label={`${components.length} 个组件`} size="small" variant="outlined" />
    </Box>
    <Typography variant="body2" color="text.secondary" sx={{ mb: 2 }}>{description}</Typography>
    <TableContainer>
      <Table size="small">

          <TableRow>
            <TableCell sx={{ fontWeight: 'bold' }}>组件</TableCell>

            <TableCell sx={{ width: 160 }}>Storybook</TableCell>

## 组件 API 规范

所有共享组件遵循统一的 API 规范：

<Box sx={{ p: 3, borderRadius: 2, backgroundColor: 'grey.50', mb: 3 }}>
  <Stack spacing={1.5}>
    <Typography variant="subtitle2" fontWeight="bold">标准 Props</Typography>
    <TableContainer>
      <Table size="small">
        <TableBody>
          <TableRow>
            <TableCell sx={{ fontFamily: 'monospace', fontWeight: 'bold' }}>sx</TableCell>
            <TableCell sx={{ fontFamily: 'monospace' }}>SxProps&lt;Theme&gt;</TableCell>
            <TableCell>所有组件必须提供，禁止使用 any</TableCell>
          </TableRow>
          <TableRow>
            <TableCell sx={{ fontFamily: 'monospace', fontWeight: 'bold' }}>size</TableCell>
            <TableCell sx={{ fontFamily: 'monospace' }}>'sm' | 'md' | 'lg'</TableCell>
            <TableCell>可交互组件应提供（ComponentSize）</TableCell>
          </TableRow>
          <TableRow>
            <TableCell sx={{ fontFamily: 'monospace', fontWeight: 'bold' }}>disabled</TableCell>
            <TableCell sx={{ fontFamily: 'monospace' }}>boolean</TableCell>
            <TableCell>可交互组件应提供</TableCell>
          </TableRow>
          <TableRow>
            <TableCell sx={{ fontFamily: 'monospace', fontWeight: 'bold' }}>loading</TableCell>
            <TableCell sx={{ fontFamily: 'monospace' }}>boolean</TableCell>
            <TableCell>数据驱动组件应提供</TableCell>
          </TableRow>
          <TableRow>
            <TableCell sx={{ fontFamily: 'monospace', fontWeight: 'bold' }}>children</TableCell>
            <TableCell sx={{ fontFamily: 'monospace' }}>ReactNode</TableCell>
            <TableCell>容器型组件应提供</TableCell>
          </TableRow>
        </TableBody>
      </Table>
    </TableContainer>
  </Stack>
</Box>

## 使用方式

```tsx
// 从 @topems/shared-components 导入
import {
  DataTable,
  StatusBadge,
  FormField,
  ConfirmDialog,
  ActionButton,
  PageContainer,
} from '@topems/shared-components';

// 使用 sx prop 自定义样式
<StatusBadge
  status="active"
  sx={{ mt: 1 }}
/>
```
